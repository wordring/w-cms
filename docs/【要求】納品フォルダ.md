## ⚠ まず確かめたいこと——「納品」は2つあります

> ユーザー:「**納品書は納品フォルダの納品書ページから発行します**」

**発行する**ということは、**弊社が出す紙**です。ところが、その少し前に伺った
`納品日` は**発注書**の話でした——あちらは**仕入先が弊社へ納める**側です。

| どちら向きか | 紙 | 誰が出すか | 対応するもの |
|---|---|---|---|
| **弊社 → 顧客** | **納品書** | ⚠ **弊社が発行する**（本書） | 受注 |
| **仕入先 → 弊社** | 仕入先の納品書 | **相手が出す**（こちらは受け取るだけ） | 発注 |

⚠ **同じ「納品」でも、別のものです。** 決めていただきたいのは:

**① 本書はどちらを扱うか。** 「発行します」なので**弊社が出す側**だと読みましたが、
**受け取る側も同じフォルダに入れる**なら、`向き` で分けることになります
（通信箱が `向き：受信／送信` でやっているのと同じ形）。

**② 発注書の `納品日`（＝仕入先から届いた日）はどこに書くか。**
⚠ **[【要求】発注フォルダ.md](【要求】発注フォルダ.md) で未決のまま**です。
本書が**弊社が出す側だけ**なら、あちらの置き場は別に決める必要があります。

## 1. 置き場

**`納品／年／月／納品書ページ`**（年月は納品日）。

⚠ **受注ページの下には置けません**——**発注書と同じ理由**です。1回の納品が
**複数の受注にまたがる**ことがあり、⚠ **分納なら1つの受注から何枚も出ます**。

## 2. なぜ器が要るのか

⚠ **物差しはユーザー自身が出しました**（[【考察】製造という軸.md](【考察】製造という軸.md) §7i）
——**①外に出る紙があるか ②1つの受注行に何度も起きるか**。

| 問い | 納品は |
|---|---|
| 外に出る紙があるか | ✓ **納品書**（2026-09-22 決定:「**納品書はこのシステムから出します**」） |
| 1つの受注行に何度も起きるか | ✓ **分納**（「一つの加工製品が**複数の納品に分かれる**場合もある」） |

**どちらも「はい」なので、器が要ります。**

⚠ **これで同じ形が5つ並びます**——**見積・発注・納品・請求の紙が原本、受注明細は鏡**。

## 3. ⚠ 受注明細に足す列はゼロ

> 2026-09-22 ユーザー:「納品は**記録すべきことがあまりありません**」

**そのとおりで、記録するのは紙のほう**だからです。

```
納品書ページ（納品／年／月）   ← 紙が原本。いつ・何を・何個
      ↓ 索引から数える
受注明細の `出荷済み`          ← 累計だけ（鏡）。⚠ **人は打ちません**
```

⚠ **`出荷済み` はいま人が打つ欄です。** 納品書ができたら**鏡に置き換わります**
——⚠ **印と事実を二重に持たない**ため。

⚠ **分納だと `納品日`・`納品数` は1セルに入りません。** これが「受注ページの表に
入れれば良いか」という当初の案を採らなかった理由です。

## 4. 納品書ページ（案）

⚠ **発注書ページと同じ作りにするのが素直**だと思います（既に動いているので）。

### タグ（案）

| タグ | 型 | 備考 |
|---|---|---|
| 納品書番号 | code | ⚠ **ページ番号そのもの**（発注書と同じ。別に採番しない） |
| 客先 | text | 連絡帳にある組織または個人 |
| 納品日 | date | ⚠ **実際に納品した日**（予定は `納期`・確定した期日は `納品日`） |
| 納品担当 | ref | 連絡帳の担当者ページ |
| 納品場所 | text | |

### 納品明細（案）

⚠ **列は受注明細と名前と型を揃えること**——揃っていないと、**横断検索が片方を
取りこぼします**（`弊社品番`・`品番`・`品名`・`数量`・`単位`）。

| 列 | 型 | 備考 |
|---|---|---|
| 弊社品番 | ref | 加工製品ページ。⚠ **これが無いと、どの受注のぶんか辿れません** |
| 品番 | code | 顧客の言葉 |
| 品名 | text | |
| 数量 | number | ⚠ **この回に納めた数**（受注数ではありません） |
| 単位 | enum | |
| 備考 | text | |

⚠ **単価・金額を書くかは未決**です。実物の納品書を見てから決めるのが確実です
（発注書は**実物7枚**を読んで形が決まりました）。

## 5. ⚠ 分納をどう表すか（未決）

**同じ加工製品を2回に分けて納める**とき:

```
受注: ブラケット 20個
  → 納品書A  10個（9/25）
  → 納品書B  10個（10/2）
```

- **受注明細の `出荷済み`** は、2枚を**足して 20** になります（鏡）。
- ⚠ **「あと何個か」は引き算で出ます**（`数量 − 出荷済み`）——**欄は要りません**。
- ⚠ **決めていただきたいのは、納品書を作るときに「残り」をどう見せるか**です
  ——発注の「必要部材」と同じように、**まだ納めていないものの一覧**が要るはずです。
