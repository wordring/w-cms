# 【要求】テンプレート

**テンプレート**の要求仕様です。
テンプレートは、ページを作るときの雛形（もとになる見本）です。
新しいページの雛形・置き場の雛形・機械が作るページの雛形の3つを扱います。

> **この文書の読み方**
>
> - 印の無い文は**要求**です（こうあってほしい、という決まり）。書くのは利用者で、
>   エージェント（AI）は矛盾を見つけたら指摘します（[開発方針 §2](開発方針.md)）。
> - 「⚠ **いま**」で始まる段落は**実装の現状**です。こちらはエージェントが実装に合わせて直します。
> - この文書には、要求として立てた節がまだありません。
>   あるのは、エージェントが旧文書から抜き出して置いた「下書き」だけです。利用者が読んで、直したり採ったりします。
> - なぜそう決めたかは、`考察/` フォルダの【考察】に残してあります。

   > 2026-08-21 利用者:「機能が名前で変わるのは目論見通りです。表示されている言葉が機能を表します」

   - 出どころ: [【考察】ページテンプレート.md](考察/【考察】ページテンプレート.md) の決定ログ・コンセプト.md:30・74

2. **テンプレートの下では、鏡もボタンも機能しません。**
   鏡は、本文には印だけを置いて、中身はサーバーが表示のたびに描く部分のことです。
   書き込みの API（サーバーへ書き込みを頼む入口）も、テンプレートの中では断ります。

   テンプレートの上でボタンを押すと、書いたものが、そこから作るページ全部へコピーされてしまうためです。

   > 2026-09-27 利用者:「テンプレート以下では鏡もボタンも機能しないようにしましょう」

   - 出どころ: アーキテクチャとDBスキーマ.md:340-345
   - ⚠ いま: 実装済みです。鏡は名前だけの案内を出し、書き込みの API は 409（断りの応答）を返します。

3. **子ページを作るとき、使えるテンプレートがあれば、メニューで選ばせます。無ければ、そのまま作ります。**
   使えるテンプレートとは、テンプレートフォルダの葉（下に子ページを持たない、端のページ）のことです。
   入力フォームのダイアログは作りません。

   - 出どころ: エディタ仕様.md:498-500・【考察】ページテンプレート §4.3・§7
   - ⚠ いま: 実装済みです。

4. **新しいページの初期本文は、内容だけにします。**
   - 子ページの一覧は、左レール（画面の左の列）が受け持つので、本文には入れません。
   - ダミーのデータを入れません。
   - 出どころ: アーキテクチャとDBスキーマ.md:552・557
