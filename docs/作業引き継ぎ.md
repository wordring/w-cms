  出ず、エラーも出ない。**印刷は `printOnly` を通すこと**（写しを見えない別の枠に置いてその枠だけを刷る——10-03 から。10-02 深夜の

  表示部品が無い）——ヘッドレスの E2E が緑でも、本物の Chrome では開かないことがある。本物で見るのは `e2e/probe-print-chrome.js`
  （`channel: 'chrome'`・画面つき・印刷の画面が開くとページが止まるので「応答しない＝開いた」と読む）。
- **ローカル検証のログインは `a` / `a`**。CSRF対策で `Origin` ヘッダ必須。
- **QRの検証ツールは開発機に pip で入れている**（`opencv-python-headless`・`qrcode`・

**索引・スキーマ**

- **「必要部材表（や手配状況）が空」は、壊れているとは限らない**（09-24・09-25 に利用者の問い）——鎖は **受注明細 → 加工製品
  ページ（弊社品番、または品番と同じ図面番号タグ）→ その材料表 × 受注数**。どこで切れているかは、`vocab_index` を `data_type`
  ごとに、`page_tags` を `部品番号・品番・図面番号` で数えると一目で分かる（弊社品番が空・結ぶ加工製品が無い・材料表が0行の
  どれか）。受注残表では弊社品番が空のセルが薄赤になる。
- **⚠ 畳めなかったタグは、並べると先頭・絞ると消える**（09-21・SQLite で実測）。
  `date` として畳めない値は `norm_value` が **NULL** になり、`ORDER BY` では先頭
  （NULL 最小）、`WHERE norm_value <= ?` では黙って消える。**`norm_value IS NOT NULL` を
  明示し、畳めなかったものを別枠で必ず見せること。**
  ⚠ **`納期` はこれに当たらなくなりました**（09-23 に型が `text` へ・利用者決定）——
  `最短納期` にも畳んだ値が付きます（再構築後の索引で確認）。**代わりに逆の制約が来ました**:
  **索引では納期を日付として並べ替え・範囲検索できません**（`2026/10/15` が文字として
  入るので、`2026-10-15` 形との大小も、暦の順も当てになりません）。
  ⚠ **だから納期で並べる・絞る口は、索引の `norm_value` で絞らないこと。**
  いまの受注残表は **Go の中で `cms.NormalizeValue(cms.ColDate, due)` を通してから並べて**
  いるので効いています（`sortBacklogGroups`・読めないものは先頭）——**同じ手を使うこと。**
- **⚠ 新しいテーブルを足しても自動再構築は走らない**——`ApplySchema` は空の表を作るだけ。
  `DriftedSchemaTables` が「索引に中身があるのに表が無い」もずれとして扱う。⚠ `CREATE INDEX` を
  表と取り違えると起動のたびに再構築が走る（`createdTableName`）。
- **⚠ スキーマを変えたら、作り直しが `ApplySchema` より先**（逆だと `no such column: name` で
  起動が落ちる）。
- **⚠ 主鍵を付けると隠れていた重複が出る**／**⚠ 一括置換で SQL を直すときは UNION を跨がない**
  （`page_tags` と `vocab_index` で列名が違う）。
- **プラグインテーブルにマイグレーションは無い**——起動時に1度だけ自動再構築。
- **業務ブロックの行き先は `vocab_index`、タグは `page_tags`**。③計算は
  [vocab_query.go](../internal/cms/vocab_query.go) を通す——**索引の `field` は見出しの表示文字**
  （`品番`）で機械キー（`item-id`）ではない。
- **`section` の素の `dl` は索引に入らない（09-18）——素の `table` だけ `section` の側から拾う**
  （`syncVocabSection`・`eachPlainVocabTable`。`■材料` のような見出しの下に表が並ぶワンノート
  移行の受け皿）。**登録されていない見出しの節は素の表も索引しない**（09-20）。ヘッダを
  素の `dl` に書いても検索に掛からない——ページの可変タグへ。対応づけは `block_no`。
- **⚠ 節の見出しと `<caption>` が重なると索引が二重に入っていた**（09-21 に修正）——手配数も
  原価も倍になる。形式の解決は ①属性 ②節の見出し ③caption の順で**1回だけ**。
  ⚠ **鏡も同じ罠を踏んでいた**（09-27 に修正）——加工製品テンプレートの `<section><h2>材料</h2><table><caption>材料</caption>`
  で、**最新単価の列が2つ**出ていた（利用者の指摘）。配送係は節と表の両方へ配るので、**見出しの節に配られた
  鏡は、中の素の表（`cms.VocabTypeOf` が空の表）だけを扱うこと**（`mirrorTablesOf`・索引の `eachPlainVocabTable` と同じ判定）。
  見出しで表を名乗る解決を消せば（DBの日本語化 5段目の4）、この罠ごと無くなる。
- **`text` と `code` は畳む強さだけが違う**。`code` は空白・ハイフン類・長音・大小まで畳み、
  `text` は長音に触らない。引くのは `PagesByTag`（生）と `PagesByTagLoose`（畳んだ一致）。
  ⚠ **`NormalizeForLookup` は 09-15 に撤去**——文字列で引くと number のタグが**0件**になる。
- **語→型の推論辞書はコードではない**——正本は `config/settings.json` の `vocabulary`。壊れて
  いると起動が止まる（仕様）。語を足したらDB再構築。**登録された語彙だけDBに入る**（09-20）。
- **観察係の `descend` は OR で畳まれる**（AND にすると明細が索引から消える）。
- **本文の走査はコアの配送係だけ**（`walk.go`）。`WalkElements` を自分で回すコードはたいてい
  設計を間違えている。**鏡は引き金1つにつき1つ**。
- **テンプレート領域（ルート含む）は③計算に載らない**。判定はサイドカー＋本文HTML（DBを見ない）。
  **移行中のページ（`移行中` タグ）も表引きしない**（在ることで止める）。
- **③計算の集計スコープは `cms.RelatedPages`**（深さ1・両向き）。`block_no` はページ内の連番。

**本文・参照**

- **⚠ エディタで保存した本文は字下げされる**（2026-10-04 に踏んだ）——`<dt>図面番号</dt>` と `<dd>` のあいだ、`<tr data-id>` と
  `<td>` のあいだに改行と空白が入る。詰めた形（`</dt><dd>`・`"><td>`）の文字列や正規表現で読むと、機械が作ったばかりの本文では
  通り、人が一度保存したページだけで黙って空に読める（職場の図面2つ以上のページの半分）。読むときは `\s*` を許すか木にして読む
  （`factsOfBlock`・`cms.TagValue`）。試験の本文も字下げのある形を1つは持つこと。
- **⚠ 本文の空欄は `<dd><br/></dd>`**——`<dd>([^<]*)</dd>` だけで探すと空欄を素通りする
  （`replaceFirstFieldValue` は `<br>` も空と扱う）。
- **項目の鍵は見出しの表示文字**（`th`／`dt`）。機械キーを本文へ書く属性は無い。
  **見出しは宣言から組む**——手書きに戻すと足した列がどこからも読めない。
- **参照タグと読むのは可変タグ（`dl[data-type="tags"]`）の中だけ**——素の `dl` まで見ると
  発注書番号（`250401-203`）が参照に化ける。
- **参照が飛ぶ先は常に本文のブロック**（`#<data-id>`）。添付の識別子もブロックIDと同じ4桁。
  社内コードは「ページ番号-ブロックID」で、指し先は**消えないもの**（図面ブロックは人が消せる）。
- **本文の取得口は `GET /api/load` の1つ**（サニタイズを通す）。**アンカー合成と参照リンクは
  通さない**——合成HTMLが本文として保存されるため。
- **⚠ `/api/load` の出力を `/api/save` へ書き戻してはいけない**（09-21 に踏んだ）。`/api/load` は
  鏡を埋めて返し、落とすシリアライザは**ブラウザの `app.js`**。外から書き戻すと鏡が本文に
  焼き込まれる（エラーは一切出ない・6枚に `📄 …を開いています` と検算の `<tfoot>` が2回ずつ焼けた）。同日 `cms.StripChrome` を
  **`Sanitize`／`SanitizeReport` の冒頭**で通すようにした——⚠ **順序がこの守りの全部**
  （サニタイズは `class` を落とすので後では印が無い）。⚠ 既に保存された鏡は落とせない——
  `versions/` の最古の版から戻す（`data/master/<2桁>/<ID>/versions/*.html.gz`）。
  **外から本文を書き換えるときは正本のファイルを読む**（`data/master/<2桁>/<ID>/<ID>.html`・
  Go の中なら `cms.RewriteBody`）。番人は `internal/cms/chrome_strip_test.go`。
- **⚠ 自動保存は1.5秒のデバウンス。退出はそれを流してから**——「保存してから何かする」経路は
  `await saveToServer()` を通す。
- **解析・取り込みのあとに古くなるのは2か所**——左レール（`loadChildNav()`）と本文の子ページ
  一覧の鏡（`reloadContent()`）。⚠ **取り込み側は `loadChildNav()` だけ**——落とすのは編集モード
  なので `reloadContent()` を呼ぶと書きかけが消える。
- **エディタのクロームは `.vocab-chrome`**（シリアライザが保存しない）。**見た目の印は本文に
  保存できない**（`class` はサニタイズで落ちる）——表示時に付ける鏡型で作る。
- **殻の `id` は接頭辞 `w-` を独占する**。
- **子ページの並びは「並び順キー → 題 → ID」**（`sortChildren`・正本はサイドカー `sort_key`・
  ドラッグ並べ替えは `ReorderKey`）。
- **版は本文HTMLだけ**。リバートで権限・所有者・親は巻き戻らない。
- **スラッシュメニューの項目は絞り込みのたびに作り直す**——click / mouseenter は作るたびに配線。

**安全**

- **インラインの script/style・`on*=` は書けない**（CSP strict）。配線の固定は `TestCSPIsWired`。
- **DOM生成は `createElement`＋`textContent`**（`innerHTML` へ文字列を入れない・保存型XSSの前科）。
- **サニタイズ後にHTMLを足す関数**（`RenderComputedViews`・`RenderAnchors`・`RenderPageShell`・
  `RenderReferenceLinks`）は自前でエスケープ責任を負う。
- **本文の埋め込みの宛先は `/data/` 配下ときれいなURLに限る**。クロームがリンクから埋め込みを
  導出するときは形を検査する（`refreshAttachmentPreviews` が手本）。状態を変える経路は
  メソッドを絞る（`route_guard_test.go`）。
- **認可の読み口は `cms.db`（派生）**——派生から正本へは書き戻さない。
- **匿名には「読めない」と「存在しない」を区別させない**（どちらも404）。戻り先は `safeNextPath`。
- **添付の保存先は `files/` サブフォルダ**（上書きは構造的に不可能）。名前の検査
  `SafeAttachmentName` は全アップロード口が共有——**Gemini へ送る側も同じ関門を通す**
  （`ext/toho/analyze_pdf.go`・番人 `analyze_name_guard_test.go`）。⚠ **試験から Gemini を呼ばせない**——東邦の試験の下ごしらえ
  （`setupExtTest`）が `GEMINI_API_KEY` を空にする（10-01 に、守りを外した変異で試験のデータが本当に送られた）。画像は保存前に EXIF を落とす。SVG は配信側が本体。
  PDF はインライン配信。**ZIP の展開はメール取り込みだけ**（根拠は原本 `.eml` が ZIP を持つこと・
  上限は `cms.ExpandZip` の中・目録の由来は `zip:<ZIPの保存名>/<中のパス>`）。メールの添付も
  `GuardUploadContent` を通す。
- **Gemini は有料枠のキーで運用する**（無料枠は入力が製品改善に使われる）。キーの値はチャット・
  ログ・リポジトリに残さない。
- **ルート表は `buildHandler()`**（`cmd/w-cms/main.go`）。拡張の口は各プラグインの `Routes()`。
  **`/dav/` は `CSRFProtect` の外側**。
- **⚠ データの初期化は「押した覚えがなくても起きる」**（09-16 に実データ67ページが初期化。監査には
  利用者 `a` の `data.reset` が残るが、何が押したかは不明）。控え（`data/_reset-<日時>/`）から
  1手で戻せた——**初期化のボタンを押す自動操作を書かない**。
  ⚠ 初期化は「掴まれていて」断られることがある（ウイルス対策・索引・エディタが数百ミリ秒掴み、
  `data/master` の改名が `Access is denied.`）——5回・200ミリ秒おきにやり直す。それでも駄目なら
  エディタで `<ID>.meta.json` 等を開いていないか見る。

**メール**

- **⚠ メールのサインインは w-cms の利用者ごと**（`data/mail/<ログイン名>.json`・日本語の名前は `~<16進>.json`——10-02 から）。

**WebDAV・QR**

- **⚠ Ctrl+S は w-cms に届かない。アプリを閉じるまで**（Windows の `WebClient` が最後のハンドルが

  開くので、無いと**添付が0バイトになる**。**一組**。
- **⚠ Go の埋め込みで `Write` を差し替えても素通りする**（`*os.File` の `ReadFrom` が昇格）。

注意:

- **ローカル開発のログイン**: `a` / `a`（**ローカル検証専用**。本番では使わないこと）。
- `data/` はコミットされないため、別環境では初回起動時に上記の環境変数で管理者が作られます。
  **「家でログインできない」は、初回の管理者未作成か別の認証情報**。
- **既存 `data/auth.db` の認証情報を忘れた／揃えたいとき**は、サーバーを止めてから以下で揃う:
  ```bash
  # 一時パッケージで internal/auth を呼ぶ（ルートに別の package main があるためサブdirで実行）。
  mkdir -p _resetpw && cat > _resetpw/main.go <<'GO'
  package main
  import ("fmt"; "w-cms/internal/auth"; "w-cms/internal/database")
  func main(){ database.InitAuthDB(); defer database.AuthDB.Close()
    if err := auth.SetPassword("a", "a"); err != nil {
      if err2 := auth.CreateUser("a", "a", true, ""); err2 != nil { fmt.Println(err, err2); return }
    }
    fmt.Println("ローカル管理者 a / a を用意しました") }
  GO
  go run ./_resetpw && rm -rf _resetpw
  ```
- ローカル実行・プレビュー用に `.claude/launch.json`（`go run` 起動設定）を用意済み
  （プレビューでCookieが付くよう `WCMS_SECURE_COOKIES=0` 設定済み）。
- 取り込み・解析を試すには、トップ直下に「通信箱」ページを作り（名前が機能）、
  `GEMINI_API_KEY` を設定して起動する（無ければ解析ボタンが設定を促すだけで、他は全部動く）。
