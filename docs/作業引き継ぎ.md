**安全**

- **インラインの script/style・`on*=` は書けない**（CSP strict）。配線の固定は `TestCSPIsWired`。
- **DOM生成は `createElement`＋`textContent`**（`innerHTML` へ文字列を入れない・保存型XSSの前科）。
- **サニタイズ後にHTMLを足す関数**（`RenderComputedViews`・`RenderAnchors`・`RenderPageShell`・
  `RenderReferenceLinks`）は自前でエスケープ責任を負う。
- **本文の埋め込みの宛先は `/data/` 配下ときれいなURLに限る**。クロームがリンクから埋め込みを
  導出するときは形を検査する（`refreshAttachmentPreviews` が手本）。状態を変える経路は
  メソッドを絞る（`route_guard_test.go`）。
- **認可の読み口は `cms.db`（派生）**——派生から正本へは書き戻さない。
- **匿名には「読めない」と「存在しない」を区別させない**（どちらも404）。戻り先は `safeNextPath`。
- **添付の保存先は `files/` サブフォルダ**（上書きは構造的に不可能）。名前の検査
  `SafeAttachmentName` は全アップロード口が共有——**Gemini へ送る側も同じ関門を通す**
  （`ext/subcon/parse_pdf.go`）。画像は保存前に EXIF を落とす。SVG は配信側が本体。
  PDF はインライン配信。**ZIP の展開はメール取り込みだけ**（根拠は原本 `.eml` が ZIP を持つこと・
  上限は `cms.ExpandZip` の中・目録の由来は `zip:<ZIPの保存名>/<中のパス>`）。メールの添付も
  `GuardUploadContent` を通す。
- **Gemini は有料枠のキーで運用する**（無料枠は入力が製品改善に使われる）。キーの値はチャット・
  ログ・リポジトリに残さない。
- **ルート表は `buildHandler()`**（`cmd/w-cms/main.go`）。拡張の口は各プラグインの `Routes()`。
  **`/dav/` は `CSRFProtect` の外側**。
- **⚠ データの初期化は「押した覚えがなくても起きる」**（09-16 に実データ67ページが初期化。監査には
  利用者 `a` の `data.reset` が残るが、何が押したかは不明）。控え（`data/_reset-<日時>/`）から
  1手で戻せた——**初期化のボタンを押す自動操作を書かない**。
  ⚠ 初期化は「掴まれていて」断られることがある（ウイルス対策・索引・エディタが数百ミリ秒掴み、
  `data/master` の改名が `Access is denied.`）——5回・200ミリ秒おきにやり直す。それでも駄目なら
  エディタで `<ID>.meta.json` 等を開いていないか見る。

**メール**

- **IMAP と SMTP は同じリソース**なのでトークンは1つ。**SMTP で投函したメールは「送信済み
  アイテム」に残らない**（控えは通信箱）。新しい権限は動的同意で足せる。
- **⚠ `AADSTS65001` は `invalid_grant` の形で返る**——失効とみなして捨てると権限を増やした日に
  サインインが消える。**保管は自動で捨てない**（`deleteToken` は自動では呼ばない）。
- **既読にしない**（`EXAMINE`＋`BODY.PEEK[]`）。IMAP のリテラルは行単位で読むと崩れる。
- **⚠ 添付名に Go 標準の `Part.FileName()` を使わない**——復号前に `filepath.Base` が掛かり
  base64 の `/` で切れる。使うのは `partFileName`。
- **返信の宛先は `返信先` → `差出人` の順に素のアドレスだけ**（`RCPT TO:` の都合）。
- **`/api/thread`（`In-Reply-To` の鎖）と `/api/replies`（w-cms が送った返信）は別の鎖**。

**WebDAV・QR**

- **⚠ Ctrl+S は w-cms に届かない。アプリを閉じるまで**（Windows の `WebClient` が最後のハンドルが
  閉じたときに書き戻す・実測75秒後）。**「エラーが出なかった＝保存された」は成り立たない**
  ——確かめるのはサーバー側（`PUT` ログ・`files/.versions/`・監査 `dav.write`）。
- **⚠ `PROPPATCH` を塞ぐと Ctrl+S が通らない**（403 で `PUT` まで進まない）。通すなら
  `davWriteFile` の「空なら差し替えない」が要る——`x/net/webdav` は PROPPATCH でも `O_RDWR` で
  開くので、無いと**添付が0バイトになる**。**一組**。
- **⚠ Go の埋め込みで `Write` を差し替えても素通りする**（`*os.File` の `ReadFrom` が昇格）。
  見るのは一時ファイルの大きさ。
- **⚠ 本文の無い `PROPPATCH` は 400 で弾かれる**——試験は Windows が送る XML を入れて 207 まで。
- **`handlePut` は `OpenFile` のエラーを 404 に潰す**——書き込みの断りは `refuseDavPut` で返す
  （ハンドラ＝体裁の層、FS＝安全の層）。
- **⚠ QRは「他所のライブラリと同じ絵」にならない**——絵の一致を正しさの尺度にしない。
  `python tools/qr_verify.py` が復号して確かめる（固定データを `-update-qr` で更新したら必ず走らせる）。

**文書**

- **⚠ パスを一括で置き換えるとき、変更履歴と決定ログは除く**（起きていない過去が書かれる）。
  規則は**説明文は今の場所／変更履歴・決定ログの本文は当時の名前**。
- **⚠ 公開リポジトリの履歴を書き換えるとき**（09-20）——`--replace-text` はコミットメッセージを
  書き換えない（`--replace-message` が別に要る）。置換漏れは部分形・大小混在・下線形・全角
  ハイフン／長音で5回試験に出た——**長いものから当てる・置換先に長音を入れない**。
  「完全に消えた」とは言えない（GitHub の内部にしばらく残り・既存の clone/fork にも残る）。
- **⚠ docs に書くコミットハッシュは新しい履歴のもの**（09-22）。09-20 の履歴書き換えで
  **50種のうち43種が無効**になっていた。`.git/filter-repo/commit-map` は再クローンで消えるので、
  引くなら控えのバンドル（デスクトップ）を bare clone して**作者の日時 `%at` で突き合わせる**
  （同時刻の複数は題で解く）。書く前に `git cat-file -e <h>^{commit}`。
- **⚠ 【一覧】語彙 §2.1／§2.2 は手で写さず生成する**（手順は同 §5）。手書きの鏡は8日で
  5形式ぶん嘘になっていた（消えた形式を載せ、増えた形式が無く、列の型も古い）。
- **⚠ 実体を失った識別子は機械で洗える**——docs のバッククォート囲みの CamelCase を全ソースで
