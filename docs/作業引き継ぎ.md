## 直近のセッションでやったこと（実装・`origin/main` 反映済み）

本文の配信方式を変え、それに伴うセキュリティ対策を入れた。6コミットに分けてプッシュ済み：

- **`feat: 中間版CSPを全レスポンスへ付与`**: `auth.CSPProtect` を追加し、ハンドラチェーン最外周で
  全レスポンスにCSPを付与（[middleware.go](../internal/auth/middleware.go)・[main.go](../cmd/w-cms/main.go)）。
  `default-src`/`object-src`/`base-uri`/`frame-ancestors` は目標strictと同値。`script-src`/`style-src` のみ
  暫定で `'unsafe-inline'`。正本は [【考察】CSP強化.md](【考察】CSP強化.md)。
- **`feat: 本文の許可リスト方式サニタイザを追加`**: [sanitize.go](../internal/cms/sanitize.go) を新設
  （`Sanitize` / `SanitizeReport`）。冪等性を保証（エコーバックの収束条件）。
- **`refactor: 未使用のHTML一括取込エンドポイント /upload を削除`**: 呼び出し元が無く、認証さえ通れば
  任意HTMLを無検査で正本へ書き込める入口だった。`/api/upload-pdf` は別物で現存。
- **`feat: 保存時にサニタイズし結果をエディタへ返す`**: `SaveAPIHandler` がサニタイズ後の本文を保存し、
  応答に `html` と `sanitized` を返す。フロントはブロック離脱（`focusout`）でも保存し、除去が起きた
  ブロックだけ差し替えて通知する。あわせて `updateHtmlPreview()` の属性値・テキストをエスケープ
  （値に `"` を入れると生成HTMLが壊れ属性注入も成立していたため）。
- **`feat: index.htmlと本文をサーバーで合成して返す`**: `RootHandler` が本文とタイトルを埋め込んだ
  完成HTMLを返す（[shell.go](../internal/cms/shell.go)）。認可・404も画面の作法でサーバーが返す。
  初期表示の `/api/load` 呼び出しは撤去。
- **`fix: 同名の m-tag を複数置けるようにする`**: `page_tags` の主キー `(page_id, name)` を廃し
  非一意インデックスへ。同名タグ2つで保存が500になっていた不具合の解消。

**実装中に判明した要点**: 合成方式は本文を初期HTMLの一部としてパースするため、それまで安全側に
倒れていた（`DOMParser` 経由の挿入で `<script>` が実行されなかった）前提が崩れる。**合成と
サニタイズはセットでなければならない**。編集は必ずロック取得時の生HTMLから始まるため、
「閲覧＝サニタイズ済み／編集＝生」の非対称が成立する（正本を壊さない）。

（このセッションでは `docs/` 配下の通信記録処理の設計検討には触れていない。その内容は
[【考察】通信記録処理.md](【考察】通信記録処理.md) が正本のまま、下記「残課題」に引き続き残っている。）

## 現在の状態

- 上記6コミットを `origin/main` にプッシュ済み。`go build`・`go test ./...` 全パス。
- **通信記録の取り込みは未実装（設計のみ）**。実装に入る前に、[【考察】通信記録処理.md](【考察】通信記録処理.md) §11 の未決（特に下記）を詰める必要がある。
- 編集ロックは、本文保存に加え権限変更・所有者変更・親付け替え・公開切替まで `RequireEditLock`/`lockedFetch` で直列化済み。
- 親なし（トップレベル）にできるのはトップページ（`000000`）のみ。**匿名公開**は `public` フラグ＋パスゲートで運用中（owner/admin のみ・既定非公開）。アクセスは正規URL `/000000` に統一（`/` はリダイレクト）。
- 匿名ユーザーは実効公開ページで、本文の読み取り専用表示＋子ページ一覧＋親ページへのリンク＋目次まで見られる（右レールの属性・権限編集系は引き続き非表示）。
- ローカル検証ページが `data/` に残っている場合あり（git管理外・影響なし。「DB再構築」で整理可）。
- **カスタムタグはすべてプラグインが所有する**。`Plugin` の必須メソッド `Tags()` が語彙の唯一の
  正本で、サニタイズ許可リストと `/api/tag-schema`（エディタのシリアライザ）はそこから導かれる。
  コア（`sanitize.go`・`parser.go`）は `<m-*>` を一切知らず、コアテーブルは `pages`・`page_perms`
  だけ（`page_tags` も `plugin_page_tags.go` へ移設済み）。正本は
  [【一覧】カスタムタグ.md](【一覧】カスタムタグ.md) §1 と [【ガイド】プラグイン開発.md](【ガイド】プラグイン開発.md) §2。
- **`<m-file>` は純粋なファイル容器**（`src`/`name`/`ext`）。業務上の意味は中身の要素
  （`m-client-order`/`m-supplier-order`/`m-our-estimate`/`m-supplier-estimate`）が持ち、
  `tag` 文字列による分岐は全廃した。PDFのパスは `ClosestAttr` で容器から拾う。
  値を属性から中身へ移す転換（`m-field`/`m-table`）は §2.5 と合流させる予定で**未着手**。
- **`go test -race` が使える**（gcc 導入済み）。PATH に WinLibs の
  `~/AppData/Local/Microsoft/WinGet/Packages/BrechtSanders.WinLibs.POSIX.UCRT_*/mingw64/bin` を
  足し `CGO_ENABLED=1 go test -race ./...`。通常ビルドは Pure Go を保つため `CGO_ENABLED=0` のまま。
- **ページはサーバー合成方式**。`RootHandler` が `assets/index.html` の
  `<!--WCMS_CONTENT-->` へ本文を、`<title>` へページ名を埋め込んだ完成HTMLを返す
  （[shell.go](../internal/cms/shell.go) `RenderPageShell`）。初期表示で `/api/load` は叩かない
  （同APIは編集ロック起点の載せ替え専用として現存）。認可・404も画面側の作法でサーバーが返す
  （権限無し=403、匿名×非公開=`/login` へ302、不存在=404）。
- **本文サニタイズは保存時・描画時の二層で実施済み**（許可リスト方式。
  [internal/cms/sanitize.go](../internal/cms/sanitize.go)、正本は
  [本文サニタイズ設計.md](本文サニタイズ設計.md)）。保存時はサニタイズ結果をエディタへ返し、
  除去が起きたブロックだけ差し替えて通知する（エコーバック方式）。
  無検査で正本へ書き込めた未使用の `/upload` は削除済み。
- **CSP（Content-Security-Policy）は中間版を全レスポンスへ付与済み**（`auth.CSPProtect`。
  `default-src 'self'; object-src 'self'; base-uri 'self'; frame-ancestors 'self'` は目標strictと同値、
  `script-src`/`style-src` のみ暫定で `'unsafe-inline'`）。strict 版（`'unsafe-inline'` なし）への
  格上げは前提リファクタ待ち。正本は [【考察】CSP強化.md](【考察】CSP強化.md)。

## 開発環境の再現（自宅などで再開する手順）

```bash
# 1. 最新を取得
git pull

# 2. 依存取得
go mod tidy

# 3. 初回のみ管理者を作成して起動（ローカルHTTP検証なので Secure Cookie 無効）
#    ローカル開発の管理者は user=admin / password=Admin に統一する（環境間で揃える）。
WCMS_ADMIN_USER=admin WCMS_ADMIN_PASSWORD='Admin' WCMS_SECURE_COOKIES=0 \
  go run cmd/w-cms/main.go
# 2回目以降は環境変数なしで go run cmd/w-cms/main.go
# → http://localhost:8080 （/login にリダイレクト。admin / Admin でログイン）

# 4. テスト
go test ./...
```

注意:
- **ローカル開発のログイン**: `admin` / `Admin`（このパスワードは**ローカル検証専用**。本番では使わないこと）。
- `data/`（`cms.db` と `master/`、`auth.db`）は `.gitignore` 対象でコミットされない。**環境ごとに独立**するため、
  別環境（自宅など）では初回起動時に上記の環境変数で管理者が新規作成される。`auth.db` は同期されないので、
  「家でログインできない」は data/ が無い＝初回の管理者未作成か、別パスワードで作成済みのいずれか。
- **既存 `data/auth.db` のパスワードを忘れた／揃えたいとき**は、サーバーを止めてから以下で再設定できる（admin を `Admin` に）:
  ```bash
  # 一時パッケージで internal/auth.SetPassword を呼ぶ（ルートに別の package main があるためサブdirで実行）
  mkdir -p _resetpw && cat > _resetpw/main.go <<'GO'
  package main
  import ("fmt"; "w-cms/internal/auth"; "w-cms/internal/database")
  func main(){ database.InitAuthDB(); defer database.AuthDB.Close()
    if err:=auth.SetPassword("admin","Admin"); err!=nil { fmt.Println(err); return }
    fmt.Println("admin のパスワードを Admin に再設定しました") }
  GO
  go run ./_resetpw && rm -rf _resetpw
  ```
- ローカル実行・プレビュー用に `.claude/launch.json`（`go run` 起動設定）を用意済み。
  プレビュー（http://localhost）でCookieが付くよう **`env: { "WCMS_SECURE_COOKIES": "0" }`** を設定してある。

   親付け替えも本文保存と同じロックで直列化済み（共通ゲート `RequireEditLock`／フロント `lockedFetch`）。
