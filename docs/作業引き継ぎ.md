## 覚えておくこと（今回わかった実装の勘所）

- **テンプレート置き場は h1（ページ名）で決まる。これはバグではなく設計**——
  「表示されている言葉が機能を表します」というユーザーの方針です（2026-08-21・B-9）。
  サイドカー属性への昇格は取り消しました（上の取り消し節）。
  **ただし「トップ直下のページ名を『テンプレート』から変えると、配下が丸ごと②索引・③計算から
  出入りする（告知は出ない）」ことに変わりはありません**——直すべき欠陥ではなく、
  意図した挙動として受け入れた、ということです。
- **Gemini（明細AI解析）は有料枠のキーで運用する**——2026-08-21 決定。ユーザーの言葉は
  「GoogleやMicrosoftにはすでに書類が置いてあるので、大丈夫です。学習に使用されないという
  条件で使用しています」、追加確認に対し「有料枠で使います」。**無料枠では入力データが
  製品改善に使われる**ため、「学習に使わない」という前提は**課金が有効なキーであることが条件**です。
  コードは `GEMINI_API_KEY` を読んで `option.WithAPIKey` へ渡すだけ
  （[pdf_handler.go](../internal/cms/pdf_handler.go):212-223）で**枠は判定できません**。
  つまりこれは**運用側で守るしかない必須条件**です。
- **認可の読み口はサイドカー（正本）ではなく `cms.db`（派生）**。`GetPerms` も
  `EffectivePublic` の親チェーンも DB を読む。「正本と索引がズレたら**認可は索引に従う**」ので、
  `parent_id` の喪失はそのまま公開範囲の問題になる。
- **サニタイズ後にHTMLを足す関数が3つある**（`RenderComputedViews`・`RenderAnchors`・
  `RenderPageShell`）。それぞれ自前でエスケープ責任を負っており、規律が破れると保存型XSS。
- **本文DOMを走査する箇所は29ある**のに `.vocab-chrome` の明示除外は4つだけ。残りは
  「chromeが入れ子」「chromeが `data-type` を持たない」という**現時点の偶然**に依存している。
  レジストリへ `View: true` を1件足すと5箇所が一斉に誤爆する。
- **サニタイザは相対URLの `<img src>` を通す**。`/api/` への GET が状態を変えると保存型CSRFに
  なるので、**状態を変える経路は必ずメソッドを絞る**（`route_guard_test.go` が固定）。
- **プラグインテーブルにマイグレーションは無い**。`ApplySchema` は `CREATE TABLE IF NOT EXISTS`
  を流すだけなので、**列を足すと既存DBでは保存だけが 500 になる**。`f2458a9` で起動時の
  ずれ検出＋自動再構築（`DriftedSchemaTables`）を入れたので、以後スキーマを変えたら
  **起動時に1度だけ再構築が走る**（ログに出る）。
- **`csp_test.go` はポリシー文字列しか見ていない**（配線は見ない）。`CSPProtect` を外しても
  通る。配線の固定は `cmd/w-cms/route_guard_test.go` の `TestCSPIsWired`。
- **ルート表は `buildHandler()`**（`cmd/w-cms/main.go`）。main から切り出したのはテストのため。
- **E2E は `e2e/` へ移設済み**（OneDrive から）。`cd e2e && npm install` で使える。
  **OneDrive 側のファイルはまだ残してある**ので、こちらが正本と確認できたら消してよい。
