# 【考察】発注書のPDF発行

> **検討中・実装は着手直前**（2026-09-21）。⚠ **外部依存を1つ増やす判断**を含むので、
> 理由と代案を残します。
>
> 一言でいうと: **PDF発行は MUST。だから依存を1つ入れる。いちばんの難所はフォント。**

---

## 0. なぜ要るのか

ユーザー（2026-09-21）:

> **PDFを発行出来ることはMUSTです。** 発注書はPDFで送付し**7年保存**する必要があるそう
> です。PDFにするのは**改ざん防止**なんだそうです。

そして送り方も:

> ボタンを押したら印刷出来たいです。**メールで発注を増やしたい**ですが、**FAXで発注も
> 残っています**。メールに添付して送付やFAXサーバーで送信で来たいです。

⚠ **どの経路も「PDFという1つのファイル」を作れることが前提**です（印刷・メール添付・
FAX送信）。ブラウザの「PDFに保存」では**人の手が毎回挟まり、自動送信に繋がりません**。

### ⚠ ただし「PDFだから改ざんされない」ではありません

**PDF そのものは普通に編集できます。** 電子帳簿保存法が求めているのは（筆者の理解では）
**訂正・削除の履歴が残ること**／**事務処理規程を定めて運用すること**／**タイムスタンプ**の
いずれかで、**ファイル形式ではありません**。

⚠ **これは税理士に確かめてほしい**ことです（筆者の理解が古い・不正確かもしれません）。
もし「履歴が残ること」が要件なら——**w-cms は本文の版と監査記録を既に持っています**。

⚠ **PDFを作ること自体は要件として動きません**（相手へ送る形式として必要）。念のため。

**7年保存**は w-cms には素直です——**出したPDFを発注書ページの添付として残せば**、
ページごと残ります。

## 1. 依存を1つ増やす（ユーザー承認済み）

開発方針 §1② は外部依存の追加を原則禁じていますが、**例外条項**（「その他、
プロジェクト内で事前に承認された重大なライブラリ」）に当たります。SQLiteドライバ・
argon2id・`x/net/html` と同じ扱いです。⚠ **承認は 2026-09-21 にユーザーから**。

### 選んだもの: `github.com/signintech/gopdf`

| 比べたもの | 判断 |
|---|---|
| **`signintech/gopdf`** ← 採用 | **MIT**・依存1つ（`gofpdi`）・**2026-09-12 更新**・⚠ **TTF埋め込みが本業**（作者が日本語のために作った） |
| `jung-kurt/gofpdf` | ⚠ **作者が開発終了を宣言**（後継が `go-pdf/fpdf`） |
| `go-pdf/fpdf` | 生きているが、**日本語の埋め込みに一手間**かかる |

⚠ **日本語が要件の中心**なので `gopdf` が素直です。

## 2. ⚠ いちばんの難所はフォント

**日本語のPDFはフォントを埋め込まないと読めません。** そして**どのフォントを同梱できるか**が
ライセンスの問題になります——**w-cms は MIT で公開**されており、世界中の誰かが使う前提です。

### 実測（2026-09-21）

| フォント | 結果 |
|---|---|
| `NotoSansJP-VF.ttf` | ✓ **通りました**（⚠ 可変フォントだが読めた） |
| `meiryo.ttc` / `msgothic.ttc` | ✗ **読めません**——⚠ **`.ttc` はコレクション形式**で、gopdf は単体TTFしか受けません |

⚠ **「エラーが出なかった＝正しく出た」ではありません。** 作ったPDFの `ToUnicode` を
読み返して、**`発注書　株式会社みなと商店　御中　鉄STPG370EG φ27.2` が一字一句戻る**ことを
確かめています。**中身で確かめること**（2026-09-21 朝に印刷で同じ失敗をしたばかり）。

### Noto Sans JP は **SIL Open Font License**（フォント自身の `name` 表から確認）

⚠ **同梱して再配布できます**。ただし **9.2MB**——リポジトリに入れると小さくない重さです。

### ⚠ 未決: 同梱するか、設定で指すか

| 案 | 良い点 | ⚠ 代償 |
|---|---|---|
| **A: 同梱**（`assets/fonts/`） | どの環境でもそのまま動く | ⚠ リポジトリが **9.2MB** 増える |
| **B: 設定で指す**（`pdf_font`） | 重くならない | ⚠ **設定しないとPDFが出ない**（Gemini キーと同じ形の「設定待ち」） |
| **C: 両方**（既定は同梱・設定で差し替え可） | 運用者が社名ロゴ入りの書体に替えられる | 実装が少し増える |

**筆者の推しは B → 必要になったら A へ。** ⚠ 理由は、**いま同梱しても職場と自宅の2台には
既に Windows のフォントがある**ので、9.2MB を払う相手がまだ居ないからです。
⚠ **他社へ配るときには A が要ります**——そのときに入れれば間に合います。

⚠ **設定にするなら、無いときの断り方はGeminiキーと同じ形**にすること
（「サーバーに ◯◯ が設定されていません」と画面に出し、**起動は止めない**）。

## 3. 作るもの（順番）

1. **発注書ページ**（`自社の発注書`・明細は実物7枚に合わせた1形式 ← `ec1e2cd` で済み）
2. **PDFにする口**——ページからPDFを作り、**添付として同じページへ保存**する
   （⚠ 7年保存がこれで済む。ファイルはページと一緒に残る）
3. **印刷**——⚠ **PDFがあれば印刷は「そのPDFを開く」で済みます**。受注残表で作った
   `@media print` の仕掛けは**画面の表**のためのもので、**発注書は紙の体裁が要る**ので
   PDF側で組むほうが素直です。
4. **メール添付**——w-cms は SMTP を持っているので、**2でできたPDFを添付するだけ**。
5. **FAX** ——⚠ **FAXサーバーが動いてから**（機械は購入済み・未稼働）。送るのは
   PDFか画像なので、2ができていれば繋がります。

⚠ **2がすべての前提**です。3〜5は2の上に乗るだけなので、**2を先に、確かめてから**。

---

## 4. ⚠ 罠（先に書いておく）

- ⚠ **`.ttc` は読めません**（Windows の meiryo・msgothic はこれ）。設定で指させるなら、
  **`.ttf` だけ受ける**と断ること——`.ttc` を指されて「読めません」だけ出ると理由が分かりません。
- ⚠ **可変フォント（VF）は通りましたが、太さは選べていません**。太字が要るなら、
  **別のフォントファイル**を指すことになります（`gopdf` は `SetFont` の style で太さを
  選べますが、VFの軸を動かす機能はありません）。
- ⚠ **金額の桁区切りと右寄せ**は自分で組むことになります（実物は `122,580` のように
  区切っています）。`gopdf` に表を組む機能はありません——**線と文字を自分で置きます**。
- ⚠ **発注書No. の採番**が要ります。実物は `44`・`33`・`87` のような連番でした。
  ⚠ **ページIDで代用しない**こと——相手に渡す番号なので、**欠番や飛びが説明できる**必要が
  あります（ページIDは他の用途で飛びます）。
