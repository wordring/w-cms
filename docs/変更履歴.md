# 変更履歴

過去に実施した大きな改修・ドキュメント整備の記録です。現行の仕様は各仕様書（`コンセプト.md`, `アーキテクチャとDBスキーマ.md`, `エディタ仕様.md` 等）を参照してください。本ファイルは「いつ・何を・なぜ変えたか」の経緯のみを記録します。

---

## ドキュメント構成の整理（旧 `実装計画.md`）

`docs/コンセプト.md` が思想と技術仕様を兼ねて肥大化したため、役割ごとに分割した。
*   `docs/アーキテクチャとDBスキーマ.md` を新規作成し、DBスキーマ構造・Sync処理・API仕様を移管。
*   `docs/エディタ仕様.md` を新規作成し、Notion風ブロックエディタ（ドラッグ&ドロップ、スラッシュコマンド、コンテキストツールバー等）のDOM構造とイベント仕様を移管。
*   `docs/コンセプト.md` は「自由なファイルベース保存とタグによる意味付け」という設計思想のみに絞った。

## 発注書への部品ネストおよび進捗管理の導入（旧 `実装完了報告.md` セクション1）

*   ユースケース仕様書 `docs/ユースケース_原価と利益.md` と `docs/ユースケース_受注と進捗管理.md` を新規作成。
*   データベースの `client_orders` / `our_orders` をヘッダ・明細（Items）の親子テーブルに分割。
*   HTMLパーサー・同期処理を改修し、`<m-file>` 内にネストされた `<m-item>` 群をトラバース抽出してトランザクション内でDB同期するように変更。
*   保存ファイル名を `index.html` ではなく、ページIDを用いた `[page_id].html`（例: `000000.html`）に変更。

## Web Components テンプレートの外部ファイル化（旧 `実装完了報告.md` セクション2）

JavaScript内にハードコードされていたWeb ComponentsのHTMLデザインを、`assets/templates/` 配下の個別HTMLファイルへ分離した。仕組みの詳細は `docs/エディタ仕様.md` の「8. Web Components のテンプレート外部化」を参照。

*   閲覧用（`view`）・編集用（`edit`）のテンプレートファイルを新規作成。
*   `assets/web-components.js` に非同期テンプレートローダー `fetchTemplate(name)` とキャッシュ機構（`templateCache`）を追加し、各コンポーネントの `render()` を `async/await` 化。

**検証結果**: `go test ./...` で既存のバックエンドテストが全てパスすることを確認。ブラウザでの閲覧・編集モード切り替え、部品の追加・削除、HTMLリアルタイムシリアライズの動作も手動確認済み。
