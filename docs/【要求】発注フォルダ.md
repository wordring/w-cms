# 【要求】発注フォルダ

## 発注フォルダページ

### 発注フォルダページの項目
- 必要部材
- 未発注の発注書
- 発注部材表

各項目には見出しを付けて、ハッキリとセクションを分けましょう。

納期は予定や希望、納品日は確定した期日です。

その必要部材を表にして表示します。

## 発注書ページ

発注フォルダ/年フォルダ/月フォルダ/発注書ページ というように、「発注部材表」から「発注書ページ」が作られます。

発注書ページのタイトルは、「発注　ミライ商事」と言ったような形になります。

その下にのブロックに「発注書番号」「仕入先」「発注日」「発注担当」「納品日」といったタグが並びます。
タグはDBに入るので検索できるようになります。

その下のブロックに「発注明細」表があります。
表の下に「PDF作成」ボタンがあります。

その下のブロックに発注書PDFを表示するブロックがあります。
このブロックは折り畳めます。

その下のブロックに発注書を送信するためのブロックがあります。
メール/FAX/その他を選んで「送る」ボタンを押すと、それぞれの選択に合わせたブロックが下に表示されます。
たとえばメールならメールを書くブロック、FAXなら連絡先の選択などです。
連絡帳から連絡先を選択する方法はまた練りましょう。

自社担当者の署名は、担当者の連絡帳に在るので、それをコピーします。

### タグ

タグは次のとおりです。

| タグ | 型 | 実装 | 備考 |
|---|---|---|---|
| 発注書番号 | code | あり | **発注書番号はページ番号と同じです** |
| 仕入先 | text | あり | 連絡帳にある組織または個人 |
| 発注日 | date | あり | 発注書を送信した日付 |
| 発注担当 | ref | あり | 連絡帳の担当者ページ。 |
| 納期 | text |  | 納品予定日 |
| 納品場所 | text |  |  |

納期がtext型なのは、「最短納期」のような文字列の場合があるからです。一般的にはdate型で記入されます。

### 発注明細

部材の種類によって発注明細に必要な項目は変わりますが、表はすべての項目の集合となります。
PDFを作成するときに空の項目を消すことで、部材の種類にあった発注書PDFが作成されます。

### 発注済の印

**印は発注書の行ごと**に付きます（`状態` の列）。値は4つ:

| 値 | 意味 | 手配済みに数える | 買った値段に数える |
|---|---|:--:|:--:|
| 未発注 | 紙はできたが、まだ出していない | ○ | |
| 発注済 | 出した（メール・FAX・手渡し） | ○ | ○ |
| 納品済 | 届いた | ○ | ○ |
| 取消 | 取り消した | | |

- **ページの印にしないのは、1枚の紙の中でも行ごとに事情が違うから**です
  ——1品だけ取り消す、1品だけ先に納まる。
- **取り消すと、その部材は必要部材の表へ戻ります**（手配済みに数えないため）。
- 取消の重さは2通り。**発注前は単純に取り消し**、**発注後は相手の了解が要る**ので画面が確かめます。
### ページの `発注済` をどうするか（2026-09-23）

> ユーザー:「ページに発注済みタグを持つと**検索が楽になる**と思いますが、
> **発注後でも発注を取り消す場合がある**ので、その場合どうするかです。」

⚠ **困りごとは正確です。** 人が手で打つタグにすると:

```
タグ「発注済」を付ける  →  あとで1行だけ取り消す
                              ↓
                    行は「取消」、タグは「発注済」のまま
                    ⚠ タグが嘘をつく。しかも誰も気づかない
```

**筆者の案: ⚠ 本文には書かず、索引にだけ「導いたタグ」として入れる。**

| | どこに在るか | 誰が書くか | 取り消したら |
|---|---|---|---|
| 行の `状態` | **本文**（正本） | 人・機械 | 変わる |
| ページの `発注済` | ⚠ **索引だけ**（`page_tags`） | ⚠ **保存のたび機械が数え直す** | **自動で変わる** |

- **検索は楽になります**——タグなので `PagesByTag` で引けます。
- ⚠ **嘘をつけません。** 本文が変われば保存時に必ず数え直され、DB再構築でも同じ値が出ます。
- ⚠ **「DBにはファイルから再生成できないデータを持たせない」に違反しません**
  ——**本文から計算できる**ので、再構築で復元できます
  （[【要求】運用.md](【要求】運用.md) §1）。
- ⚠ **人は打てません。** 打てると二重持ちに戻るので、**編集画面には出しません**。

⚠ **「未発注の発注書」の節で、既に `bool` を選んでおられます**——
「DBを検索して**『発注済』タグがFALSE**の発注書ページが該当します」。
**それでよければ、値は `bool`（真／偽）です。**

⚠ **残るのは、`bool` では表せない2つをどう扱うかです:**

| 紙の状態 | `発注済` は？ |
|---|---|
| 全部まだ出していない | **偽** ✓ |
| 全部出した | **真** ✓ |
| ⚠ **一部だけ出した** | ⚠ **真か偽か**——偽にすると「未発注の発注書」に**出したものが並びます** |
| ⚠ **全部取り消した** | ⚠ **真でも偽でもありません**——偽にすると、**もう用のない紙が作業一覧に残り続けます** |

⚠ **「一部だけ出した」は実際に起こります**——行ごとに印を付けられる作りにしたからです
（1品だけ先に納まる・1品だけ取り消す）。

**3値にすれば両方とも表せます**（`未発注` / `一部発注済` / `発注済`、取消だけの紙は `取消`）。
⚠ **ただし `bool` ではなくなります。** どちらを採るか決めてください。

## 発注書（紙・PDF）

**PDFを発行できることは必須**です。発注書はPDFで送付し、**保存します**。

保持年限は**設置した先で変わります**（2026-09-23 ユーザー:「個人が5年、法人が7年です。
**企業が過去に問題を起こしていた場合、最大10年**です」）——正本は
[【要求】ページとエディタ.md](【要求】ページとエディタ.md) §4。
⚠ **この会社は法人なので 7年**です。
⚠ **2026-09-23 に、版を消す機構ごと撤去しました**——**版は消えません**。
（⚠ ただし**発注書のPDFは添付なので消えません**。消える恐れがあるのは本文の版です。）

実物7枚（`w-cms用見本`）と、いま w-cms が出す紙を比べて出た差です。

| | 実物 | いまの w-cms |
|---|---|---|
| 差出人ブロック（社名・部署・住所・担当・TEL・FAX） | 右上にある | `発注担当` の署名から出す。⚠ **連絡帳に署名が無いと空** |
| 合計金額（税抜） | **表の上と下の2箇所** | ⚠ **下だけ** |
| 希望納期 | **自由文**（「急ぎでお願いします」「納期わかりましたらお知らせください。」） | ⚠ `予定納期` は**日付型**なので、**この書き方が入りません**——自由文の欄を別に足すか、備考へ寄せるかの判断が要ります |
| 納品場所 | 全7枚にある | ⚠ **書いていません** |
| 明細のグループ見出し行 | **装置名だけの行**（`装置A用`・`共通台座用`）が明細に挟まる | ⚠ **ありません** |
| 「下記の通り、発注いたします。」 | ある | ⚠ ありません |
| 発注書No. | **全7枚とも空欄** | ページ番号が入る |

⚠ **複数枚になる発注書**（2026-09-23 ユーザー:「複数ページのPDFにすればよいと思いますが、
発注書番号はどうすべきか」）——考察は [【考察】発注書のPDF発行.md](【考察】発注書のPDF発行.md) §6。
筆者の答えは **番号は1つ・PDFは1本・ページは1枚のまま**で、変えるのは**2枚目以降の紙に刷るもの**
（発注書番号・`n / N`・宛名・「次頁へ続く」）。⚠ **いまは2枚目以降に番号も宛名も無い**。
⚠ **実物7枚はすべて1枚もの**——複数枚の実物を見てから細部を決める。

⚠ **字はFAXで読める大きさにします。** G3 FAX の標準モードは**縦 98dpi しかなく**、
9pt の和文は画数の多い漢字（`鋼`・`鍍`・`厚`）が塗り潰れます。
いまは**中身を測って、入る中でいちばん大きい字**（最大12pt）で組み、入らなければ
**字を下げる前に折り返し**ます。⚠ **実機のFAXではまだ確かめていません。**

## 発注書を送る

発注書ページで**送信方法を選んで**送ります。

| 方法 | 送り方 | 発注済みの印 |
|---|---|---|
| メール | 宛先・件名・本文を確かめて送信（PDFを添付） | **自動**（送信の成功がその事実） |
| FAX | ⚠ **FAXサーバーはまだありません**——当面は人が送って、押します | **人が押す** |
| 手渡し・郵送 | 印刷して渡す | **人が押す** |

- 宛先は `仕入先` の題で連絡帳を引いた**候補**です。⚠ **当たらないことが正常**
  （新しい仕入先の1通目）なので、そのときは黙らずにそう言って、人が打ちます。
- メールの控えは**通信箱**に残ります。
- ⚠ **将来要件: 作ったPDFをワンタッチで業者へFAXする。** FAX＋APサーバー用の機械は
  2026-09-17 に購入済み（モデムは未購入）。同じ機械にモデムを繋ぎ、通信記録とも接続します。
