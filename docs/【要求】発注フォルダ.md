# 【要求】発注フォルダ

## 発注フォルダページ

### 発注フォルダページの項目
- 必要部材
- 未発注の発注書
- 発注部材表

各項目には見出しを付けて、ハッキリとセクションを分けましょう。

納期は予定や希望、納品日は確定した期日です。

### 必要部材表
DBから受注残を調べて、受注残部品の弊社品番と一致するページIDに基づき、部材DBから必要部材を集積します。
その必要部材を表にして表示します。

必要部材表
| 選 | 納期 | 客先 | 装置 | 弊社品番 | 購入品 | 残 | 参考単価 |
|--|--|--|--|--|--|--|--|
||2026-10-15|みなと商店|オールラウンド|000080|鉄 FB t4.5*75*1090|2|860円|

- 選のセルにはチェックボックスが入ります。

表の下には、発注部材表を作るため項があります。
チェックした部材をどの表に入れるか設定するためのリストボックスと発注部材表に入れるボタンがあります。
リストボックスには、新しく作る「新規」とN番目の発注部材表に追加することを示す「N番目に追加」という項目があります。
「N番目に追加」は既存の発注部材表の数だけ項目が出来ます。
ボタンを押すと「新規」なら発注部材表ができ、「N番目に追加」ならN番目の発注部材表にチェックした部材が追加されます。
発注部材表に入った部材は必要部材表から消えます。

各発注部材表の下には発注書ページを作るためのボタンがあります。
- 差出人、仕入れ先、発注日（入力しなければ現在の日付）、納期（入力しなければ空欄）を入力する欄があります。
- その下に「発注書ページを作る」ボタンがあります。

### 未発注の発注書

ここには未だ発注されていない発注書ページへのリンクを表示します。
DBから「未発注の発注書」を探します。
作業者はここを見て残りの作業を進めます。
発注書ページを削除するとリンクも消えます。

## 発注書ページ

発注フォルダ/年フォルダ/月フォルダ/発注書ページ というように、「発注部材表」から「発注書ページ」が作られます。

発注書ページのタイトルは、「発注　ミライ商事」と言ったような形になります。

その下にのブロックに「発注書番号」「仕入先」「発注日」「発注担当」「納品日」といったタグが並びます。
タグはDBに入るので検索できるようになります。

その下のブロックに「発注明細」表があります。
その下のブロックに「備考」入力欄があります。備考欄は複数行書けます。
その下に「PDF作成」ボタンがあります。

その下のブロックに発注書PDFを表示するブロックがあります。
このブロックは折り畳めます。

その下のブロックに発注書を送信するためのブロックがあります。
メール/FAXなど送付方法を選んで「送る」ボタンを押すと、それぞれの選択に合わせたブロックが下に表示されます。
たとえばメールならメールを書くブロック、FAXなら連絡先の選択などです。
連絡帳から連絡先を選択する方法はまた練りましょう。

自社担当者の署名は、担当者の連絡帳に在るので、それをコピーします。

### タグ

タグは次のとおりです。

| タグ | 型 | 実装 | 備考 |
|---|---|---|---|
| 発注書番号 | code | あり | **発注書番号はページ番号と同じです** |
| 仕入先 | text | あり | 連絡帳にある組織または個人 |
| 発注日 | date | あり | 発注書を送信した日付 |
| 発注担当 | ref | あり | 連絡帳の担当者ページ。 |
| 納期 | text |  | 納品予定日 |
| 納品場所 | text |  |  |

納期がtext型なのは、「最短納期」のような文字列の場合があるからです。一般的にはdate型で記入されます。

### 発注明細

部材の種類によって発注明細に必要な項目は変わりますが、表はすべての項目の集合となります。
PDFを作成するときに空の項目を消すことで、部材の種類にあった発注書PDFが作成されます。

発注明細表
| 列 | 型 | 材料 | 加工 | 塗装 | 鍍金 |
|---|---|:--:|:--:|:--:|:--:|
| 弊社品番 | ref | ○ | ○ | ○ | ○ |
| 品番 | code | | ○ | ○ | ○ |
| 品名 | text | | ○ | ○ | ○ |
| 材質 | text | ○ | | | |
| 形状 | text | ○ | | | |
| 寸法 | text | ○ | | | |
| 表面 | text | | | ○ | ○ |
| 数量 | number | ○ | ○ | ○ | ○ |
| 単位 | enum | ○ | ○ | ○ | ○ |
| 単価 | number | ○ | ○ | ○ | ○ |
| 備考 | text | ○ | ○ | ○ | ○ |
| 状態 | enum | ○ | ○ | ○ | ○ |

- **材料の行に `品名` は書きません**。材料に単独の名前は無く、**材質・形状・寸法の3つで決まります**
  ——書くと同じことが紙の上で2回言われ、直すときに食い違います。⚠ **購入部品は逆**で、
  **品名が同一性そのもの**なので残します。
- **`弊社品番` は紙に出しません**。相手には意味が無く、**こちらが問い合わせを受けたときに引く番号**です。
- **行の `備考` は、他社が知る必要のないもの**です。**未来の自分に向けたメモ欄**で（直した理由・注意など）、
  だから紙にもメールにも出しません。相手に伝えたいことは、表の下の**備考欄**に書きます。
- **`表面`** には色（`緑`、`半ツヤ黒`）・鍍金（`三価ユニクロ、タコメッキ`）・`生地` が入ります。
- **単価を書かない発注書があります**（実物の材料2枚は単価も合計も空欄）。
  ⚠ **`0` とは別**です——紙の `0` は「0円で発注した」の意味なので、**空欄のまま**にします。

- 「状態」の値は「未発注」「発注済」「納品済」「取消」のいずれかです。
  「取消」の場合、発注書には載りませんが、発注フォルダの必要部材表に戻ることもありません。
  発注書の送付後でさえ、「状態」が取り消しになる場合があります。

- 「状態」列すべての値に「未発注」が無い場合、そのページは「発注済の発注書」と言います。
  それ以外の場合は、そのページは「未発注の発注書」と言います。

- 行の末尾には、「必要部材表」へ戻すボタンがあります。このボタンは編集モードでは消えます。
  ボタンを押すと、発注明細表から行が消え、必要部材表へ戻ります。
  発注書の送付後でも押せます（再送の前に行を外すため）。

- 発注書送付後に、取り消しや戻す操作を行って仕入れ先に修正した発注書を再送したい場合があります。
  幸い本システムはメモを自由に書けますから、修正した理由などを残すことが出来ます。
  そこで、発注済みの状態であっても、発注書PDFの作成は可能とします。
  新しい発注書を送付した場合は、古い発注書のデータをDBから取り除き、新しい発注書のデータをDBに登録します。

- 「未発注の発注書」を探すには、発注明細表のDBから状態が「未発注」の行の集合を作り、その集合が持つページIDの集合を抽出します。

- 表の下には「PDF作成」ボタンのブロックがあります。
  PDFを作成すると「発注書表示」ブロックに表示されます。
  送付前は、このボタンを押すたびに、古いPDFを上書きして、表を基に新しいPDFが作成されます。
  送付後も、ボタンは表示されます（再送のため。下の「発注書の再送とキャンセル」）。

#### 発注書の再送とキャンセル

発注書は、一度送った後でも**編集して再送する**場合があります。
また、**発注書そのものをキャンセルする**場合もあります。

##### 再送（差し替え）

再送するときは、仕入先に**古い発注書を破棄してもらい、新しい発注書に取り換えてもらいます**。
一部だけ直した紙を追加で送るより、1枚にまとめて差し替えたほうが問題が起きにくいからです。

- **発注書番号は変えません。** 同じ注文の差し替えだからです。
- 新しい紙には、**差し替えであること**が分かるように
  「**訂正版**（2026-09-24 送付分を破棄し、本書に差し替えてください）」と備考欄に書きます。
  - 再送のメール本文にも、同じ依頼（古い発注書の破棄）を書きます。
- **古いPDFは消しません。** 送った紙は、送った事実として保存します。
  発注書ページに表示するのは**最新のPDF**で、古いPDFと発信FAX、メール等は現行PDFブロックの下にリンクとして表示します。。
- 修正した理由は、発注書ページにメモとして書けます。
- 再送すると `発注日` は**再送した日**に書き換わります（送信したときに書き換える規則のため）。
  月をまたいで再送すると、置き場（`発注／年／月`＝作った月）と `発注日` がずれますが、ずれて構いません。
- **訂正版の紙は、前の紙との違いを書きません。**
  - どの行を直したかを行の備考や印で示すことはしません。
  - 取り消した行は、訂正版の紙には載りません（取消の行は刷らない規則のまま）。「取り消しました」とも書きません。
  - 前の紙との対応は、上のリンク（古いPDF・送ったメールやFAX）で辿れれば十分です。
- 紙は「**これから相手にしてもらうこと**」だけを正しく書きます——過去の経緯ではなく、未来のほうに気を配ります。
- 行の「状態」: 再送した行は「発注済」になります。
  再送の前に新しく足した行は「未発注」なので、その間、ページは「未発注の発注書」として一覧に出ます。

#### キャンセル（発注書ごと）

発注書そのものをやめるときは、**すべての行の「状態」を「取消」にします**。

- 送付後のキャンセルは、仕入先の了解が要ります（電話などで依頼し、OKが出てから取消にする。行ごとの取消と同じ）。
- 「取消」は「その部材はもう発注しない」という意味なので、部材は必要部材表に**戻りません**。
  別の仕入先に発注し直すなどで戻したい行は、先に「必要部材表」へ戻すボタンを押します。
- 発注書ページは**消しません**。発注してキャンセルした記録として残します。
- すべての行が「取消」のページは、「未発注の発注書」には出ません（「未発注」の行が無いため）。

### 発注書PDF表示

このブロックには発注書PDFが埋め込み表示されます。このブロックは折り畳むことが出来ます。


#### 発注書PDF

**PDFを発行できることは必須**です。発注書はPDFで送付し、**保存します**。

一般的な発注書のマナーで製造します。
- 一番上に「発注書」と太字でセンターリングして書きます。
- その下の左の項は宛先ブロックです。「宛先企業の名前　御中」と書き、その下に一行あけて「発注書番号」改行「発注日」改行「納期」を書きます。
- その右の項は差出人ブロックです。弊社と担当者の署名を入れます。
- その下の全幅は発注品の表です。
- その下は備考欄です。

差出人ブロックには社名・部署・住所・担当・TEL・FAXが入ります。
合計金額は表の下に表示します。

- 発注書は一枚一社です。

**明細が1枚に収まらないときは、複数ページのPDFにします。** 発注書ページ・発注書番号・
PDFファイルは**1つのまま**です——枚数は紙の都合で、注文の同一性ではありません。

- **発注書番号は1つ**。紙ごとの枝番（`000138-1`）は付けません。
- **PDFは1本**。紙ごとに分けません（送り忘れ・保存の単位が割れるため）。
- **合計金額は最後の紙に1回**。途中の紙に小計は出しません。
- **明細行は紙の区切りで割りません。**
- **2枚目以降の紙にも刷るもの**: 発注書番号・宛名（御中）・**何枚目／全何枚**（`n / N`）・
  表の見出し。最後以外の紙の足元に「次頁へ続く」。差出人は1枚目だけでよい。

⚠ **いま**: 改ページはします（2026-09-23）が、2枚目以降に刷り直すのは**表の見出しだけ**で、
**発注書番号・宛名・`n / N` が無い**。FAX は紙が1枚ずつ届くので、その紙がどの注文の
何枚目か相手に分かりません。⚠ **実物7枚はすべて1枚もの**——複数枚の実物はまだ無いので、
差出人を2枚目にも要るかなどの細部は、実物が出てから決めます。
考察は [【考察】発注書のPDF発行.md](【考察】発注書のPDF発行.md) §6。

⚠ **字はFAXで読める大きさにします。** G3 FAX の標準モードは**縦 98dpi しかなく**、
9pt の和文は画数の多い漢字（`鋼`・`鍍`・`厚`）が塗り潰れます。
いまは**中身を測って、入る中でいちばん大きい字**（最大12pt）で組み、入らなければ
**字を下げる前に折り返し**ます。⚠ **実機のFAXではまだ確かめていません。**

### 発注書を送信

発注書ページで**送信方法を選んで**送ります。
送るPDFは、発注書ページに表示している**最新のPDF**です（送る直前に作り直しません）。

| 方法 | 送り方 | 発注済みの印 |
|---|---|---|
| メール | 宛先・件名・本文を確かめて送信（PDFを添付） | **自動**（送信の成功がその事実） |
| FAX | ⚠ **FAXサーバーはまだありません**——当面は人が送って、押します | **人が押す** |
| 手渡し・郵送 | 印刷して渡す | **人が押す** |

- 宛先は `仕入先` の題で連絡帳を引いた**候補**です。⚠ **当たらないことが正常**
  （新しい仕入先の1通目）なので、そのときは黙らずにそう言って、人が打ちます。
- メールの控えは**通信箱**に残ります。
- ⚠ **将来要件: 作ったPDFをワンタッチで業者へFAXする。** FAX＋APサーバー用の機械は
  2026-09-17 に購入済み（モデムは未購入）。同じ機械にモデムを繋ぎ、通信記録とも接続します。
