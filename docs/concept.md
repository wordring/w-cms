# w-cms ソフトウェアコンセプト・設計仕様書

このドキュメントでは、**w-cms** の基本コンセプトである「HTMLファイルとデータベースの双方向連携」および、具体的なユースケース（部材価格の推移管理など）の仕様について定義します。

---

## 1. コア・コンセプト：双方向データ連携

w-cms は、単なる静的ファイルの保存システムではなく、**「HTMLファイル（ドキュメント）」と「関係性データベース（SQLite）」が双方向でデータをやり取りするシステム**です。

```mermaid
graph LR
    HTML[アップロードされたHTML<br>例: 発注書/納品書] -- 1. 解析・登録 (Extract) --> DB[(SQLite DB)]
    DB -- 2. 過去の記録を呼び出し (Load) --> Page[部材詳細ページなど]
```

### ① インプット（ファイルからDBへ）
アップロードされたHTML（発注書、納品書など）の記述内容をパースし、データベースへ構造化データとして登録します。
*   **例**: 発注書HTML内の部材名、単価、数量、発注日を自動抽出し、DBの取引履歴テーブルにインサートします。

### ② アウトプット（DBからファイル・画面へ）
特定の詳細ページ（部材の紹介ページなど）を表示・生成する際に、データベースから関連する過去の履歴データを動的に読み出して、ページ内にレンダリングします。
*   **例**: 「ボルトA」のページを開いた際、DBから過去の発注履歴（価格の推移）を呼び出し、価格推移グラフや履歴リストとして埋め込み表示します。

---

## 2. 具体的なユースケース：部材の価格推移管理

### シナリオ
会社と自宅で共通のデータベースを使い、仕入れた部材の価格推移を自動でトラッキングします。

```text
【ステップ 1：データの蓄積（発注書・納品書の登録）】
  「A社からの納品書.html」をアップロード
  ↓
  HTML内のタグ（例: <m-item name="ボルトA" price="120" date="2026-06-18">）を解析
  ↓
  DBの `price_history` テーブルに「2026-06-18: ボルトA = 120円」として記録

【ステップ 2：データの可視化（部材ページでの確認）】
  「ボルトAの紹介ページ」を開く（または自動生成する）
  ↓
  システムがDBから「ボルトA」の過去の価格履歴を全件取得
  ↓
  ページ内に「120円(2026-06-18) ← 115円(2026-05-10) ← 110円(2026-04-01)」のように価格推移を出力
```

## 3. 実装に向けたデータモデル設計（案）

このユースケースを実現するために、今後拡張が想定されるデータベーステーブルの構造案です。

### ① `items` テーブル（部材マスタ）
部材の基本情報を管理します。
*   `id` (TEXT, PRIMARY KEY): 部材コード
*   `name` (TEXT): 部材名
*   `spec` (TEXT): 仕様・規格

### ② `price_history` テーブル（価格履歴）
発注書や納品書から抽出された価格データを蓄積します。
*   `id` (INTEGER, PRIMARY KEY AUTOINCREMENT)
*   `item_id` (TEXT, FOREIGN KEY): 部材ID
*   `price` (INTEGER): 単価
*   `source_page_id` (TEXT, FOREIGN KEY): 抽出元となったHTMLファイル（pagesテーブル）のID
*   `recorded_at` (DATE): 発注日・納品日

## 4. 今後の開発ロードマップ

上記のコンセプトを実現するために必要な機能拡張ステップです。

1.  **HTML解析機能（parser.go）の拡張**:
    *   HTMLファイルから部材名や価格情報（カスタムタグや特定のクラス・構造）を抽出できるようにパーサーを強化。
2.  **データベース（sqlite.go）の拡張**:
    *   上記の `items` や `price_history` テーブルを初期化処理に追加。
3.  **データ同期ロジック（sync.go）の拡張**:
    *   HTMLアップロード時に、メタデータだけでなく価格履歴データも抽出して `price_history` に登録する処理を追加。
4.  **動的描画機能（handler.go / テンプレート）の拡張**:
    *   部材ページを表示する際、過去の価格推移をDBから取得し、HTMLテンプレートに流し込んで描画する処理を実装。
