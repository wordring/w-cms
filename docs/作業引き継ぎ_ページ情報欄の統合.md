## このタスクの目的（一言で）

エディタ画面で**親ページIDの入力欄が2か所**ある状態を解消し、ページの属性（ページID・親ページID・作成日時・更新日時・作成者）を **文書先頭の `<m-page-info>` ブロック1か所に集約**する。あわせて画面を3層構成に再編し、HTML/CSSをモダン化する。

## 確定済みの決定（議論の結論）

1. ページ情報は **HTMLファイルに永続化**する（DBは派生インデックスで、DB再構築時に `updated_at` が「今」で上書きされ消えるため。`internal/cms/sync.go:60` 参照）。
2. 作成日時・作成者は **HTML本文**（`<m-page-info>` の属性）に記録する。
3. **書き込み主体を分離**:
   - ユーザー編集 = 親ページID
   - サーバーのみ = 作成日時・作成者（生成時1回）・更新日時（保存毎）。`SaveAPIHandler` がクライアント値を無視しサーバー値で上書き（改竄防止）。
4. **ページIDはHTMLに冗長コピーしない**。表示は常にURL/DBを正とする。
5. 画面は **3層構成**:
   - ヘッダー（クローム: タイトル・モード切替・権限・管理・ログアウト）— 保存対象外
   - **ページ操作バー（新設・ヘッダと文書の間）**: ＋子ページを作成 等のアクション — 保存対象外
   - 文書（`<m-page-info>` パネル＋本文）— HTMLに保存
6. 既存ヘッダーの簡易表示（`display-page-id` + `parent-id-input` の行）は**廃止**。
7. 親ページIDは既存の `<m-tag name="親ページID">` 方式を維持し、`<m-page-info>` に内包する（同期機構をそのまま流用）。
8. `<m-page-info>` の**表示レイアウト詳細は後回し**。当面は項目を並べただけの**仮レイアウト**で進める。
9. HTML/CSSモダン化（セマンティックタグ化・CSS変数導入・インラインstyle削減）を**別コミット**で実施。

## 実装ステップ（各ステップ別コミット推奨）

1. **DBスキーマ＋同期**: `pages` に `created_at` / `created_by` 追加（`internal/database/sqlite.go:45-51`）。`SyncIndex` / `RebuildDatabase`（`internal/cms/sync.go`）がHTMLの `<m-page-info>` から読み取り反映。`NewPageAPIHandler`（`internal/cms/handler.go:204`）で初期値を刻む。
2. **保存API保護**: `SaveAPIHandler`（`internal/cms/handler.go:33`）がサーバー権限フィールドを上書きしてから保存。
3. **フロント機能**: `<m-page-info>` コンポーネント追加（`assets/web-components.js`、`customElements.define` は末尾付近に追記）＋ テンプレート（`assets/templates/m-page-info-view.html` / `-edit.html` 新規）。`assets/index.html` のヘッダー簡易表示（317-323行付近）を削除し、ページ操作バーを新設、＋子ページ作成を移設。`updateParentIDTag()` / 読込時の親ID逆同期（1241-1245行付近）を新パネルに繋ぎ替え。
4. **HTML/CSSモダン化**。
5. **ドキュメント反映**（`docs/エディタ仕様.md`・`docs/アーキテクチャとDBスキーマ.md`）。

## 開発環境の再現（自宅で再開する手順）

```bash
# 1. リポジトリ取得（最新を pull）
git pull

# 2. 依存取得
go mod tidy

# 3. 初回のみ管理者を作成して起動（ローカルHTTP検証なので Secure Cookie 無効）
WCMS_ADMIN_USER=admin WCMS_ADMIN_PASSWORD='DevPassw0rd!' WCMS_SECURE_COOKIES=0 \
  go run cmd/w-cms/main.go
# 2回目以降は環境変数なしで go run cmd/w-cms/main.go

# → http://localhost:8080 （/login にリダイレクト。上の管理者でログイン）

# 4. テスト
go test ./...
```

注意: `data/`（`cms.db` と `master/`、`auth.db`）は `.gitignore` 対象でコミットされない。自宅環境では初回起動で再生成され、管理者作成が必要。
