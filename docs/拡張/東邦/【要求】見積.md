## 1. 見積を記録する（←旧文書から下書き）

- **見積は2種類**——顧客へ出す見積＝**売上の予定**、業者から貰う見積＝**原価の予定**（ユースケース:72-111）。
  予定の売上・原価として【要求】受注 §5（原価と利益）へつながる。
- **あとから引けること**——「あの部品は前いくらで出したか」「同じ材料を3社に聞いたうちどこが安かったか」を、ページを
  またいで引き出す（**横断比較**）。利用者「見比べることはよくありますので、いずれその機能も必要になります」
  （2026-08-21・ユースケース:26・解体前 l.636——要件定義書は行き先を「`【要求】見積` の案」としていた）。
- 図面がある見積もりは、加工製品ページに入れて区分「見積もり」のタグを付ける（2026-09-29 利用者「見積についても、図面が
  あるなら加工製品に入れて、見積もりのタグを付けたいです」——【要求】東邦拡張 §9）。

⚠ **いま**: 見積の器（見積書のページ）も横断比較も未実装。在るのは、加工製品ページの `見積計算表`（工程・数・単位・備考
——ワンノートから移した原価の内訳・2026-10-01 までは形式の名前が「見積もり」）と、その下の確定単価（§4）と、区分「見積もり」の
タグと、加工製品の一覧の絞り込みだけ。

## 2. 見積の器——決まったこと（←【考察】製造という軸 §7i・§7k・2026-09-22）

- **見積は器（見積書のページ）が要る**——理由は3つ: ①外に出る紙（見積書）がある ②受注の前にあるので、紐づける受注ページが
  まだ無い ③失注する——受注にならない見積が残るので、受注の下に置けない。
- **「見積DB」（専用の表）は要らない**——横断で読むのは索引の仕事。専用の表はドメイン表ゼロ（D-1）に逆行する。
- **発注明細と同じ表に「見積」の印で混ぜない**——状態の列に混ぜると、読み手すべてが「見積を外す」を覚えていなければならず、
  1か所忘れた日に見積が手配済みに化ける。相見積もりは1つの材料に複数社が並ぶので、混ぜると**買ってもいない会社の値段**が
  最新単価を上書きする。**形式を分け、列の宣言は共有する**（見積の明細も発注明細と同じ列で足りる）。
  利用者の問い（2026-09-22）:「見積もりの印をつければ見積も同じDBを使うことが出来ますが、そうするべきか否か」への筆者の答え。
- **価格の出所の順位**（混ぜて1つの数にせず、出所を必ず添える）——1. 発注明細（発注済・納品済）＝実際に買った値段 ＞
  2. 見積明細（貰った見積書）＝言われた値段・複数社が並ぶ ＞ 3. 発注明細（未発注）＝こちらが書いただけ・出さない ＞
  4. ワンノートの参考価格＝日付が無い・「最新単価」を名乗らせない。

⚠ **いま**: 最新単価の鏡が使っているのは1と4だけ（`ext/toho/material_price.go`）。

## 4. 確定単価——見積計算表に弊社利益を掛ける（2026-10-01 利用者の言葉から下書き）

> 「加工製品ページの見積もり計算表の下に弊社利益を掛ける項目を作り確定単価としたいです。弊社利益はデフォルトで10％なので、
> 単価に1.1をかければ良いのですが、利益率を変更できるようにしたいです。確定単価は目立つように太字です」「単価*10%=○○円と
> 表示したいです。この○○円は見積もりの集計で使うことになるかもしれません」「見積の時には、色を塗るか塗らないか、ロット数
> などで価格が変わることがあります。そのため、見積もり計算表は複数ある場合があります」「確定単価は、塗装のあるなし、ロット数
> など条件付きで検索して見積もりに入れられると良いですね」——利用者（2026-10-01）

- 見積計算表の下に**弊社利益**（単価 × 率 ＝ ○○円）と**確定単価**（単価＋弊社利益・太字）を出す。
- 率の既定は **10%**。表ごとに変えられる。
- 見積計算表は1つの加工製品に**何枚あってもよい**（塗装あり・なし、ロットごと）——1枚ずつ計算する。
- いずれ、確定単価を**条件（塗装の有無・ロット）で探して見積もりに入れる**——一般化は
  [【考察】表の集計の一般化.md](../../考察/【考察】表の集計の一般化.md)。

⚠ **いま**:
- 表の下に鏡で2行——「弊社利益: 単価 365円 × 10%（既定） = 37円」と太字の「確定単価: 402円」（`ext/toho/estimate.go`）。
  本文には書かない（単価や率を直せば、次に開いたときに計算し直す）。利益は円未満を四捨五入。
- 単価は「単価」の行の数。空なら単位が「円」の行（ロット・総計などは除く）を足したもの（そう書く）。
- 率は表の「弊社利益」の行（数に率・単位に %）。無ければ設定の既定（`extensions.toho.estimate_profit_rate`: 10）。
  閲覧モードの足元の「利益率 [ ] % 変える」で、その表に「弊社利益」の行を書く（無ければ表の末尾に足す）。編集モードでは行を
  直接直せる。
- 列の違う見積計算表（`ロット20｜ロット40` を列にした表など・約20枚）は「この形の表は計算できません」。
- ⚠ 条件で探すのはまだ（見積計算表の 246 ページは全部「移行中」で、表の写しに入っていない）。
