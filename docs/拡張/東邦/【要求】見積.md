## 2. 見積の器——決まったこと

2026-09-22 に決まったことです。出どころは、【考察】製造という軸 §7i・§7k です。

- **見積には、器（見積書のページ）が要ります。** 理由は3つです。
  1. 外に出る紙（見積書）があります。
  2. 受注の前にあるので、紐づける受注ページがまだありません。
  3. 失注することがあります。受注にならない見積が残るので、受注の下には置けません。
- **「見積DB」（専用の表）は要りません。**
  ページをまたいで読むのは、索引の仕事です。
  専用の表を作ると、「業務ごとの専用の表を DB に持たない」という決定（ドメイン表ゼロ。D-1）に逆行します。
- 「業者から貰う値段を、発注明細と混ぜないこと」と「価格の出所の順位」の決まりは、
  [【要求】見積依頼.md](【要求】見積依頼.md) §3 にあります。

⚠ **いま**: 見積書のページは、2026-10-01 からあります（§5）。

## 4. 確定単価——見積計算表に弊社利益を掛ける（下書き）

> 2026-10-01 利用者:「加工製品ページの見積もり計算表の下に弊社利益を掛ける項目を作り確定単価としたいです。弊社利益はデフォルトで10％なので、
> 単価に1.1をかければ良いのですが、利益率を変更できるようにしたいです。確定単価は目立つように太字です」
>
> 2026-10-01 利用者:「単価*10%=○○円と表示したいです。この○○円は見積もりの集計で使うことになるかもしれません」
>
> 2026-10-01 利用者:「見積の時には、色を塗るか塗らないか、ロット数などで価格が変わることがあります。そのため、見積もり計算表は複数ある場合があります」
>
> 2026-10-01 利用者:「確定単価は、塗装のあるなし、ロット数など条件付きで検索して見積もりに入れられると良いですね」

- **見積計算表の下に、弊社利益と確定単価を出します。**
  - **弊社利益**は、「単価 × 率 ＝ ○○円」の形で出します。
  - **確定単価**は、単価＋弊社利益です。太字で出します。
- **率の既定は 10% です。** 表ごとに変えられます。
- **見積計算表は、1つの加工製品に何枚あってもかまいません**（塗装あり・なし、ロットごと）。
  1枚ずつ計算します。
- **いずれ、確定単価を条件（塗装の有無・ロット）で探して、見積もりに入れられるようにします。**
  一般化の検討は [【考察】表の集計の一般化.md](../../考察/【考察】表の集計の一般化.md) にあります。

⚠ **いま**:

- **表の下に、鏡で2行を出します。**
  「鏡」は、ページを開くたびにサーバーが描き足す表示のことです。本文には書きません。
  - 1行目は、「弊社利益: 単価 365円 × 10%（既定） = 37円」の形です。
  - 2行目は、太字の「確定単価: 402円」です。
  - 本文に書かないので、単価や率を直せば、次に開いたときに計算し直します。
  - 利益は、円未満を四捨五入します。
  - 実装: `ext/toho/estimate.go`
- **単価は、「単価」の行の数です。**
  空なら、単位が「円」の行を足したものを使います（ロット・総計などは除きます）。
  足したときは、表示にそう書きます。
- **率は、表の「弊社利益」の行から読みます**（数に率、単位に % を書いた行）。
  - その行が無ければ、設定の既定を使います（`extensions.toho.estimate_profit_rate`: 10）。
  - 閲覧モードでは、足元の「利益率 [ ] % 変える」で、その表に「弊社利益」の行を書きます。
    行が無ければ、表の末尾に足します。
  - 編集モードでは、行を直接直せます。
- **列の違う見積計算表は、計算しません。** 「この形の表は計算できません」と出します。
  `ロット20｜ロット40` を列にした表などで、約20枚あります。
- **条件で探すことは、まだできません。**
  見積計算表のある 246 ページは全部「移行中」で、表の写し（本文の表を DB に入れたもの）に入っていないためです。

    PDF は、そのページの「📄 PDFを作る」で作ります。

  - 選んだ表のどれかで確定単価が出なければ、見積書を作りません。紙が黙って欠けないようにするためです。
  - 一覧の表は画面だけのもので、本文には残りません。番号は、この端末に憶えます。
  - 実装: `ext/toho/estimate_folder.go`
- **未送付の見積書**（2026-10-03 から）
  - 「見積」の置き場に、一覧が出ます。一覧は鏡で、開くたびに DB から作ります。
  - 並ぶのは、見積書ページ（見積番号のタグを持つページ）のうち、`送付日` も `送付不要` も無いものです。

- **備考の欄**（2026-10-03 から）

  - 「備考を保存」を押すと、見積書ページの「備考」の節を書き換えます（1行が1段落になります）。
    この節は、PDF が刷るところです。
  - 編集モードでは、欄を隠します。節を直接直せるためです。
  - PDF を作ると、ファイル表示（PDF などをページの中で開いて見せる枠）が表の直後に入ります。
    そのため「備考」の節は PDF の枠の下になりますが、備考の欄は、それでも表の下にあります。
  - 実装: `ext/toho/estimate_note.go`
- **まだ無いもの**: 受注とのつながり（受注・失注の印、受注の解析で見積書と突き合わせること）。
