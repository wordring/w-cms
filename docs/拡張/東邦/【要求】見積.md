## 2. 見積の器——決まったこと

2026-09-22 に決まったことです。出どころは、【考察】製造という軸 §7i・§7k です。

- **見積には、器（見積書のページ）が要ります。** 理由は3つです。
  1. 外に出る紙（見積書）があります。
  2. 受注の前にあるので、紐づける案件ページがまだありません。
  3. 失注することがあります。受注にならない見積が残るので、受注の下には置けません。
- **「見積DB」（専用の表）は要りません。**
  ページをまたいで読むのは、索引の仕事です。
  専用の表を作ると、「業務ごとの専用の表を DB に持たない」という決定（ドメイン表ゼロ。D-1）に逆行します。
- 「業者から貰う値段を、部材発注明細表と混ぜないこと」と「価格の出所の順位」の決まりは、
  [【要求】部材見積依頼.md](【要求】部材見積依頼.md) §3 にあります。

⚠ **いま**: 見積書のページは、2026-10-01 からあります（§5）。

- **見積表の足元**（鏡）
  - 計算を、次の形で出します。

    「計算表から: 原価 365円 × 利益率 10%（既定） = 利益 37円 → 単価 402円」

  - 原価は、見積計算表の価格の列の合計です。
    - 空のセルは飛ばします。
    - 式のセルは、計算した値を使います。
    - 数でない価格があれば、理由を出して計算しません。
  - 記録と合っていれば「✓ …（記録と合っています）」と出ます。
    合わなければ「⚠ 記録が計算表と合いません（記録の単価: …）」と出ます。
  - 計算表を直したとき（部材の値段が変わったとき）は、この ⚠ で分かります。
  - 書ける人には、次のボタンが出ます。
    - 「📌 この単価を記録」（合わないときだけ）
    - 「⧉ このロットを写す」
    - 「📄 見積書に入れる」
  - 見積表の無い見積計算表の下には、「📌 見積表を作って記録」が出ます。押すと、すぐ後ろに見積表を作って書きます。
  - 「⧉ このロットを写す」は、見出し・見積計算表・見積表を組ごと写して、すぐ後ろに置きます。
    - 見出しには「（写し）」を付けます。
    - 写しの見積表は、ロット・原価・単価を空にします。
    - ただし、式のセルは空にしません（2026-10-19 から）。
- **見積表の単価の式**（2026-10-19 から）
  - テンプレート「見積計算書」の「見積もり計算」の節に、2つの表を置きます。
    見積計算表（工程の行）と、単価に式のある見積表です。
  - 職場のテンプレートに置いたのは、次のものです。
    - 工程の6行（材料・ブランク・ドリル・ブレーキ・組み立て・塗装）
    - 単価の式 `=ROUND(原価*(1+利益率/100))`
  - 式は、コードに書きません。
    テンプレートの見積表の1行目にある式を、列ごとに写します（`templateRecordFormulas`）。
  - テンプレートに式が無ければ、いままでどおり、単価に計算した数を書きます。
  - 「📌 この単価を記録」は、原価と利益率を書きます。
    - 単価が式なら、そのまま残します。
    - 数の単価は、テンプレートの式に替えます。
  - 新しい見積計算書は、写す中身が無い品物のときだけ、テンプレートの節で始まります。

    - 月は、作った日の月です。

  - タグは、見積番号（ページ番号）・見積先・見積先担当・見積日・受渡期日・受渡場所・取引方法・有効期限・見積担当です。
