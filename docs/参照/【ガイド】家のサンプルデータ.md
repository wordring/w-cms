# 【ガイド】家のサンプルデータ

家（開発用）の w-cms に、職場に近い形のデータを作る手順です。
職場の data（実運用のデータ）は使いません。移行のために OneDrive に置いた**元データ**から、職場と同じ道具で作ります。

> 2026-10-15 利用者:「家には移行用の元データがあります。これを使ってレシピによってサンプルデータを作れますか。」

## 1. 何ができるか

| できるもの | 元データ（デスクトップの `w-cms\` の下） | 作る道具 |
|---|---|---|
| 置き場とテンプレート | `テンプレート\テンプレート.json` | `tools/templates.js import`・管理の「足りない置き場を作る」 |
| 通信箱のメール（約1,000通） | `メール\<アドレス>\`（職場の `tools/mail/fetch` が落としたもの） | `tools/mail/push` |
| 加工製品ページ（約290枚） | `ワンノート\板金部\`（家の `tools/onenote/extract.ps1` が吸い出したもの） | `tools/onenote/build` |

加工製品ページは、いまの形で作られます。表は見出し「部材」の下に並び、見積は見積計算表と見積表の組（ロットごと）です。

**まだできないもの**（職場では Gemini と人の判断で作ったもの）:

- 受注ページ（過去の注文書の 🤖 解析と、納品済みの判断）
- 部材見積依頼書（過去の見積もりの移し。道具が職場のページ番号で加工製品を指している）
- 見積書・部材発注書

家で受注の流れを試すときは、通信箱の注文書のメールで 🤖 解析を押して作ります（Gemini のキーが要ります）。

## 2. 手順

リポジトリの根で、Git Bash で流します。家の今の data には触らず、別の場所 `data-sample/` に作ります。

1. `git pull` します。
2. いまのサーバーを止めます。
3. 証明書を写します。各 PC が信頼している証明書をそのまま使うためです。

   ```bash
   mkdir -p data-sample && cp -r data/tls data-sample/
   ```

4. サンプルの場所でサーバーを起こします。初めての起動のときだけ、管理者 `a`/`a` を作る値を渡します。

   ```bash
   set -a; . ~/OneDrive/デスクトップ/w-cms/秘密の設定/w-cms.env; set +a
   export WCMS_TLS_CERT=data-sample/tls/cert.pem WCMS_TLS_KEY=data-sample/tls/key.pem WCMS_DAV=1
   WCMS_DATA_DIR=data-sample WCMS_ADMIN_USER=a WCMS_ADMIN_PASSWORD=a go run ./cmd/w-cms
   ```

   起動ログの「有効な設定」の1行に「データ data-sample」と出ることを確かめます。

5. 別の窓で、レシピを流します。

   ```bash
   WCMS_DATA_DIR=data-sample node tools/sample-data.js
   ```

   段は、テンプレート → 置き場 → メール → ワンノート → DB 再構築 の順です。
   2026-10-15 に職場で試したときは、全部で約11分でした（メール約1分半・ワンノート約9分）。できたのは 1,361 ページ・約4.8GB です。
   途中で止まっても、もう一度流せば続きから進みます（入っているものは飛ばします）。段を選ぶときは `--only mail,onenote` のように渡します。

6. 終わったら、ワンノートの製造の報告を見ます。置き場は `%LOCALAPPDATA%\w-cms\サンプルの製造\製造の報告.md` です。

いつもの家のデータへ戻すときは、サーバーを `WCMS_DATA_DIR` を渡さずに起こします。

## 3. 知っておくこと

- ⚠ **職場の製造の記録を書きません。** ワンノートの製造の記録と報告は `%LOCALAPPDATA%\w-cms\サンプルの製造\` に置きます（`-state`）。
  `ワンノート\板金部\製造の記録.json` は職場のページ番号を覚えているので、家で書き換えると職場の取り込みが狂います。
- **Gemini は呼びません**（`-gemini=false`）。図面の表題欄は、職場で読んだ控え（`ワンノート\板金部\` の下）があるものだけ使います。
- 製造の設定の「表の行き先」は、ワンノートのセクションと題で書きます（ページ番号では選びません）。家でも職場と同じページに当たります。
- 2026-05-01 より前の受信メールには「対応：不要」の印を付けます（職場と同じ）。
- **作り直すとき**は、サーバーを止めて `data-sample/` を `tls` 以外消し、`%LOCALAPPDATA%\w-cms\サンプルの製造\` も消してから、手順の4から流します。
- 道具は `WCMS_DATA_DIR` が空か `data` のときは止まります（いまの家のデータへ流さないため）。サーバーと道具には、同じ場所を渡します。
- `data-sample/` は Git に入りません（`.gitignore`）。中身は実データの写しなので、リポジトリの外へ出しません。
