# シナリオ別の呼び出し追跡

**対象コミット: `c60d187`（2026-10-01 作り直し・[全体地図.md](全体地図.md) と同じ測定）＋同日の「受注の行は受注フォルダを開いたときに結ぶ」を反映**

主な操作について、**実際に追える形**で呼び出しの連鎖を並べます。関数名は実在するものだけ、
分岐（403／404／409／423 になる条件）も併記します。個々の関数の説明は `go doc` が、
呼び出し元の一覧は [【一覧】関数リファレンス.md](【一覧】関数リファレンス.md) が持ちます。

> ⚠ **連鎖の多くはパッケージをまたぎます。** 取り込み（§6）・未処理（§8c）・メール（§7c・§7d）は
> `ext/comm`（と `ext/comm/mail`）、解析・整理・発注（§7・§7b・§8e）は `ext/toho`、連絡帳（§8d）は
> `ext/comm/contacts` です。**向きを間違えないこと**——コアは拡張を呼びません。コアは
> **フック（登録された関数）を呼ぶ**だけで、そこに何が積まれているかを知りません。

すべてのリクエストは最外周を通ります:

```
CSPProtect( outer )                 … 全応答へ Content-Security-Policy（strict。'unsafe-inline' なし）
  outer ├─ /dav/  → DavHandler      … **CSRFProtect の外側**（WebDAV の PROPFIND に
  │                                    Origin が付かないため。Cookie を使わない口なので
  │                                    CSRF の守りはもともと効かない）
        └─ /     → CSRFProtect(root)
                    … GET/HEAD/OPTIONS 以外は Origin（無ければ Referer）とホストの一致を要求
                      → 別オリジンなら 403、どちらのヘッダも無ければ 403
```

## 0. 起動

`cmd/w-cms/main.go` の `main()`:

```
（-gencert なら自己署名証明書を作って終了。設定もDBも要らないので最初に処理する）

cms.LoadSettings()                 … config/settings.json を読む（**DBより先**。**無くても**
                                     読めなくても不正でも log.Fatal＝Goコードに既定値は無い）
                                     validate → parseSections（拡張の節）→ applySections
                                     （設定由来の形式 vocab_formats をレジストリの末尾へ・拡張の apply）
database.InitDB()                  … data/cms.db を開き CoreTables＋coreMigrations
database.InitTablesDB()            … **data/tables.db**（表の写し）を開く（2026-09-25）
cms.DriftedSchemaTables(DB)        … プラグインのテーブル定義のずれを**先に**見る
  └ ずれがあれば cms.RebuildDatabase()   … 全テーブルDROP→data/master から再構築
cms.ApplySchema(DB)                … CREATE TABLE IF NOT EXISTS を流す（vocab_index・page_tags・
                                     material_dimensions と、その索引）。**再構築より後**（下）
cms.RebuildIfNeeded()              … ①中断した再構築のやり直し ②**表の写しの版が古ければ**
                                     （tablesDBOutdated）作り直し ③空DB＋ファイルありの復旧
database.InitAuthDB()              … data/auth.db を開き AuthTables
auth.BootstrapAdmin()              … users が空のときだけ初期管理者
editlock.StartLockReaper()         … 猶予満了を定期評価する goroutine
buildHandler()                     … ルート表（テストのために切り出してある）
cms.Extensions()                   … 載っている拡張を起動ログへ（「拡張セット: …」）
http.ListenAndServeTLS(":8443", …) … WCMS_TLS_CERT と WCMS_TLS_KEY が**両方**あるとき
http.ListenAndServe(":8080", …)    … 無いとき（片方だけなら log.Fatal＝書きかけの設定）
```

> **ずれの検出は `ApplySchema` より前**でなければ意味がありません。
> ⚠ **作り直しも `ApplySchema` より前**です。逆だと**列を変えた表へ新しい索引を張ろうとして起動が落ちます**。
> ⚠ **表を足しただけでは中身は入りません**——`ApplySchema` は `CREATE TABLE IF NOT EXISTS` を流すだけ。
> それを拾うのが `DriftedSchemaTables` の「索引に中身があるのに表が無い」判定です。

> **設定はDBより先**です——この後の再構築が語→型の推論辞書を使うため。
> `RebuildDatabase` も先頭で `LoadSettings` を読み直すので、辞書へ語を足しても
> `vocab_formats` へ形式を足しても **DB再構築**（§11）だけで反映されます（再起動は不要）。

## 1. ページを開く（`GET /{id}`）

`RootHandler`（`handler_view.go`）。**体裁は相手で分かれます。**

```
RootHandler
├ id が "" / "index.html"        → 302 /000000（クエリは保つ）
├ id == "000000" かつ pages に無い → 既定HTMLとサイドカー（mode 302）を作って SyncIndex（初回起動）
├ id に "/" を含む（/<6桁>/<名前>） → page.ServeCleanAttachment（§5の[配信①]）
│                                   （先頭が6桁のIDでなければ pageNotFound）
├ id に英数字ハイフン以外        → pageNotFound
├ strconv.Atoi 失敗             → pageNotFound
├ pages に行が無い              → pageNotFound
├ requirePageViewable ─────────────────────────────────────────┐
│   認証済み × page.GetPerms(…).CanRead が偽 → forbiddenPage（403・体裁つきHTML）
│   匿名 × page.EffectivePublic が偽
│     └ トップページ(0) → 302 /login?next=…
│     └ それ以外        → notFoundWithLogin（404・戻り先つきログイン導線）
├ os.ReadFile 失敗              → pageNotFound
│
├ body = RenderAnchors( RenderReferenceLinks( RenderComputedViews( Sanitize(content) ) ) )
│         ↑ 描画時だけ    ↑ 描画時だけ            ↑ 鏡型の段（walkMirror）  ↑ 二層目の防壁
│                                                                        （冒頭で StripChrome）
├ 匿名 → servePublicPage
│         RenderPublicShell(body, PageSEO{Title, ExtractDescription(body), CanonicalURL})
│         Cache-Control: public, max-age=600 ＋ Vary: Cookie ＋ ETag
│         If-None-Match 一致 → 304（本文を送らない）
└ 認証済み → RenderPageShell(body, title)
             Cache-Control: no-store
```

`RenderComputedViews` は `hasViewMarker` で早道し、あれば `walkers.walkMirror` で要素を配ります。
**ここが「拡張の画面がコアの描画に乗る」唯一の口**です。鏡は `<section data-mirror="表示名">` で名乗り
（`vocabTypeOf`・§2 の担当表）、**登録が無ければ `missingViewHTML` が理由を出します**。
⚠ **テンプレート以下では鏡は名前だけの案内**（`IsTemplateArea`）。
同じ段で表の鏡も走ります——受注明細の足元に検算・受注残高（`renderOrderChecksum` → `appendOrderBalance`）、
材料の表に廃版の印と最新単価の列（`markObsoleteRows` → `renderMaterialPrices`）、発注部材表の欄
（`renderOrderDraftForm`）、発注明細の行ごとのボタンと送る欄（`renderOurOrderChrome`）、ファイル表示
（`renderFileView`——中の名札ごと空にしてから描く）。ほかは `DropChrome` で前回の分を落としてから描き直します。

`RenderReferenceLinks` は `<dl` も `<table` も無ければ早道、あれば:

- **可変タグ**（`dl[data-type="tags"]`・クロームの中は除く）——値を `parseRefValue` に掛け、
  `pageExists` でリンク（`/<ページID>#<ブロックID>`）か `ref-missing` かを決めます。
  **`email` 型の名前は `linkEmailDD`**（`RegisterContactResolver` で預かった解決係に尋ね、
  **解決係が無ければ素のテキストのまま**）。**`ref` 型と宣言されたタグ**（`受信元`・`返信元`・`連絡帳` など）
  ならページIDだけの値をページ全体への参照として扱います（`parsePageRef`）。
- **表**（`linkRefCells`）——**列の宣言が `ref` のセルだけ**（`弊社品番`）をリンクにします。
  ⚠ **鏡が `<tfoot>` へ足した行は `inVocabChrome` で飛ばします**（`RenderReferenceLinks` は
  `RenderComputedViews` の**後**に走るため）。

**匿名の404は「読めない」と「存在しない」を区別しません**（例外はトップページだけ）。
404画面は `/login?next=…` を持ち、`safeNextPath` が同一サイト内の絶対パスだけに絞ります。

**本文API（`GET /api/load?id=`）**は `LoadAPIHandler`——GET 以外は405 → `queryPageID`
（400）→ `RequirePageReadOrPublic` → `pages.file_path` → `RenderComputedViews(Sanitize)` を
`text/plain`＋`nosniff` で返す。**アンカー合成と参照リンクは通しません**。⚠ **鏡は埋めて返します**
——これを外から `/api/save` へ書き戻すと鏡が本文に焼き付きます（`StripChrome` が守るが、既に保存された
鏡は落とせない）。

## 2. 保存する（`POST /api/save`）

`SaveAPIHandler`（`handler_save.go`）。**順序に意味があります。**

```
SaveAPIHandler
├ メソッドが POST でない        → 405
├ DecodeJSONBody（8MiB上限）    → 413 / 400
├ page_id が空                 → 400（新規は /api/new-page を通す）
├ gateSave
│   ├ normalizedPageID         → 400
│   ├ page.RequirePageWrite    → 401 / 403
│   └ editlock.RequireLockToken（JSON の token）→ 409（他者が保持中／トークン失効。無ければ許可）
├ SanitizeReport(req.HTML)     → safeHTML, sanitized
│   └ 冒頭で StripChrome（.vocab-chrome を根こそぎ落とす。落としたら sanitized=true）
├ FillFileViewNames            … ファイル表示の中へ名札（短いファイル名）を書き込む（表示では消す）
├ writeBody
│   ├ refuseDuplicateBoxTitle  → **409**（トップ直下で、題が置き場の名簿に在り、同じ題が既に別に在る）
│   ├ page.BumpUpdatedAt       → 500（**サイドカーが読めなければここで止まる**）
│   └ page.WriteFileAtomic(<GetPageDir>/<id>.html) → 500
├ RecordVersion(id, user, safeHTML, force=false)   … 失敗しても**保存は止めない**
├ syncBody → SyncIndex(id, safeHTML)      → 500
├ auth.AuditRequest(r, "save", id)
└ 200 saveEcho {success, page_id, updated_at, html, sanitized, unknown_types, unresolved_fields, stripped_ids}
```

`SyncIndex`（`sync.go`）の中身:

```
html.Parse → PageTitle（タイトル）
page.ReadSidecar（親・作成情報・更新日時。読めなければ parent_id は**現状維持**）
tx = DB.Begin()
  pages を upsert
  page.SyncPageMeta      … サイドカー → page_perms（upsertPerms）
  各 Observer.OnPageStart … vocab_index・page_tags・material_dimensions の当該ページ分を DELETE
  IsTemplateArea(id) が偽なら walkers.walkObserve(ctx, root)
    └ 引き金（vocabTypeOf）に当たった要素だけを担当へ配る（.vocab-chrome の中は歩かない）
       vocabIndexPlugin.OnElement（引き金 *）
         section → syncVocabSection … data-type で名乗る節（古い本文の形式）の中の**素の表**だけ
                                       （⚠ 節の見出しでは名乗れない——2026-09-29 廃止）
         table   → syncVocabTable   … **登録された形式だけ**（caption か data-type）。見出し行の th が鍵
         dl      → syncVocabDL      … 直前の dt が鍵
         （振り分けは insertVocabEntry ——可変タグ（dl[data-type="tags"]）は page_tags、
           それ以外は vocab_index。block_no は形式ごとの文書順連番＝ctx.Counter）
       dimensionPlugin.OnElement（引き金 part-materials / our-order-items・ext/toho）
         table   → indexTable … `寸法` の列を ParseDimension で分解して material_dimensions へ
         降りるかは OR で畳む（dimensionPlugin は表なら false、vocabIndexPlugin は常に true）
  PageFinisher を実装する Observer があれば OnPageEnd（いまは無い）
tx.Commit()
syncCaptionTables(id, …)  … **表の写し**（data/tables.db）。コミットの後・**失敗してもログだけで保存は止めない**
  excludedFromTables（テンプレート領域・拡張の断り＝`移行中`）なら表を持たない扱い
  → そのページの行を全表から DELETE → captionTablesOf（キャプションのある表・名前は TableName で正規化）
  → insertCaptionTable（無い表・列は足す・同じ名前の表は1つに統合）
```

> **テンプレート領域は「要素イベントを1つも発火しない」だけ**で除外されます。
> `OnPageStart`（DELETE）は呼ぶので、普通のページをテンプレートフォルダへ移すと古い行が消えます。
> 判定 `IsTemplateArea` は**サイドカーと本文HTMLで先祖を辿ります**（DBを見ない）。
>
> ⚠ **登録されていない形式の表は `vocab_index` に入りません**（2026-09-20）が、**キャプションがあれば
> 表の写しには入ります**。受注ページの「顧客の発注書（読んだまま）」は 09-28 からキャプションを外したので、
> どちらにも入りません。

**ブロック保存（`POST /api/save-block`）は版を作りません。** 同じ `gateSave` を通し、
`ReplaceBlock` で本文をマージしてから `writeBody`・`syncBody`（対象が無い／重複なら 409 でクライアントが
全文保存へ落ちる）。最終状態はロック解放時のチェックポイント（§3）が拾います。

**機械が本文を書き換える口（`RewriteBody` → `rewritePageBody`）も同じ作法**——
`Sanitize`（冒頭で `StripChrome`）→ `BumpUpdatedAt` → `WriteFileAtomic` → `RecordVersion` →
`SyncIndex`。呼ぶのは連絡帳・対応の印・下書き・整理・改定の合流・弊社品番の結び・受注残の書き戻し・
発注部材表・臨時部材表・発注書の作成・行の状態・送付・戻す・PDF の表示（16ファイル・19箇所）。
**ロックは呼ぶ側が見ます**（`RefuseWhileEditing`／`EditorOpen`・東邦は `requireWritableIdle`）。

## 3. 編集モードへ入る／抜ける

```
[入る] POST /api/lock?id=
  LockAPIHandler（editlock/handler.go）
  ├ queryPageID → 400
  ├ requireWriter（page.RequirePageWrite）→ 401 / 403
  ├ Locks.TryAcquire
  │   取れない → 423 Locked {ok:false, holder, same_user, grace_remaining_sec}
  └ 200 {ok, token}   ※**本文は返さない**
  → フロント（acquireLock）が GET /api/load を読んで populateEditor

[購読] GET /api/lock-events?id=&role=holder|waiter&token=   … SSE。presence の実体はこの接続の有無

[抜ける] POST /api/unlock?id=&token=（タブ離脱時は navigator.sendBeacon からも）
  UnlockAPIHandler → Locks.Release
                      └ 保持者本人でトークン一致のときだけ editlock.OnRelease を呼ぶ
                         └ cms/version.go の init が RecordVersion(…, force=true)
                            （中身が最新の版と同じなら何もしない）

[強制] POST /api/lock/force?id=   … page.RequireAdmin → Locks.ForceRelease → Audit "lock.force"
```

**猶予は競合トリガー方式**——誰も待っていなければ無期限、待機者が現れてから2分で明け渡します
（`lockGraceDuration`）。取得直後に SSE が繋がるまでの猶予は10秒（`holderConnectGrace`）。

> ⚠ **閲覧モードへ戻るときは、送っていない自動保存を先に流します**。自動保存は1.5秒の
> デバウンスなので、`onModeToggle` が保存を待たずに `releaseLock()` を呼ぶと**最後の入力が
> 黙って消えます**。「保存してから何かする」経路を足すときは `await saveToServer()` を通すこと。
> ⚠ **`/api/lock` を2回呼ばないこと**——同じ利用者でも2回目でトークンがずれ、そのあとの
> 削除・保存が 409 になります（`force → lock（1回）→ 使う` の順で）。

## 4. ページを作る（`POST /api/new-page`）

```
NewPageAPIHandler（handler_tree.go）
├ POST 限定（GET は 405）
├ parent が空            → 400（親なしにできるのはトップページだけ）
├ page.RequirePageWrite(parent) → 401 / 403
├ loadTemplateBody（template.go）… template= があれば**採番の前に**検証して読む
│    NormalizeID → RequirePageRead → IsUnderTemplateRoot → isLeafPage → ReadFile(BodyPath) → Sanitize
├ reserveNewPageID       … pages への INSERT で原子的に採番
├ html = 既定文 or CopyTemplateBody(templateBody)   … **純粋なコピー**（2026-09-25 に種まきを撤去）
├ page.WriteFileAtomic(page.BodyPath(新ID))
├ page.EnsureSidecar     … owner=作成者・group/mode は親の GetPerms から継承・public は常に false
├ SyncIndex
├ auth.Audit(user, "new-page", "<新ID> under <親>[ (template <id>)]")
└ 302 /{新ID}?edit=true
```

**機械が作るページは `cms.CreateChildPage`**（`page_folders.go`）——`reserveNewPageID` → `Sanitize` →
`WriteFileAtomic` → `GetPerms(親)` で継承して `EnsureSidecar` → `SyncIndex`。監査は呼び手が録ります。
本文はテンプレートを写して印を埋めたもの（`PageTemplateBody` → `NewPageDraft` → `SetTag`・`FillTable`・
`SetContent`・`SetFileView` → `HTML()`）で、**テンプレートが無い・2枚あれば作る前に 409**（題だけのページを残さない）。

> ⚠ **置き場の題はトップ直下に1枚だけ**。`/api/new-page` は題を持たない（既定文）ので、止まるのは
> **保存のとき**（§2 の `refuseDuplicateBoxTitle`）です。

## 5. 添付する（3つの口）と配る（2つの口）

```
[汎用]  POST /api/upload-file   UploadFileHandler（upload_file.go）  フォーム名 file

## 9. 版を取り出す／戻す

```
[一覧] GET /api/versions?id=      VersionsAPIHandler
  queryPageID → page.RequirePageRead → ListVersions（新しい順。本文の無い版は飛ばす）

[取得] GET /api/version?id=&v=    VersionAPIHandler
  queryPageID → page.RequirePageRead → ReadVersion
    ├ safeVersionID … 時刻由来の形（20060102T150405Z）しか受け付けない → 404
    └ gzip を 8MiB 上限で展開
  → RenderComputedViews(Sanitize(body)) を text/plain ＋ nosniff で返す

[戻す] POST /api/revert           RevertAPIHandler
├ POST 限定
├ DecodeJSONBody {page_id, version}
├ normalizedPageID → 400
├ page.RequirePageWrite → 401 / 403
├ editlock.RequireEditLock → 409
├ RevertToVersion(id, version, author)          → 失敗は 400
│   ├ ReadVersion
│   ├ **いまの内容を RecordVersion(force=true)**（リバート自体を取り消せる）
│   ├ Sanitize（過去の版も**いまの許可リスト**で濾す）
│   ├ page.WriteFileAtomic → page.BumpUpdatedAt → SyncIndex
│   └ 戻した内容も RecordVersion(force=true)
├ auth.AuditRequest(r, "revert", "<id> -> <版ID>")
└ 200 {success, page_id, version, html: RenderComputedViews(Sanitize(戻した本文))}
```

**サイドカーは触りません**——権限・所有者・親は現状のままです。

`RecordVersion` の規則: 中身のハッシュが最新の版と同じなら何もしない／`force=false` で
同じ編集者かつ最新の版IDから10分以内なら**その版を置き換える**／それ以外は新しい版を切る。
⚠ **版の掃除はありません**（2026-09-23 に撤去）。
