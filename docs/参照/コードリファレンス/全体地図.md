### 2b. 載っている拡張を「知らせる」

拡張が自分で名簿に名乗ります（`cms.RegisterExtension(id, name)`・`internal/cms/extensions.go`）。

| ID | 名前 | 名乗る場所 |
|---|---|---|
| `comm` | 通信 | `ext/comm/comm_routes.go` の `init` |
| `comm/contacts` | アドレス帳 | `ext/comm/contacts/plugin.go` の `init` |
| `comm/mail` | メール送受信・IMAP／SMTP | `ext/comm/mail/plugin.go` の `init` |
| `toho` | 東邦の業務 | `ext/toho/materials.go` の `init` |

行き先は3つです。①起動ログの「拡張セット: …」の1行、②起動ログの「有効な設定: …」の1行（`cmd/w-cms/startup_line.go`）、
③画面の出し分け（`/api/tag-schema` の `extensions`・空でも `[]`）を `assets/app.js` の `hasExtension(id)` が見ます。
`hasExtension` の呼び手は `'toho'` 7・`'comm'` 5・`'comm/mail'` 2・`'comm/contacts'` 1 です。
`hasExtension` は**知らされていなければ true** を返します（取得に失敗したら全部出す——出ないより、押して断られるほうが原因に気づけます）。

### 2c. 置き場と、機械が使うテンプレート

**置き場**（トップ直下の、名前で機能が決まるページ）は、`cms.RegisterRequiredPage` で名乗ります。

## 5. 既知のねじれ・注意点

- **編集ロック（`editlock`）は、道具のために残っています。** 画面は 10-12 から `/api/lock` を呼びません（`assets/app.js` に `/api/save`・`/api/lock` の文字はありません）。
  残っているものと、いまの効き方は次のとおりです。
  - `/api/save`・`/api/save-block` は `gateSave` → `RequireLockToken` を通ります。**ロックが無ければ通す**規約なので、道具が握っているときだけ効きます。
  - 添付の口（`openUpload`）・親の付け替え・削除・版を戻す・権限の変更は `editlock.RequireEditLock` を通ります（**5ファイル・6箇所**）。画面はトークンを付けないので、道具が握っていなければ通ります。
  - 機械が既存ページを書き換える口の関門 `editlock.RefuseWhileEditing`（**3ファイル・5箇所**）と `editlock.Locks.EditorOpen`（`editlock/handler.go` を含め**15ファイル・18箇所**）は、**ロックを握っている人が居るときだけ**断ります。画面が握らなくなったので、ほぼ素通りです。
  - 人の書きかけとの重なりは、いまは `LockPageBody`（1回の書き込み）と `/api/sync` の指紋の比べで守ります。機械もほかの書き手の1人で、ぶつかれば画面が両方を並べます。
  - 版の区切りは、ロックを手放したとき（`editlock.OnRelease` → `RecordVersion(force)`）に加えて、`/api/version-checkpoint` でも打ちます。画面はこちらだけを使います。
- **`RequireAdmin` が2つあります。** `page.RequireAdmin` は `auth.RequireAdmin` への委譲で、実体は1つです。
- **観察係は2人**です（`vocabIndexPlugin`＝引き金 `*`・`dimensionPlugin`＝`part-materials` と `our-order-items`）。だから `descend` は **OR で畳みます**（AND にすると明細が索引から消えます）。
  `material_dimensions.block_no` は自分で数えた連番で、コアの `block_no` とは揃えていません（結合しない前提）。
- **鏡の引き金は16**です（`RegisterMirror` の実測）。コアは `*`（計算ビュー）と `file-view` の2つ。東邦は14で、`drawing_mirror.go` が4つの部品の表（`part-materials`・`part-outsourcing`・`part-purchased`・`part-supplied`）を1つの繰り返しで登録し、
  ほかは `client-order-items`・`part-estimate`・`estimate-items`・`order-draft`・`our-order-link`・`our-order-items`・`rfq-needs`・`rfq-draft`・`rfq-items`・`procure-skip` です。
- **添付の配信口が2つあります。** 旧い形 `/data/master/…`（`page.DataFileHandler`）と、きれいなURL `/<ページID>/<名前>`（`page.ServeCleanAttachment`）。どちらも `.json` は配りません。
  旧い形の URL の `/data/master` は名前だけで、10-14 から `page.MasterDir()`（データの場所の下）へ読み替えて配ります。
- **索引の `pages.file_path` は、書くけれど本文を読むのには使いません**（10-14）。データの場所を変えると古い場所を指すためです。
  本文は `page.BodyPath(id)` から読みます（`RootHandler`・`LoadAPIHandler`・`ext/toho/filing_files.go`）。`file_path` を SELECT するのは `filing_files.go`（`pagesShowing`）だけで、空かどうか（本文がまだ無いページを飛ばす）にしか使いません。
- **ファイル表示の「開ける形式」は配信側の帰結です。** `fileViewKinds`（`.pdf`・`.png`・`.jpg`・`.jpeg`・`.webp`・`.gif`・`.svg`・`.mp4`・`.m4a`・`.mp3`）に無い拡張子は、開く口（リンク）を出すだけです。
- **`section` に許す `data-*` は4つ**です（`data-type`・`data-src`・`data-ref`・`data-mirror`）。
- **プラグインのテーブルにマイグレーションはありません。** `ApplySchema` は `CREATE TABLE IF NOT EXISTS` です。起動時のずれの検出（`DriftedSchemaTables`）＋自動の再構築で対応します。
  コアのテーブルには手書きのマイグレーション（`database/sqlite.go` の `coreMigrations`）があります。表の写しは `PRAGMA user_version` で作り直します。
- **`WalkElements` を回すファイルは16**です（定義を除く・22箇所）。コアの `anchor.go`（2）・`attachment_ref.go`・`file_view.go`・`formula.go`・`parser.go`・`plugin.go`（3）・
  `ref_render.go`・`sanitize.go`・`shell_public.go`・`tables_db.go`・`view_render.go`・`vocab_notify.go`（3）と、拡張の `comm/record_text.go`（2）・`contacts/signature.go`・`mail/compose.go`・`toho/order_docs.go`。
  どれも索引の走査ではありません（索引は配送係 `walk.go` だけ）。
- **コアで dt/dd の対を読むのは `eachDLPair`** です（呼び手は `plugin.go`（2）・`ref_render.go`・`vocab_index.go`・`vocab_notify.go`）。自前で読む所は残っています。
  `page_template.go` の `tagDD` と、東邦の紙の読み手（`readOrderDoc` など）です。`eachDLPair` は非公開なので、拡張からは使えません。
- **節の中の素の表を拾う `eachPlainVocabTable` は、見出しで名乗る読み方を廃した（09-29）あとも残っています。** 呼び手は `vocab_index.go`（`syncVocabSection`）と `vocab_notify.go` です。
  DBの日本語化 5段目の4で消す候補です（[【考察】DBの日本語化.md](../../考察/【考察】DBの日本語化.md)）。
- **`walkState.Ancestors` / `Closest` に本体の使い手がいません。**（【ガイド】プラグイン開発）が指す公開APIなので残してあります。
- **本体に呼び手の無い公開関数**（メソッドを除く・値としての参照も数えた実測）。**試験にも無いもの4つ**: `cms.EnsureChildByTitle`（`page_lookup.go`）・
  `cms.VocabBlocksOf`（`vocab_query.go`）・`comm.SendPurposeNames`（`compose.go`）・**`comm.LinkChildrenOf`**（`parent_link.go`・10-09——親があとから入った子へ書き足す仕事は `FixRecordTags` がしている）。
  **試験だけが使うもの5つ**: `cms.FirstBlockHTML`・`cms.ViewMarkerHTML`・`cms.LoadSettingsFrom`・`cms.AttachmentVersions`（`attachment_write.go`）・`contacts.PartnerCandidates`。
  `cms.WriteTag` は、`comm/parent_link.go` が使うようになりました。消すか使うかは利用者の判断です。
- **手配の集計が2本あります。** 古い `RequiredMaterials`（`/api/required-materials`・`RelatedPages` の範囲）と、新しい集計です。
  新しいほうは、手配状況（`ProcurementByProduct`）と必要部材表（`UnorderedItems`）が**同じ帳簿**（`procure_ledger.go` の `buildLedger`）を通します。古いほうを叩くのは E2E（`verify-template.js`）だけです。
- **社名を機械が書く口は、揃え方が2通りです。** 解析・受注の整理・加工製品の整理・見積書・部材見積依頼の返事は `contacts.OrgNameForPage`（**7ファイル・9箇所**）、連絡帳の登録の初期値は `contactRowInitials`（候補が2つ以上なら空）です。
  1つでも生の名前を書くと、完全一致で結ぶ2つの木が黙って結ばれません（`linkPartner` → `PartnerByTitle`）。
- **改訂明細表を探す口は `revisionTableAt` の1つ**です（属性でも caption でも）。`InsertRevisionRow` は `analyze_pdf.go` にあり、呼び手は `revision.go` と `drawing_supersede.go` です（置き場と呼び手が別のファイル）。
- **`page_tags.norm_value` は宣言型を持ちません。** 束ねる形は `tagNormBind` 1か所です（書き手 `insertVocabEntry`・読み手 `PagesByTagLoose`）。この列を条件に使う裸の SQL を書かないでください（型を取り違えると、エラーにならず0件になります）。
- **ページIDを文字列にする所は `page.FormatID` を通します**（`page` の外から**52ファイル・119箇所**。10-14 の測り直し）。
- **`MatchDXFAttachments`（PDFとDXFの突き合わせ）は、試験から一度も呼ばれていません**（呼び手は解析の1か所だけ）。
- **メソッドの番人が無い口があります。** `method_guard_test.go` は `internal/cms`・`internal/auth`・`ext/comm` の3つにだけあります。
  `internal/cms` の番人（`TestStateChangingHandlersRejectGET` の12件）に、10-12 の口（`/api/sync`・`/api/version-checkpoint`・`/api/presence`）は入っていません（どれもハンドラの中で POST 以外を断ります）。
  `ext/toho`・`ext/comm/contacts`・`ext/comm/mail` にも番人はありません（多くは `GateJSONPost` を通すので POST 以外は 405 になりますが、固定する試験はありません）。
- **読んでから計算して書く口が、錠の外で読むことがあります。** たとえば `drawing_supersede.go` の `supersedeDrawing` は、`ReadPageBody` で読んで組んだ本文を、`RewriteBody` の中では今の本文を見ずに書きます。
  `RewriteBody` の錠は書き込みのあいだだけなので、読んでから書くまでのあいだに入った別の書き込みは、上書きされて残りません。
  編集権があったころは、`requireWritableIdle` が「誰かがエディタで開いているあいだ」を断っていました。いまは画面が編集権を握らないので、その守りは効きません（未確認: 実際に起きたかは確かめていません）。

## 7. 数え直す（この文書を疑うとき）

```bash
# 規模（ext/ と tools/ を必ず含めること）
find cmd internal ext -name '*.go' -not -name '*_test.go' | xargs wc -l | sort -rn | head -21
find cmd internal ext tools -name '*_test.go' | xargs cat | wc -l
grep -rh '^func Test' --include='*_test.go' cmd internal ext tools | wc -l
wc -l assets/*.js assets/*.css assets/*.html
ls e2e/verify-*.js | wc -l; ls e2e/probe-*.js | wc -l

# パッケージの依存の向き（ディレクトリごと）
for d in internal/cms ext/comm ext/comm/contacts ext/comm/mail ext/toho; do
  echo "$d → $(ls $d/*.go | grep -v _test.go | xargs grep -h '"w-cms/' | sed 's/.*"w-cms\/\([^"]*\)".*/\1/' | sort -u | tr '\n' ' ')"; done
# 拡張どうしの import（向きは必ず「拡張 → 通信」）
grep -rln '"w-cms/ext/' --include='*.go' ext | grep -v _test.go

# ビルドタグ（拡張のパッケージの側には無い＝取り付け口だけ）
grep -rn '^//go:build' --include='*.go' cmd ext internal

# ルート表（コアと、拡張が足す分）
grep -c 'protected.HandleFunc("' cmd/w-cms/main.go           # 41（ほかに定数で書く auth.SessionAPIPath の1本・合わせて42）
grep -cE 'root\.Handle(Func)?\("' cmd/w-cms/main.go          # 16
for d in ext/comm ext/comm/contacts ext/comm/mail ext/toho; do echo "$d $(ls $d/*.go | grep -v _test | xargs grep -h 'Pattern: *"' | wc -l)"; done

# コアが宣言する登録の口と、拡張からの登録
grep -rn '^func Register' --include='*.go' internal/cms | grep -v _test
grep -rnoE '(cms|comm)\.Register[A-Za-z]*\(' --include='*.go' ext | grep -v _test | awk -F: '{print $3}' | sort | uniq -c

# 本文を書く錠
grep -rn 'LockPageBody(' --include='*.go' internal ext | grep -v _test

# 語彙の形式・ビュー・ルート・置き場の本数は、組ごとに実際に数えるのがいちばん確か
#   （`_measure/` に小さな main と ext_*.go の写しを置き、cms.VocabDefs() / cms.PluginRoutes() /
#    cms.ExtensionIDs() / cms.RequiredPages() を出す。`_` で始まる名前は `./...` に拾われない。終わったら消すこと）
go build ./... && go build -tags nomail ./... && go build -tags minimal ./...
```

**`gofmt -l` は判断の材料にしないこと。** このリポジトリでは CRLF のため、全ファイルが挙がります。
整形の確かめは `go build` / `go vet` / `go test` で行います。
