## 30秒で掴む

- **単一バイナリのGoサーバー**（`cmd/w-cms`）が、ポート 8080 で HTTP を受ける。外部サービスは
  PDF解析の Gemini のみ（任意）。
- **ページの正本はファイル**。本文は `data/master/<先頭2桁>/<id>/<id>.html`、属性（所有者・権限・
  親・作成/更新）は同じフォルダの `<id>.meta.json`（サイドカー）。
- **SQLite は使い捨ての索引**。`data/cms.db` はファイルから再生成できる（`RebuildDatabase`）。
  再生成できない情報（ユーザー・セッション・監査ログ）だけが `data/auth.db` にある。
- **画面はサーバー合成**。`GET /{id}` が `assets/index.html`（殻）に本文を埋めた完成HTMLを返す。
- **フロントはバニラJS**。ビルド工程なし。`assets/app.js`（2938行）がエディタ本体。
  **カスタム要素 `<m-*>` はゼロ**——`web-components.js`・`templates/`・`components.css` は
  2026-08-19〜20 にファイルごと撤去済み（正本は
  [【考察】語彙モデル.md](../【考察】語彙モデル.md) §8・§9）。
- **本文の語彙は「構造HTML＋`data-*` マーカー」の1箇所だけ**。繰り返し明細＝
  `<table data-type>`、名前:値＝`<dl data-type>`、業務文書ブロック・ファイル容器・計算ビュー＝
  `<section data-type>`。形式の宣言は①語彙レジストリ（`vocab.go`・12形式）、
  索引は②汎用索引（`vocab_index.go` → 縦持ちテーブル `vocab_index`）。
- **計算ビュー（子ページ一覧・手配集計）はサーバー事前描画**。本文に保存されるのは
  空のマーカーだけで、中身は `view_render.go` が返すたびに埋める（閲覧ゼロJS）。
- **CSP は strict**（`script-src 'self'; style-src 'self'`。`'unsafe-inline'` なし）。
  インライン `<script>`／`<style>`／`on*=` はリポジトリ全体でゼロ。
- **同時編集はページ単位の悲観ロック**。プロセス内メモリ＋SSE。

## プラグイン（`plugin_*.go` 5本）

`Plugin` インターフェース（`Name` / `Schema` / `Tables` / `Sync`）を実装し、

## 覚えておくべき不変条件

1. **サニタイズは二層**。保存時（`SanitizeReport`）と描画時（`Sanitize`）。片方だけにしない。
2. **語彙は1箇所**。エディタのシリアライザは `/api/tag-schema` に従う。手書きの要素リストを
   フロントに置かない（置くと「画面に出るのに保存で消える」が再発する）。
3. **添付は `.pdf` のみ**。ページのフォルダには本文とサイドカーが同居しているため、
   任意の名前・種類を書けると権限昇格と保存型XSSになる（2026-08-05 に実際に塞いだ）。
4. **`.vocab-chrome` は保存されない**。サーバー事前描画の中身とエディタのクローム
   （PDFプレビュー・ドロップゾーン等）は同じクラスを付け、シリアライザが読み飛ばす。
   この規則が破れると、派生表示が本文の正本へ焼き付く。
5. **`page` は上位（ハンドラ・ロック）を知らない**。逆向きの import を足さない。
   `htmldoc` は internal を1つも import しない。
6. **語彙レジストリは安全性の門ではない**。未知の `data-type` も保存を通し（告知のみ）、
   サニタイズは属性名の許可（要素限定）だけを見る。レジストリを検査に使い始めると
   「自由な記述をシステムが認識する」というコア・コンセプトが壊れる。
7. **新規カスタム要素（`<m-*>`）は作らない**（2026-08-17 決定）。新しい形式は
   `vocabRegistry` への宣言1件（マーカー付き標準HTML）で足す。サニタイザは
   カスタム要素を**アンラップ**する（中身のテキストは残る）ので、書いても保存されない。
8. **新規のフロントでインライン `script`／`style`／`on*=` を書かない**。CSP は strict なので、
   書いた瞬間に動かなくなる（`internal/auth/csp_test.go` が `'unsafe-inline'` の非在を固定）。
