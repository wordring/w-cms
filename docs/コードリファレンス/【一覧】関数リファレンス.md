```
CSPProtect( CSRFProtect( root ) )

                          ├─ /login, /api/login, /api/tag-schema … 認証不要

  （`TestAuthenticatedAPIsAreNotCacheable`）。
- CSP の配線は `TestCSPIsWired`（`route_guard_test.go`）、ポリシー文字列は
  `internal/auth/csp_test.go` の `TestCSPPolicyIsStrict` が固定します。

**偽陽性に注意**（このプロジェクトで実際に踏んだもの）:

- **メソッド名**——`Name` / `Schema` / `Tables` / `Triggers` / `OnElement` / `OnFile` は複数の型が
  実装するので、「最初に宣言したファイルへの依存」に見えます。
- **同名関数**——`RequireAdmin` は `auth` と `page` の両方にあります。`page.` の有無で分けること。
- **同一パッケージ内の呼び出し**——`auth.Audit(` で grep すると `auth` 自身の
  11箇所（ログイン・ログアウト・管理API）が漏れます（`Audit(` は本体で28箇所）。
- **括弧なしの参照**——`page.DataFileHandler` は `main.go` で `http.HandlerFunc(...)` に
  渡されるだけなので `DataFileHandler(` では当たりません。
- **コメント内の言及**——件数だけ見て内訳を見ないと外します。
