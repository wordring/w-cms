### 計算ビューのサーバー事前描画（`view_render.go`）

本文に保存されているのは空のマーカーだけで、中身はページを返すたびにここが埋めます。
埋めた中身は `<div class="vocab-chrome" contenteditable="false">` に包まれ、エディタの
シリアライザが読み飛ばすため**保存経路には戻りません**。

| 関数 | 何をするか | 主な呼び出し元 |
|---|---|---|
| `RenderComputedViews(r *http.Request, pageIDInt int, bodyHTML string) string` | 本文中の `<section data-type="child-list">`／`"required-materials"` を集めて中身を埋める。**マーカーが無ければパースせず素通し** | `RootHandler`（`Sanitize` の**後**）・`LoadAPIHandler` |
| `fillViewMarker(el *html.Node, innerHTML string)` | マーカーの中身を全消しして描画結果へ置き換える（マーカー内に書かれた内容は表示に乗せない） | `RenderComputedViews` |
| `childListViewHTML(user *auth.User, parentIDInt int) string` | 子ページ一覧の `<ul class="child-list">` を組み立てる（タイトルは `html.EscapeString`） | `RenderComputedViews` |
| `requiredMaterialsViewHTML(pageIDInt int) string` | 手配集計の `<table class="materials-table">` を組み立てる | `RenderComputedViews` |

閲覧者によって中身が変わる（子ページ一覧は read 権限で絞る）ため、`*http.Request` を
受け取って `auth.CurrentUser(r)` を見ます。編集中の変化（子ページ作成など）は自動更新
されず、反映は**再読み込み**です。

#### プラグインが共用する読み取りヘルパ（`vocab_index.go` の後半）

マーカー付き標準HTMLを「機械キー → 値」へ均す層。鍵の決め方は②汎用索引と同じ規則
（見出し／`dt` の表示文字 → レジストリの `Label` 経由で `Field` へ）なので、
プラグインごとに読み方が分岐しません。

| 関数 | 何をするか | 主な呼び出し元 |
|---|---|---|
| `VocabDLFields(dl *html.Node, def VocabDef) map[string]string` | `dl` の項目を機械キー→値の表にする。入れ子の `dl`/`table`/`section` へは降りない。多値は先頭を採る | `plugin_client_order`・`plugin_our_order`（ヘッダdl）・`plugin_estimates`（2形式） |
| `VocabTableRows(table *html.Node, def VocabDef) []map[string]string` | 表のデータ行（2行目以降）を機械キー→値の並びにする。見出し行だけの表は nil | `plugin_client_order`・`plugin_our_order`（明細表） |
| `FirstVocabChild(root *html.Node, element, dataType string) *html.Node` | `root` 配下の最初の `element[data-type==dataType]`（`dataType` が空なら問わない）。**入れ子の `section` へは降りない** | `plugin_client_order`・`plugin_our_order`（各2箇所） |
| `ClosestFileSrc(n *html.Node) string` | 祖先の `<section data-type="file" data-src>` から PDF パスを拾う | `plugin_client_order`・`plugin_our_order`・`plugin_estimates`（2箇所） |
| （内部）`walkSkippingNested(root, skip, fn)` / `nodeText(n)` | 入れ子をまたがない走査／要素配下のテキスト連結（＝表示文字が値） | 上記各関数・`TagValue`／`dlTagValue`（`plugin.go`） |
