## `internal/auth`

| 関数 | 何をするか | 主な呼び出し元 |
|---|---|---|
| `RequireAuth(next)` | 未認証はAPI=401／画面=`/login` へ | `main`（`/api/` 全体） |
| `OptionalAuth(next)` | セッションがあれば載せる。無くても通す | `main`（匿名可ルート） |
| `CSRFProtect(next)` | GET/HEAD/OPTIONS 以外で Origin（無ければ Referer）のホスト一致を要求 | `main`（全体） |
| `CSPProtect(next)` | CSPヘッダを全レスポンスへ | `main`（最外周） |
| `Authenticate(user, pass)` | ロックアウト確認 → ハッシュ検証 → ユーザー組み立て | `LoginAPIHandler` |
| `CreateSession(user)` / `ResolveSession(token)` / `DeleteSession(token)` | セッション（DBにはSHA-256ハッシュのみ） | ログイン／各ミドルウェア／ログアウト |
| `CurrentUser(r)` / `WithUser(r, u)` | コンテキスト経由のユーザー受け渡し | 全ハンドラ／ミドルウェア・テスト |
| `Audit(user, action, target)` | 監査ログ1行 | 保存・権限変更・管理操作 |
