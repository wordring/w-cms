> 利用者のもの、候補と検索は**出どころの側が `page.CanView` で絞る**、発注書は新しい
> ページを作る）。**返信だけは返信元ページの `page.CanView` を見ます**。

> **③計算は索引を `vocab_query.go` 経由でしか読みません。** いま集計は5本あり、
> スコープが2通りです:
>
> - **`RequiredMaterials`**（古い集計・`/api/required-materials`）——`RelatedPages` で
>   スコープを決め（自ページ＋参照でつながるページ・深さ1）→ 受注明細 `client-order-items`
>   → 部品番号タグで `PagesByTag` → `part-materials` → 同じスコープの `our-order-items`。
>   仕入先は**発注書ページの `仕入先` タグ**（`FirstTag`）から（ヘッダと明細を `block_no` で
>   対応づける仕掛けは 2026-09-18 に消えた）。
> - **`ProcurementByProduct`・`UnorderedItems`・`latestMaterialPrices`・`SearchMaterials`**
>   （2026-09-21）——`VocabRowsOfType` で**全社**の受注明細／発注明細を読み、
>   `productOfOrderRow`（`弊社品番` → 無ければ `品番` の逆引き）と `materialKeyOf`
>   （材質＋形状＋寸法）で束ねます。**`RelatedPages` は使いません**（発注書は
>   `発注／年／月` に在って受注ページから2段先——深さ1では黙って0件）。

## 9. 数え方（再現手順）

```bash
# 呼び出し元（テスト・コメント・宣言行を除く）
grep -rn --include='*.go' -F 'SyncIndex(' internal cmd ext \
  | grep -v '_test.go' | grep -vE ':[0-9]+:\s*//' | grep -vE ':[0-9]+:func (\([^)]*\) )?SyncIndex\('

# 公開APIの一覧
go doc ./internal/cms
go doc ./ext/comm
go doc ./ext/subcon
```

**偽陽性に注意**（このプロジェクトで実際に踏んだもの）:

- **メソッド名**——`Name` / `Schema` / `Tables` / `Triggers` / `OnElement` / `OnFile` /
  `Extensions` は複数の型が実装するので、「最初に宣言したファイルへの依存」に見えます
  （`Extensions` は `cms.Extensions()` と `IntakeHandler.Extensions()` の2つ）。
- **同名の別関数**——`SaveAttachment` は `cms.SaveAttachment` と `IntakeContext.SaveAttachment`
  の2つ。`TagValue(` は `dlTagValue(`・`PageTagValue(` にも当たります。`Sanitize(` は
  `htmldoc` の `Sanitizer.Sanitize` にも当たります。
- **同名関数**——`RequireAdmin` は `auth` と `page` の両方にあります（`page` は委譲）。
  `ensureChildByTitle`（連絡帳・小文字）と `EnsureChildByTitle`（コア）も別物です。
- **同一パッケージ内の呼び出し**——`auth.RequireAdmin(` で grep すると `auth` 自身の
  6箇所が漏れます。`page.*` も同じで、`page` パッケージ内からの呼び出しは `page.` が付きません。
- **括弧なしの参照**——`page.DataFileHandler` は `main.go` で `http.HandlerFunc(...)` に
  渡されるだけなので `DataFileHandler(` では当たりません。`RegisterView(…, xxxViewHTML)` の
  ように関数値で渡すものも同じです。
- **コメント内の言及**——件数だけ見て内訳を見ないと外します。
- **語彙やルートの本数**——grep より、**小さな `main` を書いて `cms.VocabDefs()` /
  `cms.PluginRoutes()` / `cms.ExtensionIDs()` / `cms.RequiredPages()` を印字する**ほうが
  確かです（ビルドタグの組ごとに数えられます）。
