# シナリオ別の呼び出し追跡

**対象コミット: `cac2079`（2026-08-27 作成）**

主な操作について、**実際に追える形**で呼び出しの連鎖を並べます。関数名は実在するものだけ、
分岐（403／404／409 になる条件）も併記します。個々の関数の説明は `go doc` が、
呼び出し元の一覧は [【一覧】関数リファレンス.md](【一覧】関数リファレンス.md) が持ちます。

すべてのリクエストは最外周の2つを通ります:

```
CSPProtect  … 全応答へ Content-Security-Policy（strict。'unsafe-inline' なし）
CSRFProtect … GET/HEAD/OPTIONS 以外は Origin（無ければ Referer）とホストの一致を要求
              → 別オリジンなら 403、どちらのヘッダも無ければ 403
```

## 0. 起動

`cmd/w-cms/main.go` の `main()`:

```
database.InitDB()                  … data/cms.db を開き CoreTables＋coreMigrations
cms.DriftedSchemaTables(DB)        … プラグインのテーブル定義のずれを**先に**見る
cms.ApplySchema(DB)                … CREATE TABLE IF NOT EXISTS を流す
  └ ずれがあれば cms.RebuildDatabase()   … 全テーブルDROP→data/master から再構築
cms.RebuildIfNeeded()              … 中断した再構築のやり直し／空DB＋ファイルありの復旧
database.InitAuthDB()              … data/auth.db を開き AuthTables
auth.BootstrapAdmin()              … users が空のときだけ初期管理者
editlock.StartLockReaper()         … 猶予満了を定期評価する goroutine
buildHandler()                     … ルート表（テストのために切り出してある）
http.ListenAndServe(":8080", …)
```

> **ずれの検出は `ApplySchema` より前**でなければ意味がありません（流したあとでは
> 「宣言どおりのテーブルが在る」ように見えてしまう）。

## 1. ページを開く（`GET /{id}`）

`RootHandler`（`handler_view.go`）。**体裁は相手で分かれます。**

```
RootHandler
├ id が "" / "index.html"        → 302 /000000
├ id == "000000" かつ pages に無い → 既定HTMLとサイドカーを作って SyncIndex（初回起動）
├ id に英数字ハイフン以外        → pageNotFound
├ strconv.Atoi 失敗             → pageNotFound
├ pages に行が無い              → pageNotFound
├ requirePageViewable ─────────────────────────────────────────┐
│   認証済み × page.GetPerms(…).CanRead が偽 → forbiddenPage（403・体裁つきHTML）
│   匿名 × page.EffectivePublic が偽
│     └ トップページ(0) → 302 /login?next=…
│     └ それ以外        → notFoundWithLogin（404・戻り先つきログイン導線）
├ os.ReadFile 失敗              → pageNotFound
│
├ body = RenderAnchors( RenderComputedViews( Sanitize(content) ) )
│         ↑ 描画時だけ            ↑ 鏡型の段（walkMirror）  ↑ 二層目の防壁
│
├ 匿名 → servePublicPage
│         RenderPublicShell(body, PageSEO{Title, ExtractDescription(body), CanonicalURL})
│         Cache-Control: public, max-age=600 ＋ Vary: Cookie ＋ ETag
│         If-None-Match 一致 → 304（本文を送らない）
└ 認証済み → RenderPageShell(body, title)
             Cache-Control: no-store
```

**匿名の404は「読めない」と「存在しない」を区別しません**（例外はトップページだけ）。
404画面は `/login?next=…` を持ち、`safeNextPath` が同一サイト内の絶対パスだけに絞ります。

`pageNotFound` は相手で分かれます——匿名は `notFoundWithLogin`、認証済みは素の `http.NotFound`
（読めないページには 403 を返しており、存在を隠していないため）。

## 2. 保存する（`POST /api/save`）

`SaveAPIHandler`（`handler_save.go`）。**順序に意味があります。**

```
SaveAPIHandler
├ メソッドが POST でない        → 405
├ decodeJSONBody（8MiB上限）    → 413 / 400
├ page_id が空                 → 400（新規は /api/new-page を通す）
├ page.NormalizeID             → 400
├ page.RequirePageWrite        → 401 / 403
├ editlock.Locks.Validate      → 409（他者が保持中／トークン失効）
├ page.BumpUpdatedAt           → 500（**サイドカーが読めなければここで止まる**）
├ SanitizeReport(req.HTML)     → safeHTML, sanitized
├ os.WriteFile(<id>.html)      → 500
├ RecordVersion(id, user, safeHTML, force=false)   … 失敗しても**保存は止めない**
├ SyncIndex(id, safeHTML)      → 500
├ auth.Audit(user, "save", id)
└ 200 {html, sanitized, updated_at, unknown_types, unresolved_fields, stripped_ids}
```

`SyncIndex`（`sync.go`）の中身:

```
html.Parse → ParseCore（タイトル）
page.ReadSidecar（親・作成情報・更新日時。読めなければ parent_id は現状維持）
tx = DB.Begin()
  pages を upsert
  page.SyncPageMeta      … サイドカー → page_perms
  各 Observer.OnPageStart … 自テーブルの当該ページ分を DELETE（＝洗い替えの前半）
  IsTemplateArea(id) が偽なら walkers.walkObserve(ctx, root)
    └ 引き金に当たった要素だけを担当へ配る（.vocab-chrome の中は歩かない）
  PageFinisher を実装する Observer があれば OnPageEnd
tx.Commit()
```

> **テンプレート領域は「要素イベントを1つも発火しない」だけ**で除外されます。
> `OnPageStart`（DELETE）は呼ぶので、普通のページをテンプレートフォルダへ移すと
> 古い行が消えます（飛ばす実装だと残る）。

**ブロック保存（`POST /api/save-block`）は版を作りません。** 流れは全文保存とほぼ同じですが、
`ReplaceBlock` で本文をマージしてから書き、`RecordVersion` は呼びません
（対象が無い／重複なら 409 でクライアントが全文保存へ落ちる）。最終状態はロック解放時の
チェックポイントが拾います。

## 3. 編集モードへ入る／抜ける

```
[入る] POST /api/lock?id=
  LockAPIHandler
  ├ page.NormalizeID → 400
  ├ page.RequirePageWrite → 401 / 403
  ├ Locks.TryAcquire
  │   取れない → 423 Locked {holder, same_user, grace_remaining_sec}
  └ 200 {ok, token}   ※**本文は返さない**
  → フロントが GET /api/load を読む（そちらが計算ビューのSSRを通るため）

[購読] GET /api/lock-events   … SSE。presence の実体はこの接続の有無

[抜ける] POST /api/unlock?id=&token=
  UnlockAPIHandler → Locks.Release
                      └ 保持者本人だったときだけ editlock.OnRelease を呼ぶ
                         └ cms 側の init が RecordVersion(…, force=true)
                            （中身が最新の版と同じなら何もしない）
```

**猶予は競合トリガー方式**——誰も待っていなければ無期限、待機者が現れてから2分で明け渡します。

## 4. ページを作る（`POST /api/new-page`）

```
NewPageAPIHandler（handler_tree.go）
├ POST 限定（GET は 405）
│   ※ GET で通ると本文へ <img src="/api/new-page?parent=…"> を1つ置くだけで、
│      開いた全員にページを作らせられる（保存型CSRF）
├ parent が空            → 400（親なしにできるのはトップページだけ）
├ page.RequirePageWrite(parent) → 401 / 403
├ loadTemplateBody       … template= があれば**採番の前に**検証して読む
│                           （採番後に失敗するとファイルの無いページ行が残る）
├ reserveNewPageID       … pages への INSERT で原子的に採番
├ html = 既定文 or FreshenTemplateBody(templateBody, newID)
│                           └ 種まきの段（walkSeed）。空欄を列型の既定値で埋める
├ os.WriteFile(<新ID>.html)
├ page.EnsureSidecar     … owner=作成者・group/mode は親から継承・public は常に false
├ SyncIndex
├ auth.Audit(user, "new-page", …)
└ 302 /{新ID}?edit=true
```

## 5. 添付する

```
[PDF]  POST /api/upload-pdf     UploadPDFHandler
[画像] POST /api/upload-image   UploadImageHandler

どちらも同じ順序:
├ POST 限定（GET は 405）
├ http.MaxBytesReader（32MiB）
├ page.NormalizeID → 400
├ page.RequirePageWrite → 401 / 403
├ editlock.RequireEditLock → 409
├ safeAttachmentName(…) … **名前の守りは1箇所**（サイドカー・本文と同名は拒否）
├ 中身の検査
│   PDF   … 先頭が %PDF-
│   画像  … SniffImageKind（マジックナンバー）＋ 拡張子との一致 ＋ SVG は ValidateSVG
│           HEIC/AVIF/TIFF/BMP は**形式ごとの理由**を返して 400
├ 画像のみ StripImageMetadata … EXIF等を除去（JPEG は向きを画素へ反映して再符号化）
├ os.Stat で上書きかを判定 → os.WriteFile
├ auth.Audit(user, "attach" | "attach.overwrite", "<id>/<名前>")
└ 200 {file_name, src…}

[配信] GET /data/master/<先頭2桁>/<id>/<名前>   page.DataFileHandler
├ path.Clean（.. の解決）
├ page.RequirePageReadOrPublic → 匿名は404／認証済み×権限なしは403
├ <id>.html / <id>.meta.json は配らない（404）
├ X-Content-Type-Options: nosniff
└ 種別で分岐
    .pdf                     … application/pdf（インライン）
    .svg                     … image/svg+xml ＋ attachment ＋ この応答限定の sandbox CSP
    .png/.jpg/.jpeg/.webp/.gif … 実際の種別でインライン
    それ以外                 … application/octet-stream ＋ attachment
```

## 6. 版を戻す（`POST /api/revert`）

```
RevertAPIHandler（handler_version.go）
├ POST 限定
├ decodeJSONBody
├ page.NormalizeID → 400
├ page.RequirePageWrite → 401 / 403
├ editlock.RequireEditLock → 409
├ RevertToVersion(id, version, author)
│   ├ ReadVersion … 版IDは時刻由来の形しか受け付けない（.. や / は 400）
│   ├ **いまの内容を RecordVersion(force=true)**（リバート自体を取り消せる）
│   ├ Sanitize（過去の版も**いまの許可リスト**で濾す）
│   ├ os.WriteFile → page.BumpUpdatedAt → SyncIndex
│   └ 戻した内容も RecordVersion(force=true)
├ auth.Audit(user, "revert", "<id> -> <版ID>")
└ 200 {html}   … エディタが本文を載せ替える
```

**サイドカーは触りません**——権限・所有者・親は現状のままです。

## 7. 削除する（`POST /api/delete-page`）

```
DeletePageAPIHandler（handler_delete.go）
├ POST 限定
├ page.NormalizeID → 400
├ id == "000000"          → 400（トップページは削除できない）
├ page.RequirePageWrite   → 401 / 403
├ editlock.RequireEditLock → 409
├ 子ページの件数を数える  → 409（件数つき。「先に移動するか削除して」）
├ moveToTrash(id)         … data/trash へ**移動**（物理削除ではない）
├ PurgePageIndex(id)      … 空の本文で SyncIndex → page_perms → pages を削除
├ auth.Audit(user, "delete-page", "<移動元> -> <移動先>")
└ 200 {page_id, trash_path}
```

**復元UIはありません。** 戻すには手で `data/master` へ移してDB再構築します。

## 8. ログイン・ログアウト

```
[画面]   GET /login          auth.LoginPageHandler（認証不要）
[認証]   POST /api/login     auth.LoginAPIHandler（認証不要・CSRFProtect は通る）
         ├ loginSem（argon2id の同時実行を4件に制限。1ハッシュ 64MiB）
         ├ Authenticate 失敗 → auth.Audit(username, "login.fail", clientIP)
         │                     302 /login?error=1&next=…
         ├ CreateSession → setSessionCookie
         ├ auth.Audit(user, "login", clientIP)
         └ 302 next（safeNextPath が同一サイト内の絶対パスだけに絞る）
[破棄]   POST /api/logout    auth.LogoutAPIHandler（POST 限定）
         ├ ResolveSession でユーザー名を得てから auth.Audit(user, "logout", clientIP)
         └ DeleteSession → clearSessionCookie → 302 /login
```

**接続元アドレス**（`clientIP`）は、前段がループバック／私設アドレスのときだけ
`X-Forwarded-For` の**末尾**を採ります。無条件に信じると記録される接続元を詐称できるためです。

## 9. クローラ（`GET /sitemap.xml` / `GET /robots.txt`）

```
SitemapHandler … publicPages()（全ページを回して page.EffectivePublic で絞る）
                 → <urlset> ＋ public, max-age=600

RobotsHandler  … database.DB == nil または page.EffectivePublic(0) が偽
                 → "Disallow: /"（サイトが閉じている＝業務インスタンス）
                 → それ以外は /api/ と /login を閉じ、Sitemap: 行を出す
```

絶対URLの基底は `WCMS_BASE_URL` を最優先し、無ければリクエストから組み立てます
（`X-Forwarded-Proto`/`-Host` は前段がプロキシのときだけ採用）。

## 10. フロント側の起動順

```
index.html
├ <head>  boot.js       … **同期**スクリプト。レールの開閉を描画前に確定（FOUC防止）
├ <head>  app.css
├ <body>  …本文はサーバーが合成済み（#w-editor-content に埋まった状態で届く）
└ </body> 直前 app.js   … defer なし。DOMが揃ってから同期実行
             window.onload:
             ├ loadMe() ＋ loadTagSchema()（語彙は保存が走る前に必要）
             ├ 匿名なら applyMode / loadPageMeta / loadChildNav して終了
             └ onModeToggle → loadPageMeta / loadPerms / loadChildNav / loadVersions
```

> `boot.js` も `app.js` も `defer` を持ちません。`<head>` の同期スクリプトが先、
> `</body>` 直前が後、という**書いてある順**どおりに実行されます。
