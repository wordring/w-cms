# シナリオ別の呼び出し追跡

「この操作をすると、どの関数が、どの順で呼ばれるか」。対象コミット `8a05b8b`
（2026-08-17。コードは `4eb3514` から無変更）。
**F** = フロント（`assets/app.js` ほか）、**S** = サーバー（Go）。

---

## 0. 起動

```
main()                                    cmd/w-cms/main.go
  ├─ database.InitDB()                    data/ 作成 → cms.db 接続（WAL・busy_timeout・FK）
  │    └─ CreateCoreTables()              pages / page_perms
  ├─ cms.ApplySchema(DB)                  登録済み全プラグインの CREATE TABLE
  ├─ cms.RebuildIfEmpty()                 pages が空 かつ data/master にHTMLあり → 全再構築
  ├─ database.InitAuthDB()                auth.db 接続＋テーブル作成
  ├─ auth.BootstrapAdmin()                users が空なら WCMS_ADMIN_USER/PASSWORD から初期管理者
  ├─ editlock.StartLockReaper()           1秒ごとに Locks.tick()（猶予満了の評価）
  └─ http.ListenAndServe(":8080", auth.CSPProtect(auth.CSRFProtect(root)))
```

**プラグインの登録はここより前**に済んでいます（各 `plugin_*.go` の `init()` が `Register()` を呼ぶ）。

## 1. ログイン


## 2. ページを見る（`GET /000123`）

```
S  auth.CSPProtect → auth.CSRFProtect（GETは素通り）→ auth.OptionalAuth
     └─ Cookie があれば ResolveSession → LookupUser → コンテキストへ載せる
   cms.RootHandler                        internal/cms/handler_view.go
     ├─ "/" と "/index.html" は 302 → /000000
     ├─ id == "000000" かつ未作成なら既定ページを自動生成（WriteSidecar mode=302）
     ├─ id が英数字ハイフンのみか検査 → strconv.Atoi
     ├─ SELECT file_path, title FROM pages WHERE id = ?
     ├─ requirePageViewable()
     │    ├─ 認証済み: page.GetPerms(id).CanRead(u)   … 不可なら 403
     │    └─ 匿名:     page.EffectivePublic(id)       … 不可なら 302 /login
     ├─ os.ReadFile(filePath)
     ├─ cms.Sanitize(content)             ← 描画時サニタイズ（二層目）
     ├─ cms.RenderPageShell(body, title)  assets/index.html の <!--WCMS_CONTENT--> と <title> を置換
     └─ 200 text/html（Cache-Control: no-store）
```

続いてブラウザがフロントを読み込みます。

```
F  <head> インライン script                レール開閉を localStorage から復元（FOUC防止）
F  app.js（</body> 直前・defer なし）      解析中に実行。関数定義と bindChromeActions()
F  web-components.js（head・defer）        解析完了後に実行。カスタム要素を define
F  window.onload
     ├─ await Promise.all([loadMe(), loadTagSchema()])
     │      loadMe      → GET /api/me      匿名なら body.anonymous を付けてログイン導線
     │      loadTagSchema → GET /api/tag-schema  ← 保存に必須なので先に確定させる
     ├─ syncRailToggleButtons() / initHeadroom()
     ├─ initBlocks()                       本文の各要素を .editor-block で包む
     ├─ buildToc() / setupEditorEvents() / setupAutoSave()
     ├─ 匿名なら: applyMode() → loadPageMeta() → loadChildNav() で終了
     └─ 認証済み: onModeToggle() → loadPageMeta() / loadPerms() / loadChildNav()
```

`web-components.js` は `<head>` にあり `defer` 付きなので、実行は**解析完了後**です。
`app.js` は `</body>` 直前で `defer` 無しのため、解析中＝カスタム要素の `define` より**先**に走ります
（`index.html` にその意図がコメントで書かれています）。

**初期表示で `/api/load` は叩きません**（本文は既にHTMLへ埋まっている）。

### 2a. 匿名の閲覧（公開ページ）

匿名（セッション無し）のとき、`requirePageViewable` は `page.EffectivePublic(id)` で判定します。

```
S  page.EffectivePublic(id)               internal/cms/page/perms.go:226
     └─ 自分から parent_id チェーンを遡り、各ページの page_perms.public を確認
          ・どこかで public=false            → false（画面は 302 /login）
          ・ページ不明・循環・DBエラー       → false（フェイルクローズ）
          ・親なし（ルート）まで公開が繋がる → true
```

フロントは `loadMe()` の結果で `body.anonymous` が付き、分岐します（`window.onload`）。

```
F  匿名: applyMode()（読み取り専用）→ loadPageMeta() → loadChildNav() で終了
        loadPerms() は呼ばない（権限カードは body.anonymous の CSS で非表示）
S  GET /api/page-meta・/api/children は OptionalAuth ＋ RequirePageReadOrPublic
     └─ /api/children は親のゲートを通した後、**子を1件ずつ**
        認証済み= GetPerms().CanRead ／ 匿名= EffectivePublic で絞って返す
        （handler_tree.go ChildPagesAPIHandler。非公開の子は一覧に現れない）
```

`<m-child-list>` を本文に置いた場合も同じ `/api/children` を叩くため、絞り込みは共通です。

## 3. 編集モードへ入る（ロック取得）

```
F  ヘッダのスイッチ change → onModeToggle() → enterEditMode()
     ├─ acquireLock()
     │    └─ POST /api/lock?id=…
     │  S    page.RequirePageWrite()       write 権限が無ければ 403
     │  S    editlock.Locks.TryAcquire(id, user, token="")
     │  S      ├─ 空き → トークン発行・保持者記録・broadcast → 200 {token, html}
     │  S      └─ 他者保持 → 423 {holder, same_user, grace_remaining_sec}
     ├─ （成功）populateEditor(d.html)     ← サーバーの最新本文で載せ替える（古い版で上書きしないため）
     ├─ applyMode()                        body[edit-mode] を付け、構造HTMLを contenteditable に、
     │                                      全カスタム要素へ render() を投げ直す
     ├─ openHolderEvents()                 EventSource /api/lock-events?role=holder&token=…
     │  S    editlock.LockEventsAPIHandler → Locks.subscribe(role="holder") で holderConn=true
     ├─ lastSavedBlocks = ensureBlockIds() > 0 ? null : serializeBlocks()
     └─ resetHistory()                     アンドゥ履歴の起点
```

**失敗（423）時**は `showBusyToast()` ＋ `openWaiterEvents()` で待機者として購読し、
サーバーからの `available` を待ちます（自分では再試行しません）。

## 4. 文字を打ってから保存されるまで

```
F  input／MutationObserver → triggerAutoSave()   1.5秒デバウンス（focusout では即保存）
     └─ saveToServer()
          ├─ 編集モードでなければ何もしない／語彙未取得なら見送る
          ├─ ensureBlockIds()              新ブロックへ data-id を採番
          ├─ serializeBlocks()             DOM → 保存用HTML（語彙は /api/tag-schema に従う）
          ├─ decideSaveStrategy(blocks)
          │     'none'  変更なし           → 何も送らない
          │     'block' 1ブロックだけ変化   → saveBlockToServer()
          │     'full'  構造変化・複数変化  → saveFullToServer()
          └─ pushSnapshot()                アンドゥ履歴へ積む
```

### 4a. ブロック単位保存

```
F  POST /api/save-block {page_id, block_id, html, token}
S  auth.RequireAuth → cms.SaveBlockAPIHandler
     ├─ page.RequirePageWrite()
     ├─ editlock.Locks.Validate(id, user, token)   … 不一致なら 409
     ├─ os.ReadFile(<id>.html)
     ├─ cms.SanitizeReport(req.HTML)               ← 保存時サニタイズ（一層目）
     ├─ cms.ReplaceBlock(current, block_id, safe)  … 見つからない/重複なら 409
     ├─ page.BumpUpdatedAt(id)                     サイドカーの更新日時だけ進める
     ├─ os.WriteFile(<id>.html, merged)
     ├─ cms.SyncIndex(id, merged)                  下記 4c
     ├─ auth.Audit(user, "save-block", id)
     └─ 200 {html, sanitized, updated_at}
F  409 の切り分け: 本文に「編集権」を含む → handleLockLost()
                   それ以外 → lastSavedBlocks=null にして全文保存へフォールバック
F  sanitized=true → applySanitizedBlock()（フォーカス中のブロックは触らない）＋通知
```

### 4b. 全文保存

`POST /api/save` → `cms.SaveAPIHandler`。流れは 4a と同じで、`ReplaceBlock` の代わりに
本文全体を書き換えます。409 は編集権喪失のみ。

### 4c. `SyncIndex`（ファイル → DB）

```
S  cms.SyncIndex(id, html)                internal/cms/sync.go
     ├─ html.Parse()
     ├─ cms.ParseCore(root)               タイトル（最初の h1）だけ
     ├─ page.GetPageDir(id) で file_path 組み立て
     ├─ page.ReadSidecar(id)              親・作成情報・更新日時（正本）
     ├─ tx 開始
     ├─ INSERT INTO pages ... ON CONFLICT DO UPDATE
     ├─ page.SyncPageMeta(tx, ...)        サイドカー → page_perms
     ├─ for p := range cms.Plugins() { p.Sync(tx, pageID, root) }   ← 各プラグインが洗い替え
     └─ tx.Commit()
```

## 5. 2人目が同じページを編集しようとした（競合と明け渡し）

```
B(2人目) F  onModeToggle → acquireLock → POST /api/lock → 423
         F  showBusyToast() ＋ openWaiterEvents()（role=waiter で SSE 購読）
S           Locks.subscribe(role="waiter")
              └─ 保持者が present かつ猶予未設定なら graceDeadline = now + 2分
              └─ broadcast()

A(保持者) F  SSE で {type:"waiter", grace_remaining_sec} を受信
         F  「あと約N分で編集権が移ります」トースト＋「今すぐ編集権を渡す」
              → saveToServer() → leaveEditMode()（releaseLock → 閲覧モード）

S  StartLockReaper の tick(1秒ごと)
     ├─ 待機者あり かつ 保持者不在        → 即削除して broadcast
     ├─ 待機者あり かつ 猶予未設定        → 猶予を張る
     ├─ 待機者あり かつ 猶予満了          → 削除して broadcast
     └─ 待機者なし かつ 猶予あり          → 猶予を解除

A(保持者) F  {type:"lost"} → handleLockLost()
              └─ 本文をクリップボードへ退避 → 閲覧モードへ → reloadContent()
B(2人目) F  {type:"available"} → enterEditMode() を再実行して編集開始
```

**presence は SSE 接続の有無**で決まります（ポーリングしません）。タブを閉じれば
`unsubscribe` が走り、保持者離脱なら即明け渡し、待機者離脱なら猶予キャンセルです。

## 12. アンドゥ・リドゥ（Ctrl+Z / Ctrl+Y）

履歴は編集セッション限り。`enterEditMode()` の `resetHistory(開始時HTML)` が起点、
`leaveEditMode()`・`handleLockLost()` が破棄します。積むのは**保存経路**
（`saveToServer` と各保存関数。app.js:528/555/597）なので、粒度は保存が走る単位です。

```
F  keydown（setupEditorEvents）           Ctrl/Cmd+Z → undo() ／ Ctrl+Y・Ctrl+Shift+Z → redo()
     preventDefault でブラウザ標準 undo を止める（二重スタック防止）。
     カスタム要素内の入力欄からも効く（要素種別の絞り込みより前に処理）
F  undo()
     ├─ undoStack から現在を pop → redoStack へ
     └─ restoreSnapshot({ 1つ前の html, 取り消した編集のキャレット })
          ├─ suppressSnapshot = true      復元を新しい変更として積まない
          ├─ populateEditor(html)         流し込み・ブロック化（保存基準は破棄→次回は全文保存）
          ├─ applyMode()                  contenteditable を付け直す（忘れると打てなくなる）
          ├─ restoreCaret({ blockId=data-id, 文字オフセット })
          └─ triggerAutoSave()            戻した内容を正本へ反映
```

`pushSnapshot` は直前と同一内容なら積まず、上限は `UNDO_LIMIT`=100（超えたら古い方から捨てる）。

```
F  閲覧モードで <m-required-materials page-id=…> の render()
     ├─ テンプレート描画（編集モードはプレースホルダ表示のみで終了）
     └─ GET /api/required-materials?page_id=…
S  RequiredMaterialsAPIHandler            internal/cms/plugin_materials.go（RouteProvider 提供）
     ├─ page.RequirePageRead()
     ├─ ① client_orders(page_id) の order_no → client_order_items から受注明細（item_id, quantity）
     ├─ ② 各 item_id で part_materials(part_id = item_id) を引き、
     │     必要数 = 1部品あたり数 × 受注数 を部材名で積算
     ├─ ③ our_orders(page_id) JOIN our_order_items で発注済数を品名で積算
     └─ Remaining = max(0, TotalRequired − Ordered) を JSON で返す
F  tbody へ行を生成（部材名・仕入先名は escapeText を通す）
```

内容は**保存されません**（閲覧のたびに計算し直す派生表示）。
