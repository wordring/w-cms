## 5. ウェブの見本から読めること（2026-10-17 に筆者が調べた）

紙の請求書によく並ぶ項目は、上から次のとおりです（会計ソフトの会社の解説・国税庁の Q&A による）。

- **請求書番号・請求日**（右上）。請求日は、たいてい締め日の日付にします。取引先の締め日に合わせて書くのがふつうです。
- **宛名**（左上）。会社なら「御中」。
- **発行者**（右側）。会社名・住所・電話。インボイスの登録番号もここに書きます。
- **件名** と、いちばん目立つ所に **今回のご請求額（税込）**。
- **支払期限**・**振込先**（銀行・支店・口座の種類・番号・名義）。
- **明細**。締めでまとめる請求書は、**取引ごとに日付を書く**必要があります。納品書の日付と番号ごとに行を並べる形が分かりやすいです。
- **小計・消費税・合計**。税抜か税込かが分かるように書きます。

インボイス（適格請求書）にするなら、さらに次が要ります。

- 登録番号（T で始まる13桁）。登録番号は、課税事業者として登録した事業者にだけ届きます。登録していなければ、インボイスは出せません。
- 税率ごとの合計と、税率ごとの消費税。
- **消費税の1円未満は、1枚の請求書ごとに、税率ごとに1回だけ**丸めます。明細の行ごとに丸めて足すのは認められません。
- 納品書に税率ごとの消費税を書き、請求書に登録番号を書いて、**2つを合わせてインボイスにする**形も認められています。
- 客先から見ると、インボイスでないと、払った消費税を自分の納める消費税から引けません（仕入税額控除）。だから、客先が課税事業者なら、インボイスを求められることが多いです。

出どころ:
- マネーフォワード クラウド「請求書の書き方」（https://biz.moneyforward.com/invoice/basic/1622/）
- バクラク「請求書の締め日」（https://bakuraku.jp/knowledge/knowledge-invoice/closing-date）
- 国税庁 インボイス Q&A 問57・問67（https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/qa/57.pdf ・ …/67.pdf）

## 6. 答えを受けた案（筆者・2026-10-17）

- **1枚に1社、締め日までの分をまとめます。** 前回の請求額・入金・繰越は載せません（「今回のご請求」だけ）。
- **締め日は、会社ごとに書いておきます。** 連絡帳の組織のページに、タグ `締め日` を置く形を勧めます（値は「末日」か日にち。例: `20`）。
  書いていない会社は「末日」として扱い、請求書を作る画面で直せるようにします。
- **作る場所は2つ考えられます。**
  - 締め日が来たら、会社を選んで「請求書を作る」を押すと、その期間の**発行済の納品書の行**が並ぶ。
  - 受注残表の納品と同じように、行を選んで作る。
  - 筆者の勧めは前者です（締めでまとめるので、期間で集めるほうが漏れません）。
- **単価の決まっていない行は載せません。** その行があるときは、画面で「単価がまだの行が N 行あります」と知らせます（止めはしません。決まったら次の請求書に入れられます）。
- **明細は、納品書ごとに日付と番号を添えて並べます**（締めでまとめるときは取引ごとに日付が要るため）。
- **紙は、納品書の紙と同じ道具で刷ります。** 上の §5 の項目を、同じ並びで置きます。
  - 請求日は締め日。支払期限と振込先は、§7 で決めた所から読みます。
  - 消費税は、1枚ごとに1回だけ丸めます（インボイスにするかどうかに関わらず、そうしておきます）。
- **置き場は `記録／年／月／製造記録`**（月は作った日）。題は「【弊社】請求書　<客先>」、`ページ種類` は `弊社請求書`。
- **1つの納品書の行を、2枚の請求書に載せないようにします。** 載せた行には印が付き、次の請求書の候補から外れます。

## 7. まだ決めること

1. **インボイスの登録をしているか。** 東邦金属工業所として登録していれば、登録番号を紙に刷ります。
   分からなければ、税理士さんか、国税庁の「インボイス制度 適格請求書発行事業者公表サイト」で確かめられます。
   登録していなければ、登録番号の欄を空のまま刷ります（後から書き足せる形にします）。
2. **振込先と登録番号を、どこに書いておくか。** 筆者の勧めは、連絡帳の自社の組織ページ（部材発注書の署名を書いているページ）に、「請求書の振込先」の節と、タグ `登録番号` を置く形です。
   ⚠ 口座番号は、公開しているリポジトリ（設定のファイル `config/settings.json`）には書きません。
3. **支払期限の決め方。** 例: 「翌月末」。会社ごとに違うなら、締め日と同じく組織のページにタグ `支払期限` を置きます。
4. **締め日を書く場所。** 連絡帳の組織のページ（筆者の勧め）か、製造台帳の社名のページか。
