**直さないもの（理由）**

- **列の名前の置き換えの入れ子の表**: 本番に入れ子の表はありません。衝突の確かめが錠の外にあるのも、`RewriteBody` の中でもう一度確かめるので害がありません。
- **「向き」のタグを消してすり抜ける**: 組「通信」に人がいないので届きません。`向き` を `fixed` にすると、人が書く記録の作り方に響くので、人を入れるときに決めます。
- **`CreateChildPage` のサイドカーの書き込みの失敗**: ディスクが書けないときなので、ログのまま。`SyncIndex` が失敗すると誤りを返しますが、ページはできていて、索引はあとで直ります（呼び手が作り直すと2枚になりえます。`SyncIndex` の失敗自体がまれなので、そのまま）。
- **作り直しの途中の `EnsureFolder`**: 作り直しは管理者が押すもので、短いあいだです。
- **`handler_reorder.go`**: 並び順だけです。**`tables_db.go` の `page_id` 列**: 運用しだいです。
- **公開まわりの小さなもの**（`WCMS_BASE_URL`・`max_upload_mib` の上限）: 本番の公開ページは 0 枚で、設定を書くのは管理者です。
- **`webpush.go` のプロキシ**: 本番にプロキシはありません。
- **遅くなるだけのもの**（`IsTemplateArea`・管理画面の一覧・`AssignBlockID`・列の置き換え・通知の送り方・SSE の本数・Gemini の時間）: 実際に困っていません。
- **`boot_data.go`**: 同じ要求の中なので、panic は net/http が拾います。ページを開くのも操作なので、操作に数えるのも害がありません。
- **`VocabNumber` の小数**: 読み手の `VocabQuantity` は、古い集計と注文の数量です。`個数` は語の値の範囲で整数と決めています。使う場所が増えたら直します。
- **`validateParentChange` の 401/403 が 400 になる**: 画面は文を見せるだけなので、そのままにし、コメントだけ直しました。
