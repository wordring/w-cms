- 納品済を発注済へ戻したとき、在庫表から引く数は、戻したときに数え直します（入れたときの数と同じとは限らない）。入れた数をどこかに控える形は、在庫の記録の 5 番（仮の在庫を外す）と一緒に決めます（【考察】在庫の記録 §6.6）。
- web の通知の取り消し（`/api/push/unsubscribe`）は、だれの受け口でも消せます。共用の PC で、前の人の受け口を消すための作りです。受け口の住所は長い秘密で、消されても通知が止まるだけです。
- ローカル編集の鍵を住所（`?token=`）で受けるのは、古いヘルパーのために当面残しています。どの PC のヘルパーも入れ替えたら外します。
- 機械が ID の無いブロック（テンプレートから作ったページ）を書き替えると ID が変わり、書きかけの人の保存がぶつかる件（§2.1）は、まだです。
