# 【考察】現品票の印刷

> 2026-10-23 利用者:「ubuntuにブラザーql800を繋げて現品票を印刷しようと思います。納品用と塗装、メッキ等の表面処理用途なります。接続方法とエディタ画面を提案してください。」

現品票は、品物や箱に貼る小さな札です。何が・いくつ・どこへ行くかを書きます。
この文書は、ブラザーのラベルプリンター QL-800 を職場のサーバー機（Ubuntu）につないで、w-cms から現品票を刷る形の案です。
問いは §6、答えは §6.1 です。2026-10-30 に作りました（§7）。

## 1. 何に使うか

使い道は2つです。

- **納品用**: 客先へ納める品物に貼ります。納品書と同じ中身（客先・品番・品名・数量・注文番号・納品日）を、品物ごとに1枚にします。
- **表面処理用**: 塗装・メッキなどの業者へ出す品物に貼ります。部材発注書の外注加工の行から作ります（業者・品番・加工部品番号・数量・表面処理の中身・戻りの納期・発注書番号）。

どちらも、w-cms にもう書いてある行から作ります。人が同じことを書き写さないためです。

## 2. QL-800 について知っておくこと

- **つなぎ方は USB だけです。** QL-800 には LAN も Wi-Fi もありません（LAN があるのは QL-820NWB、Wi-Fi は QL-810W）。
  だから、刷る機械（サーバー機）の近くに置くことになります。
- **ロールの幅は最大 62mm です。** 長さは、長尺のロール（DK-22205 など）なら自由に決められます。決まった大きさのラベル（DK-11209 など）もあります。
- **赤と黒の2色が刷れます。** 赤黒のロール（DK-22251）を使ったときだけです。表面処理の札で、色や処理の名前を赤にする使い方ができます。
- **解像度は 300dpi です。** 小さな字と QR コードも読めます。
- ⚠ **「Editor Lite」の灯りを消しておくこと。** 灯りが点いていると、パソコンからは USB メモリに見えて、プリンターとして使えません。ボタンを長押しして灯りを消します（取扱説明書で確かめてください）。

## 3. つなぎ方の案

### 案A: サーバー機に USB でつなぎ、w-cms が直接刷る（おすすめ）

- QL-800 をサーバー機の USB につなぎます。Ubuntu では `/dev/usb/lp0` のような名前で見えます。
- w-cms が札の絵を作り、ブラザーが公開している手順（ラスターコマンド）でプリンターへ送ります。
  手順書は [QL-800/810W/820NWB の Software Developer's Manual](https://download.brother.com/welcome/docp100278/cv_ql800_eng_raster_101.pdf) です。
- よいところ:
  - **どの端末からでも刷れます。** 現場のスマホで「🏷 現品票」を押すと、サーバー機の横の QL-800 から出ます。
  - 外の部品が要りません。Go の標準ライブラリだけで書けます（開発方針 §1）。QR コードは、w-cms の中にもう作る道具があります（`internal/cms/qr.go`）。
  - 用紙の設定などを、Ubuntu の印刷の設定（CUPS）に頼りません。CUPS は古い形のドライバー（PPD）をやめる方向なので、先々の手間が減ります。
- 気をつけること:
  - プリンターはサーバー機の近くに置きます。現場が離れているなら、USB の延長か、案C を考えます。
  - w-cms を動かす利用者に、`/dev/usb/lp0` へ書く権限を与えます（グループ `lp` に入れる）。手順は導入のときに書きます。

### 案B: サーバー機に USB でつなぎ、Ubuntu の印刷（CUPS）で刷る

- ブラザーの Linux 用ドライバーを入れ、w-cms は PDF を作って印刷へ回します。
- よいところ: 印刷の待ち行列や、ふつうの印刷の道具がそのまま使えます。
- 気をつけること: ドライバーの入れ方と、Ubuntu の版ごとの相性を確かめる必要があります。案A より手間がかかる見込みです。

### 案C: 現場のパソコン（Windows）に USB でつなぎ、ブラウザから刷る

- w-cms は札の大きさに合わせた印刷用の画面を出し、人がブラウザの印刷で QL-800 を選びます。
- よいところ: サーバー機に手を入れません。すぐ始められます。
- 気をつけること: そのパソコンからしか刷れません。ブラウザの印刷の設定（余白・用紙の大きさ）を毎回そろえる必要があります。

筆者のおすすめは **案A** です。まず案C で札の中身と大きさを決め、サーバー機が動いたら案A に移る、という順も取れます。

## 4. 画面の案

⚠ 表の中にボタンは置きません（2026-10-21 の決まり）。操作は表の下の帯に置きます。

### 4.1 どこから刷るか

- **納品用**: 納品書ページ（製造ページの納品作業から作るもの）の納品明細表の下の帯に「🏷 現品票」を置きます。
- **表面処理用**: 部材発注書ページの部材発注明細表の下の帯に「🏷 現品票」を置きます。外注加工の行だけが候補になります。
- 行の先頭のチェックで、刷る行を選びます（何も選ばなければ全部の行）。

### 4.2 押すと開く欄

「🏷 現品票」を押すと、帯の下に欄が開きます。

1. **行の一覧**: 選んだ行が並びます。行ごとに次のものを直せます。
   - **枚数**: 何枚刷るか。既定は1枚です。
   - **箱に分ける**: 数量を箱ごとに分けます。たとえば 40個を「20・20」と書くと、「1/2 箱 20個」「2/2 箱 20個」の2枚になります。
   - **一言**: その札にだけ足す言葉（「上下注意」など）。
2. **見本**: 実際の大きさに近い形で、1枚目の札を見せます。行を選ぶと、その行の札に替わります。
3. **刷る**: 「🖨 QL-800 で刷る」で刷ります（案A）。案C のときは「🖨 印刷の画面を開く」です。
   刷り終わったら「○枚を刷りました」と出ます。プリンターが答えないとき（電源・紙切れ・Editor Lite の灯り）は、その理由を出します。

札の中身は本文に保存しません。刷った記録だけを、そのページの「刷った現品票」の節に残す案もあります（§6 の問い5）。

### 4.3 札の中身の案（62mm 幅）

**納品用**（62mm × 約 70mm）

- いちばん上に「現品票」と客先の正式名称（連絡帳の「正式名称」・2026-10-23 から）。
- 大きく品番。その下に品名。
- 数量（箱に分けたときは「1/2 箱　20 個」）。
- 注文番号・納品日・弊社の名前。
- 右下に QR コード（その納品書ページを開く）。

**表面処理用**（62mm × 約 70mm・赤黒のロールなら処理の行を赤）

- いちばん上に「表面処理　現品票」と業者の名前。
- 大きく品番と加工部品番号。
- 表面処理の中身（「塗装　黒」「無電解ニッケル」など。外注加工表の「表面」「仕様」から）。
- 数量・戻りの納期・発注書番号。
- 戻り先（弊社の名前）。
- 右下に QR コード（その部材発注書ページを開く）。品物が戻ってきたとき、読めばすぐ発注書が開きます。

## 5. コアと拡張のどちらに置くか（開発方針 §0）

- **プリンターへ送る部分**（札の絵を QL-800 の手順で送る・プリンターの状態を読む）は、業務の言葉を持ちません。
  ほかの会社が同じ仕組みでラベルを刷るときにも使えます。
- **現品票の中身**（どの表のどの列を札に載せるか・納品用と表面処理用の形）は、東邦の業務です。拡張（`ext/toho`）に置きます。
- プリンターへ送る部分を、コアに置くか、業務の言葉を持たない別の拡張（たとえば `ext/label`）に置くかは、利用者に決めてもらいます（§6 の問い1）。
  筆者の勧めは別の拡張です。ラベルプリンターを使わない会社では、外してビルドできるからです。

## 6. 問い

1. プリンターへ送る部分の置き場は、コア・別の拡張（`ext/label`）・東邦の拡張のどれにしますか。筆者の勧めは別の拡張です。
2. つなぎ方は、案A（サーバー機に USB・w-cms が直接刷る）でよいですか。サーバー機と QL-800 を置く場所は近いですか。
3. ロールは何を使いますか（62mm の長尺・決まった大きさ・赤黒）。表面処理の札を赤黒にしますか。
4. 札に載せる項目は、§4.3 の案でよいですか。足すもの・外すものはありますか（材質・図面番号・装置名 など）。
5. 刷ったことを記録しますか（いつ・誰が・何枚）。記録するなら、そのページに節を足すか、監査の記録だけにするかを決めます。
6. 納品書・部材発注書のほかに、刷りたい所はありますか（製造ページから、加工製品ページから、在庫表から など）。

### 6.1 答え（2026-10-30）

> 2026-10-30 利用者:「サーバーにQL-800を接続しました」

- 問い1: プリンターへ送る部分は、別の拡張 `ext/label` に置きます（筆者の勧めのとおり）。
- 問い2: 案A です。QL-800 は業務サーバーの USB（口 1-8）につながり、`/dev/usb/lp0` に見えています（グループ `lp`）。
- 問い3: 62mm の長尺（黒）です。赤黒にはしません。
- 問い4: 札の項目は §4.3 の案のままです（使ってみてから足し引きします）。
- 問い5: 刷ったことは、監査の記録だけに残します（いつ・誰が・何枚）。ページの本文は変えません。
- 問い6: いまは納品書と部材発注書の2つだけです。

### 6.2 つないで確かめたこと（2026-10-30）

- 状態の問い合わせ（`ESC i S`）には、誤りなし・62mm の長尺（媒体の種類 0Ah）と答えました。
- 文字だけの試しの札（約 30mm）を1枚刷り、「刷り終わった」（状態の種類 01h）の答えが返りました。台本は手順書の流れのとおりです（初期化 → ラスターの形 → `ESC i z` → 自動で切る → 余白 35 点 → 1行 90 バイトを `g` で送る → `1Ah`）。
  - QL-800 は、圧縮（`M`）と、空の行の命令（`Z`）を受けません。行は全部 `g` で送ります。
  - 62mm の長尺は、720 ピンのうち左右 12 ピンずつが余白で、印字は 696 点です。
  - 1枚目は、右で切れた分が左に出ました。試しの台本が Ghostscript の白黒の絵（P4）の頭を2行と決めて読み、間の説明の行（`# Image generated by …`）の分だけ行の始まりがずれたためです。頭を読み直して直りました。w-cms で作るときは、絵を Go の中で描くので、この形は通りません。
- ⚠ **自動で電源が切れること**: 手順書（Raster Command Reference）には、自動で電源を切る時間を変える命令が載っていません。電源が切れると、USB の機器ごと消えます（w-cms からは起こせません）。
  - 2026-10-30 利用者:「QL-800は勝手にdふぇん減が切れるかもしれませんが、対策は出来ますか？」
  - 対策の案は次の2つです。①プリンターの設定で、自動で切る形をやめる（ブラザーの Windows 向けの設定の道具で変える見込み・まだ確かめていない）。②w-cms が刷る前に状態を問い、電源が切れていれば「QL-800 の電源が切れています」と言って刷らない。電源を入れ直せば同じ名前で見えるので、w-cms を起こし直す必要はありません。

## 7. 作ったもの（2026-10-30）

> 2026-10-30 利用者:「正しい・作り始めて」

- **プリンターの道具** `cmd/w-cms-label`: プリンターの口を持つのはこの道具だけです（w-cms は守りのため機械の部品に触れない）。w-cms とは Unix ソケットだけでやりとりします（電話をかける道具と同じ形）。札の中身は知らず、白黒の絵を命令にして送り、刷り終わるのを待ちます。置き方は `deploy/label/README.md` です。
- **ラベルの拡張** `ext/label`（問い1の答え）: 札を1ページ1枚の PDF で受け取り、mutool で 300dpi の白黒の絵にし、時計回りに 90 度回して道具へ渡します。画面の `GET /api/label/state` は、いま刷れるか（電源・ロール・ふた）を答えます。
- **現品票** `ext/toho/genpin.go`: 納品書の納品明細表・部材発注書の部材発注明細表（外注加工の行だけ・取り消した行は除く）の下に「🏷 現品票」。押すと、行ごとに刷るか・枚数・箱の分け方（「20,20」）・一言を決める欄と、刷るのと同じ白黒の見本が出ます。「🖨 QL-800 で刷る」で刷ります。
  - 札は横 100mm × 62mm です（2026-10-30 利用者:「現品票は上下62ミリで横に長く使っています。大きな文字で印刷しています」）。品番をいちばん大きく、入らなければ字を小さくします。
  - 刷ったことは監査の `genpin.print`（ページと枚数）だけに残します（問い5）。本文は変えません。読める人なら刷れます。
  - 見本は GET の絵です（CSP が `blob:` の絵を許さないため）。
- 確かめたこと: Go の試験・E2E `verify-genpin.js`（試験用）。本番の納品書から1枚刷り、道具が「1 枚を刷りました」と記録しました。
- 札の向き・字の大きさ・並びは、本番で刷った札を見て、いまの形に決まりました（2026-10-30 利用者:「これでよい」）。
- 刷る前に電源を確かめます（2026-10-30 利用者:「印刷ボタンを押したときにプリンターの電源を調べて、電源を入れるように警告できますか？」）。「🖨 QL-800 で刷る」を押すと、まずプリンターの様子を聞き直し、電源が入っていなければ、欄と通知に「QL-800 の電源が入っていません。電源ボタンを押して電源を入れてから、もう一度…」と出して送りません。サーバーの `/api/genpin/print` も、札を絵にする前に同じ確かめをします（`genpinPrinterProblem`）。電源が切れていても刷るボタンは押せます（押したときに確かめる）。
- まだのこと: 自動で電源が切れる設定（§6.2）を、プリンターの側で変えるかは利用者が決めます。
