## 2. 決まったこと

- **トップ直下に「製造」を1つ置きます。** その下に、案件ごとの製造ページが並びます。開けば、いま進んでいる仕事が全部見えます。
  - 品物の台帳は「製造台帳」、進行中の仕事は「製造」です。名前は分かれています。
- **1つの案件は、見積の依頼から納品までです。** 見積だけで終わる案件も入ります。
- **1つの案件は1社です。**
- **案件の書類は、その製造ページに並べます。** 見積の依頼・部材見積依頼・見積計算書・見積書・部材発注・製造記録（工数など）・納品書です。
  - ⚠ そのかわり、**いくつもの案件にまたがる書類は作りません**（利用者:「そこは割り切って」）。
    同じ業者への部材発注書も、同じ客先への納品書も、案件ごとに1枚になります。
- **請求書だけは例外です。** いままでどおり、締め日で客先ごとにまとめ、記録の年月に置きます（【考察】請求書）。
- **残りの数の一部だけで、案件を始めることがあります。** 100個の注文のうち、先に40個だけ作る、という形です。
- **案件が終わったら、製造ページは記録の年月へ移ります。** 請求書を出した時点です。

## 3. 形（筆者の案）

### 3.1 製造ページ

- 置き場は `製造／製造ページ`（年月で分けません。進んでいるものだけが並ぶので、多くはならない見込みです）。
- 題は「<客先>　<最初の品名>」（品物が2つ以上なら「ほか N 件」を添える）。`ページ種類` は「製造」。製造番号はページ番号です。
- タグ: 製造番号・客先・始めた日・ページ種類。
- **製造明細表**: この案件で作る品物の表です。
  - 列は 弊社品番・受注（受注ページ。見積の段階では空）・品番・品名・数量（この案件で作る数）・単位・納期・製造完了・備考。
  - 受注の行から作るときは、受注明細から写します（人が品番を打たない）。
- **書類は、この製造ページの子です。** 見積計算書・部材見積依頼書（とその返事）・見積書・部材発注書・製造記録・納品書。
- **鏡「この製造の請求書」**: この製造の行が載った請求書へのリンクを出します（請求書は記録の年月にあるため）。

### 3.2 作業の帯（製造ページの上）

製造明細表の行を選んで、作業を始めます。作った書類は、この製造ページの子になります。

- 見積計算書を作る（選んだ行の加工製品ごと）
- 部材見積依頼（選んだ行の部材を、見積依頼必要部材表へ）
- 見積書を作る（客先へ）
- 部材発注書を作る（選んだ行の加工製品の部材 × この案件で作る数）
- 製造完了（行ごとのチェック）
- 納品書を作る（今回納める数を直せる）

### 3.3 入口は2つ

- **注文から始める**: 受注残表で行を選び、「🏭 製造開始」を押します。
  - 今回作る数が初めに入っていて、直せます（一部だけで始めるため）。初めの数は「残りのうち、まだどの製造にも入っていない数」です。
  - 1社の行だけを選べます（違う客先の行は止めます）。
  - 受注残表では、製造に入った行に「製造中」の印とリンクが付きます。
- **見積から始める**: 見積の依頼が来たときに、品物（加工製品）と数から製造ページを作ります。
  - あとで注文が来たら、受注残表で行を選び、「既にある製造に入れる」でこの製造ページに結びます。

### 3.4 終わり方

- **請求書を出したとき**: その製造ページの行が全部、発行済の請求書に載ったら、機械が記録へ移します。
  移す先は、その請求書の月の `記録／年／月／製造記録` です。分納で一部だけ請求したときは、残りを請求するまで「製造」に残ります。
- **見積だけで終わったとき**: 製造ページの「この製造を閉じる」で、閉じた日の月の記録へ移します。

### 3.5 いまある仕組みとの関係

- **受注ページ**（客先の注文書）は、いままでどおり `記録／年／月／依頼` に置きます。客先の紙で、いくつもの案件にまたがることがあるためです。
- **受注残表**は「受注」のページに残ります。行を選ぶ所が、いまの「部材見積依頼へ」「納品書を作る」に「製造開始」が加わる形です。
- **トップ直下の「見積」「部材見積依頼」「部材発注」の入口**（見積書を作る・再部材見積依頼・必要部材表・発注部材表）は、製造ページの形が使えるようになるまで残します。片付けるかは、使ってから決めます。
- **過去の書類**は、いまの記録の年月に置いたままにします（移しません）。

## 4. 割り切ったことで変わること

- 業者に届く部材発注書が増えます（同じ業者でも、案件ごとに1枚）。
- 同じ客先へ同じ日に2つの案件を納めると、納品書は2枚になります。
- 必要部材表（全部の受注残から部材を数える表）は、案件ごとの表になります。

## 5. 書類の置き方を決めるときに考えたこと

筆者は初め、「書類は記録の年月に置き、製造ページには鏡で一覧を出す」を勧めました。理由は、①1枚の書類がいくつもの案件にまたがる ②製造より前にできる書類がある ③置き場の決まりが1つで済む ④製造ページを移すのが簡単、の4つでした。

利用者は、見積も製造に入れ（②が消える）、またがる書類は作らないと割り切りました（①が消える）。請求書だけを例外にして、締めでまとめる形を残しました。

3. **製造ページの題**は「<客先>　<最初の品名>」でよいですか？
