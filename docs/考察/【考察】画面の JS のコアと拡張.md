## 1. いまの形（2026-10-20 に調べた）

- サーバーは、もう拡張ごとに分かれています。拡張は `init()` で `cms.RegisterExtension` などを呼び、登録の口でコアに載ります。
- 画面の JS は、ほぼ全部が1本の `assets/app.js`（12,884 行）です。東邦と通信の働きも、この中にあります。
  - 東邦の配線は、後ろにまとまっています（10,745 行目から最後まで、約2,100 行）。
  - 整理の欄・メールの飾り・電話・連絡先などは、前半に散らばっています。
  - モードを切り替えるたびに飾りを付け直す一覧（`applyMode` の中）が、業務の飾りを名指しで呼んでいます。
- ファイルどうしは `window.` の名前で呼び合っています。`app.js`（コア）が `mail-compose.js`（通信）の `window.wcmsMailCompose` を呼んでいるのは、向きが逆です。

## 2. 決めたこと

### 2.1 向きは1つ

- 拡張の JS はコアの JS を借りてよい。コアの JS は拡張の JS を借りない（名前も呼ばない）。
- コアが拡張の働きを呼びたい所は、コアが口を用意し、拡張がそこに自分を登録します（サーバーの `RegisterMirror` と同じ形）。

### 2.2 コアが渡すのは `window.wcms` の1つ

- コアの `app.js` は、拡張に渡す道具と口を `window.wcms` にまとめます（凍らせて、拡張が書き換えられないようにする）。
- 拡張の JS は `window.wcms` だけを使います。ここに無いコアの中身には手を出しません。
- 足すときは必要な分だけにします（口が増えすぎると約束が太る）。
- 最初の版の中身は、次のとおりです。
  - 口: `onChrome(fn)`——モードを切り替えるたび（と読み直したとき）に、飾りを付け直す。登録が遅れても、もう描いたあとならすぐ1度呼ぶ。拡張の飾りが落ちても、コアは止まらない（呼び出しを包む）。
  - 道具: 要素を作る（`makeEl`・`makeButton`）・JSON を送る（`jsonPost`・`postJSON`・`readResult`・`failMessage`）・知らせる（`notify`）・ページの番号（`pageId()`）・タグの値（`tagValue`）・拡張が載っているか（`hasExtension`）・本文の欄（`editorContent()`）・読み直す（`reloadContent`・`loadChildNav`）など。

### 2.3 拡張の JS は、拡張の置き場に置き、拡張が登録する

- 拡張の JS は、その拡張のフォルダに置きます（例: `ext/comm/assets/comm.js`）。
- 拡張は `init()` で `cms.RegisterScript` を呼んで、自分の JS を名乗ります。サーバーは `/assets/ext/<拡張>/<ファイル>` として配り、殻（`index.html`）の `<!--WCMS_EXT_SCRIPTS-->` に `<script src>` を差し込みます。
- ビルドで外した拡張は、登録しないので、その JS も配られません。
- `assets/` と同じく、ディスクから配ります（入れ替えなしで直せる・E2E の写しの道具がそのまま使える）。配り方も `assets/` と同じ `no-cache` です。

### 2.4 モジュール（import／export）は、あとで決める

- いまの `app.js` は地続きで、全部をモジュールにすると書き直しになります。
- 先に `window.wcms` の形で、コアと拡張を別のファイルに分けます。分け方が固まってから、モジュールにするかを決めます（筆者の勧め）。

## 3. 進め方

1. 最初の1本: 通信の記録ページの飾り（作るページ・返信・やりとりの前後・この記録への返信）を `ext/comm/assets/comm.js` へ移す。
2. 東邦の後ろの約2,100 行を `ext/toho/assets/` へ移す。
3. 前半に散らばった業務の部分（整理の欄・電話・連絡先・業務の語の名残など）を、口を作って移す。`mail-compose.js` も通信の置き場へ。
4. 番人: コアの JS に業務語が無いこと、コアが拡張の名前を呼ばないこと、拡張を外したビルドで画面にエラーが出ないこと。

どの段も振る舞いは変えません。`app.js` は写しで直し、E2E を通してから書き戻します。

### 4.2 東邦の後ろの配線（2026-10-20 昼・職場）
