# 【考察】製造単位の部材発注

> 状態: **考え中**（2026-10-21）。案と問いだけです。まだ作っていません。

製造の単位（案件をまとめた製造ページ）ごとに必要な部材を数え、それをまとめて部材発注書を作る形を考えます。
2026-10-21 に、臨時部材表・必要部材表・手配不要表をいったん外しました（[【考察】案件残から製造へ.md](【考察】案件残から製造へ.md) §7）。
この文書は、その作り直しの考えです。

## 1. 話の流れ（利用者の言葉）

> 2026-10-21 利用者:「臨時部材表と手配不要表もなくし、必要部材表もなくしてください。」

> 2026-10-21 利用者:「一度無くして、適切な形で作り直します」

> 2026-10-21 利用者:「案件をまとめた製造単位ごとに必要部材を集計し、集計した表をさらにまとめて発注書を作るのも良いと思います」

> 2026-10-21 利用者:「製造単位ごとに必要部材を集計し、それをまとめて発注書を作る形を考えましょう。まず【考察】に案と問いを書いてください。」

## 2. いまの形（2026-10-21）

言葉の説明です。

- **製造ページ**: 案件明細の行をいくつか（1社）まとめた、製造のひとまとまりです。トップ直下の「製造」の下にあります。
- **部材**: 加工製品ページの部材の表（材料表・外注加工表・購入部品表・支給部品表）の行です。種類ごとの運び方は設定 `order_kinds` にあります（[【考察】部材の種類ごとの発注項目.md](【考察】部材の種類ごとの発注項目.md)）。
- **発注部材表**: 部材発注書を作る前の、下書きの表です。仕入先ごとに1枚にします。
- **部材発注書**: 仕入先へ出す紙と、そのページです（1枚に1社）。

いまの流れは、次のとおりです。

1. 製造ページの「📦 この製造の部材を発注部材表へ」を押すと、この製造でまだ手配していない部材が、製造ページの中の新しい発注部材表に入ります（`/api/mfg/parts`）。
   - 数は「この製造で作る数 × 1個あたりの数」と「案件×加工製品で、まだ手配していない数」の小さいほうです（`mfgPartLines`・`UnorderedItems`）。
   - 手配済みは、部材発注明細表と発注部材表の行の「案件」の列で、案件ごとに引きます。
2. 発注部材表の足元の欄で、仕入先と差出人を選んで「部材発注書を作る」を押すと、部材発注書ができます。置き場は、その製造ページの子です。
3. 部材発注書を送ると、行が発注済になります。

いまの形の足りない所です。

- **製造をまたいでまとめられません。** 発注部材表は製造ページの中にあり、部材発注書は1枚の発注部材表から作ります。2つの製造で同じ材料を使っても、別々の部材発注書になります。
- **全部の部材が、いっぺんに1枚の発注部材表に入ります。** 材料屋・塗装屋など仕入先ごとに分けるのは、人が行を動かす仕事です。
- **手配不要（在庫で足りる・自社で作る）を書く所がありません**（手配不要表を外したため）。
- **案件に結び付かない部材（消耗品・工具・社内用）を発注する道がありません**（臨時部材表を外したため）。

## 3. 案（筆者）

### 3.1 2つの段に分ける

**段1: 製造ごとに数える（製造ページの「必要部材」）**

- 製造ページに、この製造の必要部材を出す欄（ビュー）を置きます。保存しない、表示のたびに数える欄です。
- 1行は「加工製品 × 部材」です。列は、種類・品名（材質・形状・寸法 など）・必要数・手配済み・残り・仕入先（後述）です。
- 手配済みは、この製造の案件の行に結んだ部材発注明細の行から数えます（いまと同じ「案件ごと」）。
- 行ごとに「手配不要」を付けられるようにします（理由つき）。記録は、この製造ページの中に置きます（§3.4）。

**段2: まとめて発注する（「製造」の置き場の「まとめて発注」）**

- 「製造」の置き場に、開いている製造ページ全部の「残り」を集めた表を出します。
- **仕入先ごとに**分けて並べます。同じ部材（同じ種類・材質・形状・寸法・表面）は、製造をまたいで**1行にまとめて数を足します**（どの製造・案件の分かは、行の内訳に残します）。
- 行を選んで「部材発注書を作る」を押すと、その仕入先の部材発注書が1枚できます（発注部材表を挟まずに直接）。
- 部材発注書の置き場は `記録／年／月／製造記録` です（いくつもの製造にまたがるため）。各製造ページからは、自分の分を含む部材発注書が見えるようにします（鏡）。

### 3.2 まとめた行と、二重に発注しない仕組み

- 部材発注書の明細の1行が、いくつもの案件の分を含みます。
  案: 明細の「案件」の列に、案件ページの番号を「、」で並べ、内訳（案件ごとの数）は「内訳」の列（紙には刷らない）に書きます。
  例: 案件 `001452、001460`・内訳 `001452:20、001460:10`・数量 `30`。
- 手配済みの引き算は、この内訳から案件ごとに数えます。だから、製造を取り消して別の製造で始め直しても、二重に発注しません（いまの「案件ごとに引く」を続ける）。

### 3.3 仕入先の決め方

- 案: 加工製品ページの部材の表に「仕入先」の列（任意）を置き、そこに書いてあれば初めからその仕入先に分けます。無ければ「仕入先未定」の組に入り、まとめる画面で人が選びます。
- 種類ごとの決まり（材料はいつもの材料屋、など）は、設定 `order_kinds` に「既定の仕入先」として持たせる案もあります。

### 3.4 手配不要と、案件に結び付かない部材

- **手配不要**: 製造ページの中に「手配不要表」を置きます（製造ごと・理由と日付）。段1の「残り」から引きます。製造を閉じれば、記録と一緒に記録の年月へ移ります。
- **案件に結び付かない部材**: 案は2つです。
  - 案A: 「製造」の置き場の「まとめて発注」の表の下に、手で書く行（臨時の行）を置く。
  - 案B: 案件の無い製造ページ（例: 「社内用・消耗品」）を作り、その中に手で部材を書く。どの部材も、いつも製造ページから来る形にそろう。

### 3.5 作る順（案）

1. 段1: 製造ページの「必要部材」のビュー（数えて見せるだけ）。
2. 段2: 「製造」の置き場の「まとめて発注」と、部材発注書を直接作る口（内訳つき）。
3. 手配不要（製造ページの中）。
4. 仕入先の列と、既定の仕入先。
5. 案件に結び付かない部材（§3.4 の案A か案B）。
6. 製造ページの「📦 この製造の部材を発注部材表へ」と、製造ページの中の発注部材表の扱いを決める（残すか、まとめる画面へ寄せるか）。

## 4. 問い

1. **まとめる範囲**: 「まとめて発注」には、開いている製造ページ全部を出しますか。それとも、まとめる製造を選んでから出しますか。
2. **同じ部材を1行にまとめるか**: 製造をまたいで同じ部材（同じ材質・形状・寸法・表面）を1行に足しますか。それとも、行は製造（案件）ごとのまま、同じ部材発注書に並べますか。
   1行にまとめる場合、紙には合計の数だけを刷り、内訳は w-cms の中だけに残す、でよいですか。
3. **仕入先の決め方**: 部材ごとに「いつもの仕入先」を加工製品ページに書きますか。それとも、発注のたびに選びますか。種類ごとの既定（材料は○○）でよいですか。
4. **発注部材表を残すか**: いまは「発注部材表（下書き）→ 部材発注書」の2段です。まとめる画面から直接部材発注書を作る形にして、発注部材表をなくしてよいですか。
5. **手配不要の置き場**: 製造ページの中（製造ごと）でよいですか。在庫を「この製造に回した」という記録として扱ってよいですか。
6. **案件に結び付かない部材**: §3.4 の案A（まとめる画面に手で書く行）と案B（案件の無い製造ページ）の、どちらがよいですか。
7. **部材発注書の置き場**: 製造をまたぐ部材発注書は `記録／年／月／製造記録` に置き、製造ページからは鏡で見る、でよいですか。1つの製造だけの部材発注書は、いまどおり製造ページの子でよいですか。
8. **外注加工**: 外注加工（塗装・鍍金など）は、品物そのものを送る仕事です。材料と同じ画面でまとめてよいですか。それとも、外注加工は製造ページから1件ずつ出しますか（資料を綴じるため）。

### §4 の答え（2026-10-21）

1. まとめる範囲

   > 2026-10-21 利用者:「選んだ製造だけ」

   → 「まとめて発注」は、まとめる製造ページを選んでから、その製造の残りだけを出します（開いている製造全部は出さない）。

2. 同じ部材を1行にまとめるか

   > 2026-10-21 利用者:「備考も含め一致するなら一行にたす。紙には合計を刷って良い。備考が違うなどの場合は、上下に行を並べるような配慮が欲しい。」

   → 次のとおりにします。
   - 種類・材質・形状・寸法・表面・仕様・**備考**まで全部が同じ行だけを、1行にまとめて数を足します。紙には合計の数を刷ります（どの案件の分かの内訳は、w-cms の中だけに残す・§3.2）。
   - 備考などが少しでも違う行は、まとめません。そのかわり、同じ部材（備考だけが違う など）の行が**上下に並ぶ**ように並べます（並べる順の鍵は、種類 → 材質 → 形状 → 寸法 → 表面 → 備考）。

3. 仕入先の決め方

   > 2026-10-21 利用者:「仕入れ先は加工製品ページの表に推奨業者として書かれているので、これをデフォルトで入れ、必要なら修正してからPDFの作成ボタンを押せば良いと思う」

   → 加工製品ページの部材の表の列「推奨業者」を、仕入先の初めの値にします（列は今もあります）。
   まとめる画面で直してから、部材発注書を作り、PDF を作ります。§3.3 の「仕入先」の列を新しく作る案と、種類ごとの既定の案は採りません。
   推奨業者が空の行は「仕入先未定」の組に入り、人が選びます。

4. 発注部材表を残すか

   > 2026-10-21 利用者:「まず、製造フォルダでチェックを入れ、製造ページが出来て、製造ページで作業します。そこで作る発注部材表から部材発注書を作ります」

   → 発注部材表は残します。流れは「製造」の製造待ちで選んで開始 → 製造ページ → 製造ページの中の発注部材表 → 部材発注書、です。
   筆者の読み: **まとめる単位は製造ページそのもの**です（製造待ちで案件を選んで開始した時点で、まとめる範囲が決まる。問い1の「選んだ製造だけ」と同じ）。
   だから §3.1 の段2（「製造」の置き場で製造をまたいでまとめる画面）は作らず、製造ページの中で、案件をまたいで同じ部材を1行にまとめ（問い2の決まり）、推奨業者ごとに発注部材表を分けます（問い3）。違えば直します。

5. 手配不要の置き場

   > 2026-10-21 利用者:「良いです、」

   → 製造ページの中に置きます（製造ごと・理由と日付）。

6. 案件に結び付かない部材

   > 2026-10-21 利用者:「自社案件として、案件ページに追加するようにしては？通信箱の手書きメモからスタートするのが良いかもしれませんね」

   → 消耗品・工具・社内用なども、**自社を発注元とする案件**（自社案件）として案件ページに書きます。始まりは通信箱の手書きのメモ（「＋ 記録する」）で、そこから案件ページを作ります。
   あとは、ほかの案件と同じく、案件残表 → 製造待ち → 製造ページ → 発注部材表 → 部材発注書、です。§3.4 の案A・案B は採りません。

7. 部材発注書の置き場

   > 2026-10-21 利用者:「まず部材発注書がどこに記録されるか考えましょう」

8. 外注加工

   > 2026-10-21 利用者:「製造ページ内に発注書を記録する場合の問題点を教えてください」

   → 7 と 8 は、下の §5 で考えます。

## 5. 部材発注書をどこに記録するか（2026-10-21・問い7・8 の続き）

いまは、製造ページの発注部材表から作った部材発注書は、**その製造ページの子**になります。製造ページを閉じると、子ごと `記録／年／月／製造記録`（閉じた月）へ移ります。
（納品書・見積書・部材見積依頼書も、製造ページから作れば同じく子になります。）

### 5.1 製造ページの子にする（いまの形）の良い所

- 製造ページを開けば、その製造の部材発注書がすぐ下に並びます。1つの製造が、1つのまとまり（フォルダ）になります。
- 閉じると、製造ページと一緒に、まとめて記録へ移ります。
- 権限が製造ページにそろいます。
- 子ページのあるページは削除できない決まりなので、製造ページを消して部材発注書を失うことはありません。

### 5.2 製造ページの子にする場合の問題点

1. **案件を取り消して別の製造へ移すと、部材発注書は元の製造ページの下に残ります。**
   新しい製造ページを開いても、その案件の部材をもう発注したことが、下の一覧には見えません。
   二重発注は、案件ごとに数える仕組みで防げます。ただし、人が「どこで発注したか」を探しにくくなります。
2. **記録の年月が、発注した月ではなく、製造を閉じた月になります。**
   部材発注書は7年残す書類です。月ごとに発注書を見返すときに、発注した月の `製造記録` に無く、閉じた月の製造ページの下にあります。
3. **閉じるまで、記録の年月に現れません。** 進んでいる製造の部材発注書は、トップ直下の「製造」の下にあります。月ごとの一覧には、閉じるまで出ません。
4. **1枚の部材発注書を、2つの製造にまたがらせられません。** 問い4の答え（製造ページごとに作る）なら、困りません。
5. **製造ページの子が増えます。** 部材発注書・納品書・見積書が並ぶと、子ページの一覧が長くなります（見やすさの問題だけです）。
6. **外注加工（問い8）**: 外注加工の部材発注書は、品物と資料（図面）を一緒に送ります。資料は製造ページの加工製品から綴じるので、置き場がどちらでも、綴じ方は変わりません。
   置き場で困るのは、上の1〜3と同じことです。

### 5.3 もう1つの形——記録の年月に置き、製造ページからは一覧で見る

- 部材発注書は、作った日の `記録／年／月／製造記録` に置きます（製造ページの子にしない）。
- 部材発注書に `製造` のタグ（製造ページへのリンク）を書き、製造ページには「この製造の部材発注書」の一覧（表示のたびに集める欄）を出します。案件を移したときは、案件のつながりからも引けます。
- 良い所: 記録の年月が発注した月になります（上の2・3が無くなる）。案件を移しても、一覧で見つかります（上の1が軽くなる）。
- 困る所: 製造ページが「全部の書類の入ったフォルダ」ではなくなります。書類は一覧（リンク）で見ます。

### 5.4 問い

- 部材発注書は、製造ページの子（5.1）と、作った日の記録の年月（5.3）の、どちらがよいですか。
- 同じことを、納品書・見積書・部材見積依頼書にも当てますか（書類の置き方を、1つの決まりにそろえるか）。
