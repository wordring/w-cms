# w-cms (Content Management System)

Go言語で構築された、ファイル統合型のコンテンツ管理システム（CMS）です。

エディタで編集したHTMLを、ファイルシステム（物理ストレージ）へ効率的に分散配置して保存し、同時にHTML内のメタデータやコンテンツ構造を解析してSQLiteデータベースにインデックス情報として登録・同期します。

**Notionライクなブロックベースのインタラクティブエディタ**を備え、**見える文字（階層・ページ名・見出しの表示文字）を手掛かりに**構造化データを読み取ってデータベースと同期します（集計に載せるブロックの印が `data-type`）。保存形式は素のHTMLのままなので、閲覧はJavaScriptなしで完結します。

---

## 🚀 特徴

1. **Notion風ブロックエディタ**
   - 直感的なドラッグ＆ドロップによるブロック単位の並び替え。
   - `/` キーによるスラッシュコマンドメニューからの見出し・段落・発注書などの即座な挿入。
   - ブロックごとにポップアップするコンテキストツールバーによる、スマートなインライン操作。

2. **物理ストレージと仮想階層の分離**
   - 物理ファイルは、自動生成される連番の数字IDをベースに自動でディレクトリ分散（例: `/data/master/00/00001/00001.html`）して格納されます。
   - ユーザーがドキュメント同士を整理するための「仮想階層（親子関係）」は、ページ属性のサイドカー（`<id>.meta.json`）が正本で、データベース側に検索用インデックスとして同期されます。

3. **認証・認可とページ単位の権限**
   - argon2id によるパスワード認証、セッション、CSRF/CSPの多層防御。
   - ページごとに Unix風の read/write を owner・group・other で制御し、明示的に公開したページだけを匿名へ開けます。

4. **同時編集の直列化**
   - ページ単位の悲観ロック＋SSEで、複数人が同時に開いても上書き事故（lost update）が起きません。

5. **CGO不要のPure Go SQLite**
   - Windows環境などでもCコンパイラなしで動作するPure Go実装のSQLiteドライバ (`modernc.org/sqlite`) を採用しています。

6. **マーカー付き標準HTMLによる構造化データ**
   - 本文中の `<table data-type="...">`・`<dl data-type="...">`・`<section data-type="...">` から可変メタデータや取引情報（見積・発注単価、部品構成）を抽出し、データベースへインデックス情報として自動で同期します。
   - 形式の宣言は**語彙レジストリ**（`internal/cms/vocab.go`）にデータとして置き、新しい形式はそこへ1件足すだけで、エディタの挿入メニュー・索引・型検証まで揃います。
   - 保存されるのは素のHTMLなので、閲覧側はJavaScriptもカスタム要素も要りません（かつての Web Components 方式は 2026-08 に全廃しました）。

## 🛠 動作方法

### 1. 依存関係のセットアップ
Goがインストールされている環境で、プロジェクトルートにて依存パッケージをダウンロードします。

```bash
go mod tidy
```

### 2. アプリケーションの起動
**初回のみ**、初期管理者を環境変数で指定して起動します（認証が有効です）。

```bash
# ローカル検証（HTTP）では Secure Cookie を無効化する
WCMS_ADMIN_USER=admin WCMS_ADMIN_PASSWORD='強いパスワード' WCMS_SECURE_COOKIES=0 \
  go run ./cmd/w-cms
```
2回目以降は環境変数なしで `go run ./cmd/w-cms` で起動できます（管理者は `data/auth.db` に保存済み）。

起動すると `http://localhost:8080` で立ち上がります。ブラウザでアクセスするとログイン画面（`/login`）にリダイレクトされるので、上で設定した管理者でログインしてください。

> 本番（インターネット公開）では TLS/HTTPS が必須です。リバースプロキシ（Caddy/nginx）でTLS終端し、`WCMS_SECURE_COOKIES` は設定しない（既定の Secure 有効）でください。詳細は [認証認可設計.md](docs/認証認可設計.md) と [【ガイド】デプロイ・運用.md](docs/【ガイド】デプロイ・運用.md)。

### 3. テストの実行

```bash
go test ./...
```
